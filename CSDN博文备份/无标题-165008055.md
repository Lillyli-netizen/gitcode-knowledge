是一种<strong>脚本语言</strong>，最初运行在<strong>浏览器（客户端）</strong>中；用于实现<strong>人机交互效果。</strong>Node.js 出现后，它也可以运行在服务器端。</p> <br><p><strong>核心作用：</strong></p> <br><ul><li><strong>网页特效</strong>：监听用户行为，让网页作出对应的反馈（轮播图）</li><li><strong>表单验证</strong>：针对表单数据的合法性进行判断</li><li><strong>数据交互</strong>：获取后台数据，渲染到前端</li><li><strong>服务端编程</strong>：通过 Node.js 的组成</h4> <br><p>JavaScript 由三大部分组成：</p> <br><table><thead><tr><th>组成部分</th><th>说明</th><th>具体内容</th></tr></thead><tbody><tr><td><strong>ECMAScript</strong></td><td>JavaScript <br><table><thead><tr><th>类型</th><th>示例</th></tr></thead><tbody><tr><td><strong>数字字面量</strong></td><td>1000、18、88.99</td></tr><tr><td><strong>字符串字面量</strong></td><td>'喵而咪之'、"王富贵"</td></tr><tr><td><strong>数组字面量</strong></td><td><code>[]、[1, name="%E4%BA%8C%E3%80%81%E5%8F%98%E9%87%8F%EF%BC%88variable%EF%BC%89">二、变量（variable）</h3> <br><h4 id="2.1%20%E5%8F%98%E9%87%8F%E6%98%AF%E4%BB%80%E4%B9%88" name="2.1%20%E5%8F%98%E9%87%8F%E6%98%AF%E4%BB%80%E4%B9%88" style="background-color:transparent">2.1 变量是什么</h4> <br><p><strong>变量</strong>是计算机中用来存储数据的<strong>容器</strong>，它让程序有了"记忆"能力。</p> <br><p>- 白话理解：变量就像一个贴了标签的盒子，盒子里装数据</p> <br><blockquote> <br> <p>注意：变量不是数据本身，而是存储数据的<strong>容器</strong>；通过变量名可以<strong>取出或替换</strong>里面的数据</p> <br></blockquote> <br><pre><code class="language-javascript">let age = 18        // 声明一个变量 age，存放 18<br>let uname = '小明'   // 声明一个变量 uname，存放 '小明'<br></code></pre> <br><h4 id="2.2%20%E5%8F%98%E9%87%8F%E7%9A%84%E5%9F%BA%E6%9C%AC%E4%BD%BF%E7%94%A8" name="2.2%20%E5%8F%98%E9%87%8F%E7%9A%84%E5%9F%BA%E6%9C%AC%E4%BD%BF%E7%94%A8">2.2 变量的基本使用</h4> <br><h5 id="2.2.1%20%E5%A3%B0%E6%98%8E%E5%8F%98%E9%87%8F" name="2.2.1%20%E5%A3%B0%E6%98%8E%E5%8F%98%E9%87%8F">2.2.1 声明变量</h5> <br><pre><code class="language-javascript">let 变量名<br></code></pre> <br><ul><li><strong><code>let</code></strong>：声明<strong>关键字</strong>（允许、许可、让、要），由 JS 语法提供</li><li><strong>变量名</strong>：也叫标识符，自己命名</li></ul> <br><pre><code class="language-javascript">let age    // 声明了一个 age 变量<br></code></pre> <br><h5 id="2.2.2%20%E5%8F%98%E9%87%8F%E8%B5%8B%E5%80%BC" name="2.2.2%20%E5%8F%98%E9%87%8F%E8%B5%8B%E5%80%BC">2.2.2 变量赋值</h5> <br><p>声明之后，通过 <code>=</code> 给变量存入数据。下面是一个完整的综合示例，涵盖声明、赋值、使用、查看类型、重新赋值、初始化、命名规范和声明多个变量：</p> <br><pre><code class="language-javascript">// 1. 声明一个年龄变量<br>let age<br>// 2. 给变量赋值<br>age = 20<br>// 3. '张三'<br>console.log(age1, uname1)</code></pre> <br><h5 id="2.2.3%20%E5%8F%98%E9%87%8F%E5%88%9D%E5%A7%8B%E5%8C%96%EF%BC%88%E5%A3%B0%E6%98%8E%E5%90%8C%E6%97%B6%E8%B5%8B%E5%80%BC%EF%BC%89" <br><p>第一次给变量赋值叫<strong>初始化</strong>，实际开发中通常声明时直接初始化：</p> <br><pre><code class="language-javascript">let age = 18    // 声明变量 age，同时存放 18 这个数据<br></code></pre> <br><h5 <p><strong>注意</strong>：<code>let</code> <strong>不允许</strong>多次声明同一个变量，否则会报错：<br /> <code>Uncaught SyntaxError: Identifier 'age' has already been declared</code></p> <br></blockquote> <br><h5 id="2.2.5%20%E5%A3%B0%E6%98%8E%E5%A4%9A%E4%B8%AA%E5%8F%98%E9%87%8F" name="2.2.5%20%E5%A3%B0%E6%98%8E%E5%A4%9A%E4%B8%AA%E5%8F%98%E9%87%8F">2.2.5 声明多个变量</h5> <br><pre><code class="language-javascript">// 语法：多个变量中间用逗号隔开<br>let age = 18, uname = 'pink'<br>// 不推荐这样写，为了更好的可读性，请一行只声明一个变量<br>let age = 18<br>let uname = 'pink'</code></pre> <br><h5 id="2.2.6%20%E5%8F%98%E9%87%8F%E7%BB%BC%E5%90%88%E6%A1%88%E4%BE%8B" name="2.2.6%20%E5%8F%98%E9%87%8F%E7%BB%BC%E5%90%88%E6%A1%88%E4%BE%8B">2.2.6 变量综合案例</h5> <br><p><strong>案例：输入用户名并输出</strong></p> <br><pre><code class="language-javascript">// 1. 弹出输入框，提示用户输入用户名<br>prompt('请输入用户名')<br>// 2. 用变量保存用户输入的内容（prompt 的返回值是字符串类型）<br>let uname = prompt('请输入用户名')，<br>// 3. 把用户名输出到页面上<br>document.write(uname)</code></pre> <br><p><strong>说明：</strong>第 1 步先演示了单独调用 <code>prompt()</code>，但这样输入的内容没有被保存；第 2 步用变量 <code>uname</code> 接收返回值，之后才能通过变量名取出并使用。这也是变量 <strong>存储数据 </strong>价值的体现。</p> <br><p><strong>案例2：输出用户信息</strong></p> <br><pre><code class="language-javascript">// 1. 分别弹出输入框，让用户输入姓名、年龄、性别，并用变量保存<br>let userName = prompt('请输入您的姓名')<br>let age = prompt('请输入您的年龄')<br>let gender = prompt('请输入您的性别')<br>// 2. 控制台输出，便于调试<br>console.log(userName, age, gender)<br>// 3. 把用户信息拼接后输出到页面<br>document.write(userName + '的年龄是' + age + '岁，性别是' + gender)</code></pre> <br><p><strong>说明：</strong>这里用三个变量分别保存用户输入的三项信息，再用 <code>+</code> 把字符串和变量拼接成一句完整的话输出。注意 <code>prompt()</code> 拿到的年龄也是字符串类型，这里直接拼接展示没有问题。</p> <br><p><strong>案例2：交换两个变量</strong></p> <br><pre><code class="language-javascript">// 交换两个变量<br>let a = 10<br>let b = 20<br>// 交换前：10 20<br>console.log(a, b)<br>// 借助第三个临时变量 temp 完成交换：<br>// 先把 a 原来的值存起来，再把 b 的值给 a，最后把暂存的值给 b<br>let temp = a<br>a = b<br>b = temp<br>// 交换后：20 10<br>console.log(a, b)</code></pre> <br><p><strong>说明：</strong>交换两个变量的值需要借助一个临时变量 <code>temp</code>：先把 <code>a</code> 的值暂存起来，再把 <code>b</code> 的值赋给 <code>a</code>，最后把暂存的值赋给 <code>b</code>。这体现了 <strong>变量取出和替换数据</strong> 的能力。</p> <br><h5 id="" name=""></h5> <br><h4 id="2.3%20%E5%8F%98%E9%87%8F%E7%9A%84%E6%9C%AC%E8%B4%A8" name="2.3%20%E5%8F%98%E9%87%8F%E7%9A%84%E6%9C%AC%E8%B4%A8">2.3 变量的本质</h4> <br><p><strong>内存</strong>：计算机中存储数据的空间。</p> <br><p><strong>变量本质</strong>：是程序在内存中申请的一块存储空间，变量名用来找到这块空间，<code>=</code> 把数据存进去。</p> <br><pre><code class="language-javascript">let age = 18        // 在内存中申请一个空间，存放 18<br>let goods = '电脑'   // 在内存中申请一个空间，存放 '电脑'<br></code></pre> <br><h4 id="2.4%20%E5%8F%98%E9%87%8F%E5%91%BD%E5%90%8D%E8%A7%84%E5%88%99%E4%B8%8E%E8%A7%84%E8%8C%83" name="2.4%20%E5%8F%98%E9%87%8F%E5%91%BD%E5%90%8D%E8%A7%84%E5%88%99%E4%B8%8E%E8%A7%84%E8%8C%83">2.4 变量命名规则与规范</h4> <br><table><thead><tr><th>类别</th><th>性质</th><th>说明</th></tr></thead><tbody><tr><td><strong>规则</strong></td><td>必须遵守，不遵守报错（类似法律层面）</td><td>1. 不能是 关键字或保留字 （如<code>let</code> 、<code>var</code> 、<code>if</code> 、<code>for</code> 等）<br /> 2. 只能由字母、数字、下划线<code>_</code> 、<code>$</code> 组成，且不能以数字开头<br /> 3. 严格区分大小写（<code>Age</code> 和<code>age</code> 是两个变量）</td></tr><tr><td><strong>规范</strong></td><td>建议遵守，不遵守不会报错（类似道德层面）</td><td>1. 起名要见名知意<br /> 2. 遵守小驼峰命名法：第一个单词全小写，后面每个单词首字母大写，如<code>userName</code></td></tr></tbody></table> <br><blockquote> <br> <p>语法上也允许用中文等 Unicode 字符做变量名（如<code>let 年龄 = 18</code> ），但实际开发中不推荐。</p> <br></blockquote> <br><p><strong>合法变量名判断表：</strong></p> <br><table><thead><tr><th>变量名</th><th>是否报错</th><th>是否符合规范</th></tr></thead><tbody><tr><td><code>21age</code></td><td>报错</td><td>不能以数字开头</td></tr><tr><td><code>_age</code></td><td>不报错</td><td>合法；_ 开头常用来约定表示"内部变量"</td></tr><tr><td><code>user-name</code></td><td>报错</td><td>- 是关键字</td></tr><tr><td><code>na@me</code></td><td>报错</td><td>@ 是非法字符</td></tr><tr><td><code>$age</code></td><td>不报错</td><td>合法；$ 开头的命名常见于 jQuery 等场景</td></tr></tbody></table> <br><h4 id="2.5%20let%20%E5%92%8C%20var%20%E7%9A%84%E5%8C%BA%E5%88%AB" name="2.5%20let%20%E5%92%8C%20var%20%E7%9A%84%E5%8C%BA%E5%88%AB">2.5 let 和 var 的区别</h4> <br><table><thead><tr><th>对比项</th><th>var（旧）</th><th>let（新，推荐）</th></tr></thead><tbody><tr><td><strong>先使用后声明</strong></td><td>允许（不合理）不报错，但得到`undefined`</td><td>不允许，报错，必须先声明再使用</td></tr><tr><td><strong>重复声明</strong></td><td>允许（不合理）</td><td>不允许</td></tr><tr><td><strong>变量提升</strong></td><td>变量提升，并自动初始化为`undefined`</td><td>无，存在暂时性死区（TDZ），声明前访问报错</td></tr><tr><td><strong>块级作用域</strong></td><td>无</td><td>有</td></tr></tbody></table> <br><pre><code class="language-javascript">/ ========== let 和 var 的区别 ==========<br>// 1. 变量提升：var 声明前访问不报错；let 声明前访问报错（暂时性死区 TDZ）<br>console.log(num1)        // undefined（var 声明会提升，并自动初始化为 undefined）<br>var num1 = 10<br>// console.log(num2)     // 报错：Cannot access 'num2' before initialization<br>let num2 = 20<br>// 2. 重复声明：var 允许，let 不允许<br>var num3 = 1<br>var num3 = 2             // 不报错，相当于重新赋值<br>console.log(num3)        // 2<br>let num4 = 1<br>// let num4 = 2          // 报错：Identifier 'num4' has already been declared<br>// 3. 块级作用域：var 没有，let 有（出了 {} 就访问不到）<br>{<br>  var a = 10<br>  let b = 20<br>}<br>console.log(a)           // 10：var 声明的变量会"泄漏"到块外面<br>// console.log(b)        // 报错：b is not defined，let 只在所在的 {} 内有效</code></pre> <br><blockquote> <br> <p><strong>结论</strong>：<code>var</code> 是旧时代的设计，存在允许重复声明、无块级作用域等缺陷。新代码中声明变量统一使用<code>let</code></p> <br></blockquote> <br><h4 id="2.6%20%E5%8F%98%E9%87%8F%E6%8B%93%E5%B1%95%20%E2%80%94%E2%80%94%20%E6%95%B0%E7%BB%84" name="2.6%20%E5%8F%98%E9%87%8F%E6%8B%93%E5%B1%95%20%E2%80%94%E2%80%94%20%E6%95%B0%E7%BB%84">2.6 变量拓展 —— 数组</h4> <br><p><strong>数组（Array）</strong> 是一种将一组数据存储在单个变量名下的优雅方式。</p> <br><pre><code class="language-javascript">let names = ['小明', '小刚', '小红', '小丽', '小米']<br></code></pre> <br><blockquote> <br> <p>['小明', '小刚', ...] 整体称为 数组字面量 ，中括号[] 是数组的语法标志。</p> <br></blockquote> <br><p><br /> <strong>核心概念：</strong></p> <br><table><thead><tr><th>术语</th><th>说明</th></tr></thead><tbody><tr><td><strong>元素</strong></td><td>数组中保存的每个数据</td></tr><tr><td><strong>下标（索引index）</strong></td><td>数组中数据的编号，<strong>从 0 开始</strong></td></tr><tr><td><strong>长度</strong></td><td>数组中数据的个数，通过 <code>数组名.length</code> 获得</td></tr></tbody></table> <br><p><strong>取值语法：</strong></p> <br><pre><code class="language-javascript">数组名[下标]<br>let names = ['小明', '小刚', '小红', '小丽', '小米']<br>names[0]        // 小明<br>names[1]        // 小刚<br>names.length    // 5</code></pre> <br><p>数组可以存储任意类型的数据，元素按顺序排列，下标从 0 开始。</p> <br><blockquote> <br> <p>注意 ：数组里的字符串必须加引号。 <strong>任何字符串字面量都要用引号包裹</strong> ，不加引号的内容会被 JS 当成变量名解析；如果这个变量没有声明，就会报错 ReferenceError: xxx is not defined ，和是不是中文没有关系。</p> <br></blockquote> <br><p><strong>案例：一周七天数组</strong></p> <br><pre><code class="language-javascript">// 定义一个保存一周七天的数组<br>let weeks = ['星期一', '星期二', '星期三', '星期四', '星期五', '星期六', '星期日']<br>// 通过下标取值（下标从 0 开始，6 对应最后一个元素）<br>console.log(weeks[6]) // 星期日<br>// 数组长度 = 元素个数 = 最大下标 + 1<br>console.log(weeks.length) // 7</code></pre> <br><blockquote> <br> <p><strong>说明：</strong>数组的下标从 0 开始，所以最后一个元素的下标是 <code>长度 - 1</code>。</p> <br> <p>这里 <code>weeks[6]</code> 取到的是「星期日」，<code>weeks.length</code> 得到数组的元素个数 7。</p> <br></blockquote> <br><p><strong>两个延伸知识点：</strong></p> <br><ol><li><strong>取数组最后一个元素</strong>：不用手写死下标，可以写成 <code>weeks[weeks.length - 1]</code>，数组长度变化时这行依然正确，比 <code>weeks[6]</code> 更通用。</li><li><strong>下标越界不会报错</strong>，而是得到 <code>undefined</code>：<code>weeks[7]</code> 返回 <code>undefined</code>（数组只有 0~6 七个下标）。这和变量未声明报错（<code>ReferenceError</code>）不同，访问数组不存在的位置只是<strong>取不到值。</strong></li></ol> <br><h3 id="%E4%B8%89%E3%80%81%E5%B8%B8%E9%87%8F" name="%E4%B8%89%E3%80%81%E5%B8%B8%E9%87%8F">三、常量</h3> <br><h4 id="3.1%20%E5%B8%B8%E9%87%8F%E7%9A%84%E5%9F%BA%E6%9C%AC%E4%BD%BF%E7%94%A8" name="3.1%20%E5%B8%B8%E9%87%8F%E7%9A%84%E5%9F%BA%E6%9C%AC%E4%BD%BF%E7%94%A8">3.1 常量的基本使用</h4> <br><p><strong>概念</strong>：用 const 声明、声明后绑定不能被修改的变量，称为<strong>常量</strong>。</p> <br><p><strong>使用场景</strong>：当一个数据确定永远不会改变时（如圆周率、重力加速度），用 const 而不是 let。</p> <br><p><strong>命名规范</strong>：语法上和变量一致；惯例上常量名 <strong>全大写，多个单词用下划线连接</strong> 。</p> <br><pre><code class="language-javascript">// 声明一个常量（声明时必须赋值）<br>const G = 9.8<br>// 输出这个常量<br>console.log(G)</code></pre> <br><h4 id="3.2%20%E5%B8%B8%E9%87%8F%E7%9A%84%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9" name="3.2%20%E5%B8%B8%E9%87%8F%E7%9A%84%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9">3.2 常量的注意事项</h4> <br><ol><li><strong>常量声明时必须赋值 ，不能先声明后赋值。</strong></li><li>常量不能被重新赋值 。</li></ol> <br><pre><code class="language-javascript">// 错误示例：常量被重新赋值<br>const G = 9.8<br>G = 9.9             // 报错：Assignment to constant variable.<br>console.log(G)<br></code></pre> <br><pre><code class="language-javascript">// 错误示例：常量声明时未赋值<br>const age           // 报错：Missing initializer in const declaration<br>console.log(age)<br></code></pre> <br><blockquote> <br> <p>`const` 锁的是"变量和数据之间的绑定关系"，不是数据本身。如果常量里存的是数组或对象， <strong>不能整体替换，但可以修改里面的内容</strong> 。</p> <br></blockquote> <br><h4 id="3.3%20let%E3%80%81var%E3%80%81const%20%E5%AF%B9%E6%AF%94%E6%80%BB%E7%BB%93" name="3.3%20let%E3%80%81var%E3%80%81const%20%E5%AF%B9%E6%AF%94%E6%80%BB%E7%BB%93">3.3 let、var、const 对比总结</h4> <br><table><thead><tr><th>关键字</th><th>说明</th><th>使用建议</th></tr></thead><tbody><tr><td><strong><code>let</code></strong></td><td>现代标准的变量声明方式，值可以修改</td><td>✅ 优先使用</td></tr><tr><td><strong><code>var</code></strong></td><td>旧的声明方式，存在重复声明、无块级作用域等问题</td><td>新代码不再使用</td></tr><tr><td><strong><code>const</code></strong></td><td>声明后不能重新赋值</td><td>数据不需要改变时使用</td></tr></tbody></table> <br><h3 id="%E5%9B%9B%E3%80%81%E6%95%B0%E6%8D%AE%E7%B1%BB%E5%9E%8B" name="%E5%9B%9B%E3%80%81%E6%95%B0%E6%8D%AE%E7%B1%BB%E5%9E%8B">四、数据类型</h3> <br><h4 id="4.0%20%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E7%BB%99%E6%95%B0%E6%8D%AE%E5%88%86%E7%B1%BB%EF%BC%9F" name="4.0%20%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E7%BB%99%E6%95%B0%E6%8D%AE%E5%88%86%E7%B1%BB%EF%BC%9F">4.0 为什么要给数据分类？</h4> <br><p>计算机世界中的万事万物都是数据。</p> <br><p>给数据分类的原因：</p> <br><p>1. 更充分、高效地利用内存 （不同类型的数据占用的<strong>存储空间不同</strong>）<br /> 2. 更方便程序员使用数据 （不同类型<strong>支持不同的操作</strong>，如数字能运算、字符串能拼接）</p> <br><h4 id="4.1%20%E6%95%B0%E6%8D%AE%E7%B1%BB%E5%9E%8B%E6%95%B4%E4%BD%93%E5%88%86%E7%B1%BB" name="4.1%20%E6%95%B0%E6%8D%AE%E7%B1%BB%E5%9E%8B%E6%95%B4%E4%BD%93%E5%88%86%E7%B1%BB">4.1 数据类型整体分类</h4> <br><p>JS 数据类型整体分为两大类：</p> <br><table><thead><tr><th>大类</th><th>包含类型</th></tr></thead><tbody><tr><td><strong>基本数据类型</strong></td><td><code>number</code>（数字型）、<code>string</code>（字符串型）、<code>boolean</code>（布尔型）、<code>undefined</code>（未定义型）、<code>null</code>（空类型）</td></tr><tr><td><strong>引用数据类型</strong></td><td><code>object（对象）。数组Array 、函数Function 等也属于引用类型，它们本质上都是对象</code></td></tr></tbody></table> <br><h4 id="4.2%20%E6%95%B0%E5%AD%97%E7%B1%BB%E5%9E%8B%EF%BC%88Number%EF%BC%89" name="4.2%20%E6%95%B0%E5%AD%97%E7%B1%BB%E5%9E%8B%EF%BC%88Number%EF%BC%89">4.2 数字类型（Number）</h4> <br><p>即数学中学习到的数字，可以是整数、小数、正数、负数。</p> <br><pre><code class="language-javascript">let age = 18        // 整数<br>let price = 88.99   // 小数（也叫浮点数）<br></code></pre> <br><blockquote> <br> <p>JavaScript 中的正数、负数、小数等 <strong>统一称为数字类型（number）</strong> 。</p> <br></blockquote> <br><p><strong>注意事项：</strong></p> <br><p>JavaScript 是 <strong>动态类型 + 弱类型</strong> 语言：</p> <br><p>- 动态类型 ：变量本身没有固定类型，它的类型由存进去的<strong> 值 </strong>决定，而且以后还可以改成别的类型<br /> - 弱类型 ：不同类型的数据一起运算时，JS 会尽量自动转换（隐式转换）</p> <br><pre><code class="language-javascript">let a = 10        // 此时 a 是数字型<br>a = '你好'         // 之后又可以存字符串，不会报错</code></pre> <br><p>对比：Java 是强类型语言，int a = 3 规定 a 只能存整数，a = '你好' 会直接报错。</p> <br><h5 id="4.2.1%20%E7%AE%97%E6%9C%AF%E8%BF%90%E7%AE%97%E7%AC%A6" name="4.2.1%20%E7%AE%97%E6%9C%AF%E8%BF%90%E7%AE%97%E7%AC%A6">4.2.1 算术运算符</h5> <br><p>数字可以有很多操作，经常和算术运算符一起使用。</p> <br><table><thead><tr><th>运算符</th><th>作用</th><th>示例</th></tr></thead><tbody><tr><td><code>+</code></td><td>求和</td><td><code>1 + 2 = 3</code></td></tr><tr><td><code>-</code></td><td>求差</td><td><code>10 - 8 = 2</code></td></tr><tr><td><code>*</code></td><td>求积</td><td><code>2 * 3 = 6</code></td></tr><tr><td><code>/</code></td><td>求商</td><td><code>10 / 2 = 5</code></td></tr><tr><td><code>%</code></td><td>取模（取余数）</td><td><code>2 % 5 = 2</code></td></tr></tbody></table> <br><pre><code class="language-javascript">// 数字型：整数、小数都属于 number 类型，赋什么值就是什么类型<br>let num = 10<br>console.log(num) // 10<br>// 算术运算符<br>console.log(1 + 2)  // 3（加）<br>console.log(10 - 8) // 2（减）<br>console.log(2 * 3)  // 6（乘）<br>console.log(10 / 2) // 5（除）<br>console.log(4 % 3)  // 1（取模/取余数）<br>console.log(2 % 5)  // 2（2 除以 5 商 0 余 2）</code></pre> <br><blockquote> <br> <p><strong>开发中经常用 <code>%</code> 判断某个数字是否被整除。</strong>若x % 2 = 0 ，说明 x 是偶数；x % y = 0 说明 x 能被 y 整除。</p> <br></blockquote> <br><h5 id="4.2.2%20%E7%AE%97%E6%9C%AF%E8%BF%90%E7%AE%97%E7%AC%A6%E4%BC%98%E5%85%88%E7%BA%A7" name="4.2.2%20%E7%AE%97%E6%9C%AF%E8%BF%90%E7%AE%97%E7%AC%A6%E4%BC%98%E5%85%88%E7%BA%A7">4.2.2 算术运算符优先级</h5> <br><p>同时使用多个运算符编写程序时，会按某种顺序先后执行，称为<strong>优先级</strong>。<br /> JavaScript 中优先级越高越先被执行，优先级相同时从左向右执行。</p> <br><table><thead><tr><th>优先级</th><th>运算符</th></tr></thead><tbody><tr><td>最高</td><td><code>()</code> 括号</td></tr><tr><td>高</td><td><code>* 、/ 、%</code></td></tr><tr><td>低</td><td><code>+ 、-</code></td></tr></tbody></table> <br><p><strong>记忆口诀</strong>：有括号先算括号；没有括号先乘除取余，后加减。</p> <br><pre><code class="language-javascript">console.log(1 + 2 * 3)      // 7（先算 2*3）<br>console.log(10 - 8 / 2)     // 6（先算 8/2）<br>console.log(2 % 5 + 4 * 2)  // 10（2%5=2，4*2=8，再相加）</code></pre> <br><h5 id="%E6%A1%88%E4%BE%8B%EF%BC%9A%E8%AE%A1%E7%AE%97%E5%9C%86%E7%9A%84%E9%9D%A2%E7%A7%AF" name="%E6%A1%88%E4%BE%8B%EF%BC%9A%E8%AE%A1%E7%AE%97%E5%9C%86%E7%9A%84%E9%9D%A2%E7%A7%AF"><strong>案例：计算圆的面积</strong></h5> <br><pre><code class="language-javascript">// 计算圆的面积：面积 = 圆周率 × 半径 × 半径<br>// 一元 + 把 prompt 输入的字符串转成数字型<br>let radius = +prompt('请输入圆的半径')<br>const PI = 3.1415926   // 圆周率固定不变，用 const 声明<br>let area = radius * radius * PI<br>document.write('圆的面积为：' + area)</code></pre> <br><blockquote> <br> <p><strong>补充知识</strong>：一元运算符就是<strong>只操作一个数据</strong>的运算符。上面代码里的 <code>+prompt(...)</code> 用的是<strong>一元正号（+）</strong>，它的作用是把<strong>字符串转成数字</strong>。注意：不是所有一元运算符都能转数字，它们各有分工</p> <br> <p><code>+</code> 和 <code>-</code> 转数字（<code>-</code> 还会取负），<code>!</code> 转布尔并取反，<code>++</code> / <code>--</code> 让数字加 1 / 减 1，<code>typeof</code> 检测数据类型。所以 <code>+prompt()</code> 里的 <code>+</code> 是专门用来把输入字符串转成数字的。</p> <br></blockquote> <br><h5 id="4.2.3%20NaN%EF%BC%88Not%20a%20Number%EF%BC%89" name="4.2.3%20NaN%EF%BC%88Not%20a%20Number%EF%BC%89">4.2.3 NaN（Not a Number）</h5> <br><p>NaN 是数字类型的一个<strong> 特殊值 </strong>，表示一次无效的或未定义的数学运算的结果（它本身仍然是 number 类型）</p> <br><pre><code class="language-javascript">console.log('老师' - 2)   // NaN（字符串无法参与减法）<br>console.log(typeof NaN)   // 'number'</code></pre> <br><blockquote> <br> <p><strong>NaN 的"粘性"</strong> ：在<strong>数学运算</strong>中，只要有 NaN 参与，结果通常就是 NaN。如果输入的内容不是纯数字，+ 转换会得到 NaN。<br /> 注意不要记成"每个操作"，比如字符串拼接不属于数学运算：'a' + NaN 的结果是'aNaN' 。</p> <br></blockquote> <br><pre><code class="language-javascript">console.log(NaN = NaN)      // false，NaN 连它自己都不等于<br>console.log(Number.isNaN(NaN))// true，要判断 NaN 用 Number.isNaN()</code></pre> <br><h4 id="4.3%20%E5%AD%97%E7%AC%A6%E4%B8%B2%E7%B1%BB%E5%9E%8B%EF%BC%88String%EF%BC%89" name="4.3%20%E5%AD%97%E7%AC%A6%E4%B8%B2%E7%B1%BB%E5%9E%8B%EF%BC%88String%EF%BC%89">4.3 字符串类型（String）</h4> <br><p>通过<strong>单引号（<code>'</code>）</strong> 、<strong>双引号（<code>"</code>）</strong> 或<strong>反引号（<code>`</code>）</strong> 包裹的数据都叫字符串。</p> <br><pre><code class="language-javascript">let uname = '小明'          // 单引号（常用）<br>let gender = "男"           // 双引号<br>let goods = `小米`          // 反引号（模板字符串专用，下一节讲）<br>let tel = '13681113456'     // 看着是数字，但被引号包裹就是字符串<br>let str1 = ''               // 空字符串（引号中间什么都没有）<br>let str2 = '天气很"蓝"'     // <br>let str3 = '天气很\'蓝\''   // 字符串实际内容是：天气很'蓝'</code></pre> <br><p>- '天气很"蓝"' 为什么可以？ 字符串的"边界"由最外层那对单引号决定，里面的双引号只是 普通字符 ，JS 不会把它当成字符串结束，所以直接写就行。反过来，双引号包裹的字符串里也可以直接写单引号。<br /> - '天气很\'蓝\'' 为什么可以？\ 是 转义符 ，它会让紧跟在后面的那个引号失去"边界"作用，变成一个 普通的单引号字符 。所以这个字符串的实际内容是天气很'蓝' 。<br /> 其他常见转义符：\n （换行）、\t （制表符）、\\ （表示一个反斜杠本身）。</p> <br><h5 id="4.3.1%20%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9" name="4.3.1%20%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9">4.3.1 注意事项</h5> <br><ol><li>单引号、双引号<strong>必须成对使用</strong></li><li>引号可以互相嵌套， 口诀：外双内单，或外单内双 ；不能同符号直接嵌套（`'abc'def'` ❌），也不能交叉嵌套</li><li>需要在字符串里输出和边界相同的引号时，用转义符`\`</li></ol> <br><h5 id="4.3.2%20%E5%AD%97%E7%AC%A6%E4%B8%B2%E6%8B%BC%E6%8E%A5" name="4.3.2%20%E5%AD%97%E7%AC%A6%E4%B8%B2%E6%8B%BC%E6%8E%A5">4.3.2 字符串拼接</h5> <br><p><code>+</code> 运算符两边只要有一边是字符串，就做拼接。</p> <br><p><strong>口诀</strong>：数字相加，字符相连。</p> <br><pre><code class="language-javascript"><br>document.write('我叫' + '丽丽')   // 我叫丽丽<br>let uname = '小猫'<br>let move = '钓鱼'<br>document.write(uname + move)        // 小猫钓鱼<br></code></pre> <br><h5 id="4.3.3%20%E6%A8%A1%E6%9D%BF%E5%AD%97%E7%AC%A6%E4%B8%B2%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89" name="4.3.3%20%E6%A8%A1%E6%9D%BF%E5%AD%97%E7%AC%A6%E4%B8%B2%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89">4.3.3 模板字符串（重点）</h5> <br><p><strong>使用场景</strong>：拼接字符串和变量。在没有它之前，拼接变量比较麻烦。</p> <br><pre><code class="language-javascript">// 传统拼接方式（变量一多就很繁琐，引号和加号容易写错）<br>document.write('大家好，我叫' + name + '，今年' + age + '岁')<br>// 模板字符串方式<br>document.write(`大家好，我叫${name}，今年${age}岁`)</code></pre> <br><p><strong>语法要点：</strong></p> <br><ul><li>- 用 反引号``` 包裹整个字符串（英文输入法下，Esc 下方、数字 1 左边的那个键）<br /> - 用 `${变量名}` 引用变量；`${}` 里不只能放变量，还能放表达式，如`${age + 1}` 、`${price * num}`</li><li>- 模板字符串可以<strong> 直接换行 </strong>，里面的换行会被保留（订单表格案例就用到了）</li></ul> <br><blockquote> <br> <p>示例中的`name` 、`age` 使用前必须先声明并赋值，否则会报`ReferenceError` 。</p> <br></blockquote> <br><p><strong>案例：页面输出用户信息</strong></p> <br><pre><code class="language-javascript">// 模板字符串：用反引号包裹，通过 ${变量名} 拼接变量<br>let age = 18<br>document.write(`我今年${age}岁<br>`)<br>// ${} 里可以放任意表达式：变量、字面量、运算等<br>document.write(`我明年${age + 1}岁<br>`)<br>// 案例：输入姓名和年龄，页面显示“大家好，我叫 xxx，今年 xx 岁了”<br>let userName = prompt('请输入用户名')<br>let userAge = prompt('请输入年龄')<br>document.write(`大家好，我叫${userName}，今年${userAge}岁了`)</code></pre> <br><p><strong>提醒</strong>：这个案例里年龄只是显示、不做计算，所以 <code>prompt</code> 不加 <code>+</code> 没问题；但如果后面要拿年龄做加法（比如 <code>userAge + 1</code>），就要记得写 <code>+prompt(...)</code> 转成数字，否则会变字符串拼接。</p> <br><h4 id="4.4%20%E5%B8%83%E5%B0%94%E7%B1%BB%E5%9E%8B%EF%BC%88Boolean%EF%BC%89" name="4.4%20%E5%B8%83%E5%B0%94%E7%B1%BB%E5%9E%8B%EF%BC%88Boolean%EF%BC%89">4.4 布尔类型（Boolean）</h4> <br><p>用于表示"肯定/否定""真/假"，只有两个固定值：</p> <br><ul><li>true ： 真（肯定）</li><li>false ：假（否定）</li></ul> <br><pre><code class="language-javascript">let isCool = true<br>console.log(isCool)   // true<br></code></pre> <br><blockquote> <br> <p>`true` 和`false` 是字面量，直接写， <strong>不加引号 </strong>（`'true'` 是字符串，不是布尔值）。</p> <br></blockquote> <br><h4 id="4.5%20%E6%9C%AA%E5%AE%9A%E4%B9%89%E7%B1%BB%E5%9E%8B%EF%BC%88Undefined%EF%BC%89" name="4.5%20%E6%9C%AA%E5%AE%9A%E4%B9%89%E7%B1%BB%E5%9E%8B%EF%BC%88Undefined%EF%BC%89">4.5 未定义类型（Undefined）</h4> <br><p>未定义是比较特殊的类型，该类型只有一个值：`undefined` 。</p> <br><p><strong>什么情况出现未定义类型？</strong><br /> 只声明变量，不赋值的情况下，变量的默认值为 <code>undefined</code>。</p> <br><pre><code class="language-javascript">let age                // 声明变量但是未赋值<br>document.write(age)    // 输出 undefined<br></code></pre> <br><p><strong>工作中的使用场景：</strong>先声明一个变量等待接收数据，如果不确定数据有没有传过来，可以判断它是不是`undefined` ，从而判断用户是否传递了数据。</p> <br><h4 id="4.6%20null%EF%BC%88%E7%A9%BA%E7%B1%BB%E5%9E%8B%EF%BC%89" name="4.6%20null%EF%BC%88%E7%A9%BA%E7%B1%BB%E5%9E%8B%EF%BC%89">4.6 null（空类型）</h4> <br><p>JavaScript 中的 <code>null</code> 是一个代表"无""空""值未知"的特殊值，语义上表示<strong> 这里故意放空 。</strong></p> <br><pre><code class="language-javascript">let obj = null<br>console.log(obj)   // null<br></code></pre> <br><p><strong>null 和 undefined 的区别：</strong></p> <br><table><thead><tr><th>类型</th><th>含义</th></tr></thead><tbody><tr><td><code>undefined</code></td><td>还<strong> 没有赋值</strong> （系统默认的空）</td></tr><tr><td><code>null</code></td><td><strong>赋值了</strong> <p><strong>控制台颜色规律</strong>：控制台里不同类型会显示不同颜色（以 Chrome 为例：数字、布尔偏蓝色，字符串和 undefined 偏灰/黑），但颜色随浏览器主题和版本会变化， <strong>只能辅助观察，判断类型要以`typeof` 为准 。</strong></p> <br></blockquote> <br><h5 name="%E4%BA%94%E3%80%81%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2">五、类型转换</h3> <br><h4 id="5.1%20%E4%B8%BA%E4%BB%80%E4%B9%88%E9%9C%80%E8%A6%81%E7%B1%BB%E5%9E%8B%E8%BD%AC%E6%8D%A2%EF%BC%9F" 也不知道变量到底属于哪种数据类型，只有赋值了才清楚。</li><li>使用表单、<code>prompt</code> 获取过来的数据默认是<strong>字符串类型</strong>的，此时就不能直接简单地进行加法运算。</li></ol> <br><pre><code class="language-javascript">console.log('10000' + '2000')   // 输出结果 100002000（字符串拼接，不是加法）<br></code></pre> <br><p>所以需要按业务逻辑主动转换类型，让程序行为更可控、更健壮。</p> <br><h4 id="5.2%20%E9%9A%90%E5%BC%8F%E8%BD%AC%E6%8D%A2" name="5.2%20%E9%9A%90%E5%BC%8F%E8%BD%AC%E6%8D%A2">5.2 隐式转换</h4> <br><p>某些运算符被执行时，系统内部自动将数据类型进行转换，这种转换称为<strong>隐式转换</strong>。</p> <br><p><strong>规则：</strong></p> <br><ul><li><code>+</code> 号两边只要有一个是字符串，都会把另外一个转成<strong>字符串，结果为拼接</strong></li><li>除了 <code>+</code> 以外的算术运算符（如 <code>-</code>、<code>*</code>、<code>/</code> 等）会把两边的数据尽量转成 <strong>数字 </strong>再运算</li></ul> <br><pre><code class="language-javascript">console.log(11 + 11)        // 22<br>console.log('11' + 11)      // '1111'（拼接）<br>console.log('11' - 11)      // 0（字符串被转成数字）<br>console.log('1' * 1)        // 1</code></pre> <br><p>下面通过一组代码，把隐式转换的两条核心规则串起来看：</p> <br><pre><code <br><table><thead><tr><th>表达式</th><th>结果</th><th>说明</th></tr></thead><tbody><tr><td><code>+'123'</code></td><td><code>123</code></td><td>数字字符串转数字</td></tr><tr><td><code>+''</code></td><td><code>0</code></td><td>空字符串转成 0</td></tr><tr><td><code>+undefined</code></td><td><code>NaN</code></td><td>undefined 转不了数字</td></tr><tr><td><code>+'abc'</code></td><td><code>NaN</code></td><td>非数字字符串转换失败</td></tr></tbody></table> <br><blockquote> <br> <p>正因为 <code>prompt</code> 拿到的是字符串，实战中常写 <code>let num = +prompt(...)</code>，一行完成"输入 + 转数字"。</p> <br></blockquote> <br><p><strong>隐式转换的缺点</strong>：规则零碎、不直观，全靠经验，可读性差，复杂逻辑建议用显式转换。</p> <br><p><strong>小技巧：</strong></p> <br><ul><li><code>+</code> 号作为正号解析可以转换成数字型</li><li>任何数据和字符串相加结果都是字符串</li></ul> <br><h4 name="%E9%94%99%E8%AF%AF%E4%BA%8C%EF%BC%9A%E5%8F%98%E9%87%8F%E6%9C%AA%E5%AE%9A%E4%B9%89">错误二：变量未定义</h4> <br><pre><code class="language-javascript"><br>console.log(age)<br>// 报错：Uncaught ReferenceError: age is not defined<br></code></pre> <br><p><strong>分析</strong>：提示 age 从未声明过。常见原因：忘了声明，或使用时把变量名拼错了（大小写也要一致）。</p> <br><h4
