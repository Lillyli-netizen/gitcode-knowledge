来更改样式的，必须要用适合的标签来包裹它们，本质是修改标签样式，里面的文字跟随样式变化。</p> <br><h3 id="%E4%B8%80%E3%80%81%E5%AD%97%E4%BD%93%E6%A0%B7%E5%BC%8F%EF%BC%88Font%20Styles%EF%BC%89" <br><h4 id="1.1%20%E5%AD%97%E4%BD%93%E9%A2%9C%E8%89%B2%20color" name="1.1%20%E5%AD%97%E4%BD%93%E9%A2%9C%E8%89%B2%20color">1.1 字体颜色 color</h4> <br><p>颜色是文字最直观的视觉属性，通过 <code>color</code> 属性即可为文字设置不同的颜色。</p> <br><p>最常见的三种颜色指定方式：</p> <br><h5 id="%EF%BC%881%EF%BC%89%E5%85%B3%E9%94%AE%E5%AD%97" name="%EF%BC%881%EF%BC%89%E5%85%B3%E9%94%AE%E5%AD%97">（1）关键字</h5> <br><p>学习时使用，生产环境不常用。</p> <br><pre><code class="language-css">p {<br>    color: red;<br>    color: pink;<br>    color: blue;<br>}<br></code></pre> <br><h5 id="%EF%BC%882%EF%BC%89%E5%8D%81%E5%85%AD%E8%BF%9B%E5%88%B6%EF%BC%88%E6%9C%80%E5%B8%B8%E7%94%A8%EF%BC%89" name="%EF%BC%882%EF%BC%89%E5%8D%81%E5%85%AD%E8%BF%9B%E5%88%B6%EF%BC%88%E6%9C%80%E5%B8%B8%E7%94%A8%EF%BC%89">（2）十六进制（最常用）</h5> <br><p>实际开发中从设计稿直接复制即可。</p> <br><pre><code class="language-css">p {<br>    color: #FF0000;  /* 红色 */<br>    color: #F00;     /* 红色简写 */<br>    color: #3366cc;  /* 蓝色 */<br>}<br></code></pre> <br><h5 id="%EF%BC%883%EF%BC%89rgb%2Frgba%20%E6%A0%BC%E5%BC%8F" name="%EF%BC%883%EF%BC%89rgb%2Frgba%20%E6%A0%BC%E5%BC%8F">（3）rgb/rgba 格式</h5> <br><pre><code class="language-css">p {<br>    color: rgb(255, 0, 0);        /* 红色 */<br>    color: rgba(255, 0, 0, 0.3);  /* 红色，30%不透明度 */<br>}<br><br></code></pre> <br><blockquote> <br> <p><code>rgba</code> 最后一个数值取值 0~1，0 完全透明，1 完全不透明。</p> <br></blockquote> <br><p><strong>总结</strong>：学习用关键字，开发用十六进制，特殊情况用 rgb/rgba。</p> <br><h4 id="1.2%20%E5%AD%97%E4%BD%93%E6%97%8F%20font-family" name="1.2%20%E5%AD%97%E4%BD%93%E6%97%8F%20font-family">1.2 字体族 font-family</h4> <br><p>字体族决定了文字使用哪种字体外观，是页面整体风格的重要基础。</p> <br><p>给定一个有先后顺序的字体列表，浏览器会选择列表中第一个该计算机上已安装的字体。</p> <br><pre><code class="language-css">body {<br>    font-family: Arial, Helvetica, sans-serif;<br>}<br></code></pre> <br><p>属性值用<strong>逗号</strong>隔开。</p> <br><p><strong>实际开发中直接复制即可</strong>，无需记忆。例如：</p> <br><pre><code class="language-css">/* 小米字体 */<br>font-family: Helvetica Neue, Helvetica, Arial, Microsoft Yahei, Hiragino Sans GB, Heiti SC, WenQuanYi Micro Hei, sans-serif;<br>/* 京东字体 */<br>font-family: PingFang SC, Source Han Sans CN, Microsoft YaHei, Heiti SC, tahoma, arial, Hiragino Sans GB, sans-serif;<br></code></pre> <br><h4 id="1.3%20%E5%AD%97%E4%BD%93%E5%A4%A7%E5%B0%8F%20font-size" name="1.3%20%E5%AD%97%E4%BD%93%E5%A4%A7%E5%B0%8F%20font-size">1.3 字体大小 font-size</h4> <br><p>字体大小直接影响文字的可读性和页面层级，是排版中最常用的属性之一。</p> <br><pre><code class="language-css">p {<br>    font-size: 18px;<br>}<br></code></pre> <br><ul><li><code>px</code>（像素）是 CSS 中的<strong>绝对单位</strong></li><li>不同浏览器默认字体大小不一样，<strong>谷歌默认 16px</strong></li><li>建议给 <code>body</code> 统一指定大小，做到浏览器统一</li></ul> <br><pre><code class="language-css">body {<br>    font-size: 16px;<br>}<br></code></pre> <br><h4 id="1.4%20%E5%AD%97%E4%BD%93%E9%A3%8E%E6%A0%BC%20font-style" name="1.4%20%E5%AD%97%E4%BD%93%E9%A3%8E%E6%A0%BC%20font-style">1.4 字体风格 font-style</h4> <br><p>字体风格用于控制文字是否倾斜，从而表达强调或特殊语气。</p> <br><p>用来打开和关闭文本斜体。</p> <br><table><thead><tr><th>属性值</th><th>说明</th></tr></thead><tbody><tr><td><code>normal</code></td><td>普通字体（关闭斜体）</td></tr><tr><td><code>italic</code></td><td>斜体版本（如果可用）</td></tr></tbody></table> <br><p><strong>最常见用途</strong>：让 <code>em</code> 或 <code>i</code> 标签取消默认倾斜。</p> <br><pre><code class="language-css">em {<br>    font-style: normal;<br>}<br></code></pre> <br><h4 id="1.5%20%E5%AD%97%E4%BD%93%E7%B2%97%E7%BB%86%20font-weight" name="1.5%20%E5%AD%97%E4%BD%93%E7%B2%97%E7%BB%86%20font-weight">1.5 字体粗细 font-weight</h4> <br><p>字体粗细用于控制文字的厚重程度，是区分标题与正文、突出重点的常用手段。</p> <br><table><thead><tr><th>属性值</th><th>说明</th></tr></thead><tbody><tr><td><code>normal</code></td><td>正常粗细</td></tr><tr><td><code>bold</code></td><td>加粗</td></tr><tr><td><code>400</code></td><td>正常粗细（常用）</td></tr><tr><td><code>700</code></td><td>加粗（常用）</td></tr></tbody></table> <br><p>取值范围 100~900，常用 400 和 700。</p> <br><p><strong>使用场景</strong>：</p> <br><ol><li>很多标题默认加粗，用 CSS 取消加粗</li><li>部分文字需要加粗突出</li></ol> <br><pre><code class="language-css">h1 {<br>    font-weight: 400;  /* 取消标题加粗 */<br>}<br>p {<br>    font-weight: 700;  /* 加粗 */<br>}<br></code></pre> <br><h4 id="1.6%20%E5%AD%97%E4%BD%93%E8%A3%85%E9%A5%B0%20text-decoration" name="1.6%20%E5%AD%97%E4%BD%93%E8%A3%85%E9%A5%B0%20text-decoration">1.6 字体装饰 text-decoration</h4> <br><table><thead><tr><th>属性值</th><th>说明</th></tr></thead><tbody><tr><td><code>none</code></td><td>取消文本装饰</td></tr><tr><td><code>underline</code></td><td>下划线</td></tr><tr><td><code>overline</code></td><td>上划线</td></tr><tr><td><code>line-through</code></td><td>穿过文本的线（删除线）</td></tr></tbody></table> <br><p><strong>使用场景</strong>：</p> <br><ol><li>最常见：取消链接下划线</li><li>特殊情况：添加删除线</li></ol> <br><pre><code class="language-css">a {<br>    text-decoration: none;  /* 取消下划线 */<br>}<br>del {<br>    text-decoration: line-through;  /* 删除线 */<br>}<br></code></pre> <br><h4 id="1.7%20%E5%AD%97%E4%BD%93%E6%A0%B7%E5%BC%8F%E6%80%BB%E7%BB%93" name="1.7%20%E5%AD%97%E4%BD%93%E6%A0%B7%E5%BC%8F%E6%80%BB%E7%BB%93">1.7 字体样式总结</h4> <br><table><thead><tr><th>属性</th><th>描述</th><th>常见取值</th><th>示例</th></tr></thead><tbody><tr><td><code>color</code></td><td>设置文本颜色</td><td>颜色名称、十六进制、RGB、RGBA</td><td><code>color: #3366cc;</code></td></tr><tr><td><code>font-family</code></td><td>设置字体系列</td><td>无衬线字体等</td><td><code>font-family: "Microsoft YaHei", sans-serif;</code></td></tr><tr><td><code>font-size</code></td><td>设置文字大小</td><td>px</td><td><code>font-size: 16px;</code></td></tr><tr><td><code>font-style</code></td><td>设置文字样式</td><td><code>normal</code>、<code>italic</code></td><td><code>font-style: normal;</code></td></tr><tr><td><code>font-weight</code></td><td>设置文字粗细</td><td>数值 100~900、<code>normal</code>、<code>bold</code></td><td><code>font-weight: 700;</code></td></tr><tr><td><code>text-decoration</code></td><td>设置文字装饰</td><td><code>none</code>、<code>underline</code>、<code>overline</code>、<code>line-through</code></td><td><code>text-decoration: underline;</code></td></tr></tbody></table> <br><h3 id="%E4%BA%8C%E3%80%81%E6%96%87%E6%9C%AC%E5%B8%83%E5%B1%80%EF%BC%88Text%20Layout%EF%BC%89" name="%E4%BA%8C%E3%80%81%E6%96%87%E6%9C%AC%E5%B8%83%E5%B1%80%EF%BC%88Text%20Layout%EF%BC%89">二、文本布局（Text Layout）</h3> <br><table><thead><tr><th>属性</th><th>说明</th></tr></thead><tbody><tr><td><code>text-align</code></td><td>文本对齐</td></tr><tr><td><code>text-indent</code></td><td>首行缩进</td></tr><tr><td><code>letter-spacing</code></td><td>字符间距</td></tr><tr><td><code>line-height</code></td><td>行高</td></tr></tbody></table> <br><h4 id="2.1%20%E6%96%87%E6%9C%AC%E5%AF%B9%E9%BD%90%20text-align" name="2.1%20%E6%96%87%E6%9C%AC%E5%AF%B9%E9%BD%90%20text-align">2.1 文本对齐 text-align</h4> <br><p>控制文本在它所在的<strong>块级盒子</strong>内如何水平对齐。</p> <br><table><thead><tr><th>属性值</th><th>说明</th></tr></thead><tbody><tr><td><code>left</code></td><td>左对齐（默认）</td></tr><tr><td><code>right</code></td><td>右对齐</td></tr><tr><td><code>center</code></td><td>水平居中对齐</td></tr><tr><td><code>justify</code></td><td>两端对齐（自动改变字间距）</td></tr></tbody></table> <br><p><strong>使用场景</strong>：</p> <br><ol><li>文本/图片在盒子内水平对齐</li><li>文章文字两端对齐（如腾讯体育）</li></ol> <br><pre><code class="language-css">h1 {<br>    text-align: center;<br>}<br>p {<br>    text-align: justify;  /* 两端对齐 */<br>}<br></code></pre> <br><blockquote> <br> <p><strong>注意</strong>：<code>text-align</code> 仅对<strong>块级元素</strong>生效。</p> <br></blockquote> <br><h4 id="2.2%20%E9%A6%96%E8%A1%8C%E7%BC%A9%E8%BF%9B%20text-indent" name="2.2%20%E9%A6%96%E8%A1%8C%E7%BC%A9%E8%BF%9B%20text-indent">2.2 首行缩进 text-indent</h4> <br><p>设置块级元素中文本行前面空格（缩进）的长度。</p> <br><p><strong>使用场景</strong>：</p> <br><ol><li>段落首行缩进 2 个字</li><li>Logo 隐藏文字效果</li></ol> <br><pre><code class="language-css">p {<br>    text-indent: 2em;  /* 缩进 2 个汉字 */<br>}<br></code></pre> <br><blockquote> <br> <p><code>em</code> 是<strong>相对单位</strong>，1em 等于当前元素的字体大小。如果当前元素没有设置大小，则按照父元素文字大小。</p> <br></blockquote> <br><blockquote> <br> <p><strong>注意</strong>：<code>text-indent</code> 仅对<strong>块级元素</strong>生效。</p> <br></blockquote> <br><h4 id="2.3%20%E5%AD%97%E9%97%B4%E8%B7%9D%20letter-spacing" name="2.3%20%E5%AD%97%E9%97%B4%E8%B7%9D%20letter-spacing">2.3 字间距 letter-spacing</h4> <br><p>设置文本字符之间的间距。</p> <br><p><strong>使用场景</strong>：调整字与字之间距离，提升用户体验。</p> <br><pre><code class="language-css">p {<br>    letter-spacing: 2px;<br>}<br></code></pre> <br><blockquote> <br> <p>负值可使字符重叠（需谨慎使用）。</p> <br></blockquote> <br><h4 id="2.4%20%E8%A1%8C%E9%AB%98%20line-height" name="2.4%20%E8%A1%8C%E9%AB%98%20line-height">2.4 行高 line-height</h4> <br><p>设置文本每行之间的高度。</p> <br><p><strong>使用场景</strong>：</p> <br><ol><li>设置多行文本之间的上下间距</li><li><strong>让单行文本垂直居中</strong></li></ol> <br><table><thead><tr><th>属性值</th><th>说明</th></tr></thead><tbody><tr><td><code>数字px</code></td><td>固定像素值</td></tr><tr><td><code>数字不带单位</code></td><td>当前字体大小的倍数</td></tr></tbody></table> <br><pre><code class="language-css">p {<br>    line-height: 25px;   /* 固定行高 */<br>    line-height: 1.5;    /* 当前字体大小的 1.5 倍 */<br>}<br></code></pre> <br><p><strong>核心技巧：单行文本垂直居中</strong></p> <br><p>行高 = 盒子高度 → 单行文字垂直居中</p> <br><pre><code class="language-css">.box {<br>    height: 40px;<br>    line-height: 40px;  /* 行高等于盒子高度 */<br>}<br></code></pre> <br><h4 id="2.5%20%E6%96%87%E6%9C%AC%E5%B8%83%E5%B1%80%E6%80%BB%E7%BB%93" name="2.5%20%E6%96%87%E6%9C%AC%E5%B8%83%E5%B1%80%E6%80%BB%E7%BB%93">2.5 文本布局总结</h4> <br><table><thead><tr><th>属性</th><th>作用</th><th>核心取值</th><th>注意事项</th><th>示例</th></tr></thead><tbody><tr><td><code>text-align</code></td><td>水平对齐方式</td><td><code>left</code>、<code>right</code>、<code>center</code>、<code>justify</code></td><td>仅对块级元素生效</td><td><code>p {text-align: center;}</code></td></tr><tr><td><code>text-indent</code></td><td>首行缩进量</td><td>长度值（<code>20px</code>、<code>2em</code>）</td><td>仅对块级元素生效</td><td><code>p {text-indent: 2em;}</code></td></tr><tr><td><code>letter-spacing</code></td><td>字符间距</td><td>数值</td><td>负值可使字符重叠</td><td><code>h1 {letter-spacing: 2px;}</code></td></tr><tr><td><code>line-height</code></td><td>行与行之间的垂直间距</td><td>像素或倍数</td><td>行高=高度，单行垂直居中</td><td><code>p {line-height: 1.6;}</code></td></tr></tbody></table> <br><h3 id="%E4%B8%89%E3%80%81font%20%E7%AE%80%E5%86%99" name="%E4%B8%89%E3%80%81font%20%E7%AE%80%E5%86%99">三、font 简写</h3> <br><p><code>font</code> 简写属性可以在一个声明中设置多个字体属性。</p> <br><p><strong>使用场景</strong>：给整个页面设置相关字体样式。</p> <br><pre><code class="language-css">/* 小米官网写法 */<br>body {<br>    font: 14px/1.5 Helvetica Neue, Helvetica, Arial, Microsoft Yahei, Hiragino Sans GB, Heiti SC, WenQuanYi Micro Hei, sans-serif;<br>    color: #333;<br>}<br>/* 京东官网写法 */<br>body {<br>    font: 12px/1.5 PingFang SC, Source Han Sans CN, Microsoft YaHei, Heiti SC, tahoma, arial, Hiragino Sans GB, sans-serif;<br>    color: #666;<br>}<br><br></code></pre> <br><p><strong>语法格式</strong>：</p> <br><pre><code class="language-css">font: [font-style font-variant font-weight]?  font-size  [/line-height]?  font-family<br>         ↑ 可选，且应在 size 之前              ↑必填        ↑可选        ↑必填<br>> 实际开发中，直接复制大厂的字体设置即可。<br></code></pre> <br><h3 id="%E5%9B%9B%E3%80%81CSS%20%E7%BB%A7%E6%89%BF%E6%80%A7" name="%E5%9B%9B%E3%80%81CSS%20%E7%BB%A7%E6%89%BF%E6%80%A7">四、CSS 继承性</h3> <br><p><strong>子元素自动继承父元素的某些 CSS 样式属性。</strong></p> <br><ul><li>主要继承跟<strong>文字相关</strong>的样式属性：字体、颜色、文本对齐等</li><li>但如果子元素自己定义了样式，会<strong>优先使用自己的样式</strong></li></ul> <br><pre><code class="language-css">/* 父元素设置 */<br>body {<br>    font-size: 16px;<br>    color: #333;<br>    text-align: center;<br>}<br>/* 子元素 p 自动继承这些样式，但如果 p 自己定义了 color，则用自己的 */<br>p {<br>    color: red;  /* 覆盖继承的 color: #333 */<br>}<br></code></pre> <br><blockquote> <br> <p><strong>特殊情况</strong>：<code>h</code> 标签默认加粗，<code>a</code> 标签默认有下划线，这些<strong>不能通过继承性修改父级来实现取消</strong>，需要单独指定 <code>h</code> 和 <code>a</code> 的样式。</p> <br></blockquote>
