id="%E7%AC%AC3%E5%B1%82%20.item%20%E2%80%94%E2%80%94%20%E6%A0%85%E6%A0%BC%E6%A0%BC%E5%AD%90%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89-toc" name="tableOfContents" style="margin-left:80px"><a 栅格格子（重点）</a></p> <br><p id="%E7%AC%AC4%E5%B1%82%20.content%20%E2%80%94%E2%80%94%20%E5%8D%A1%E7%89%87-toc" name="tableOfContents" style="margin-left:80px"><a name="tableOfContents" style="margin-left:40px"><a rel="noopener noreferrer">三、核心技巧：负 margin 为什么能让首尾贴齐？</a></p> <br><hr id="hr-toc" name="tableOfContents" /> <br><p></p> <br><p>写这段代码之前，我们先需要理清楚需求。要做的是淘宝首页那种<strong>多行商品卡片墙</strong>，核心就一个诉求：<strong>每行卡片之间有统一缝隙，但首尾卡片要贴齐版心边缘</strong>。</p> <br><p class="img-center"><img alt="" height="518" src="https://i-blog.csdnimg.cn/direct/251aee78a6a940fb8fe2954cc685fc0b.png" width="700" /></p> <br><p>下面按<strong>真实的写代码顺序</strong>来还原：</p> <br><h4 id="%E7%AC%AC%E4%B8%80%E6%AD%A5%EF%BC%9A%E5%85%88%E5%86%99%20HTML" name="%E7%AC%AC%E4%B8%80%E6%AD%A5%EF%BC%9A%E5%85%88%E5%86%99%20HTML" style="background-color:transparent">第一步：先写 HTML</h4> <br><p>先把盒子和格子写出来。于是有了 <code>.box</code>（容器）和 <code>.item</code>（格子），先写 若干个 item 占位。</p> <br><pre><code class="language-html"><div class="box"><br>  <div class="item">1</div><br>  <div class="item">2</div><br>  <div class="item">3</div><br>  <!-- ... 14 个 item --><br></div></code></pre> <br><h4 id="%E7%AC%AC%E4%BA%8C%E6%AD%A5%EF%BC%9A%E7%BB%99%20.box%20%E5%86%99%20CSS%EF%BC%8C%E8%AE%A9%E5%AE%83%E6%A8%AA%E6%8E%92%20%2B%20%E6%8D%A2%E8%A1%8C" name="%E7%AC%AC%E4%BA%8C%E6%AD%A5%EF%BC%9A%E7%BB%99%20.box%20%E5%86%99%20CSS%EF%BC%8C%E8%AE%A9%E5%AE%83%E6%A8%AA%E6%8E%92%20%2B%20%E6%8D%A2%E8%A1%8C">第二步：给 .box 写 CSS，让它横排 + 换行</h4> <br><p>这里的关键是让 <code>.box</code> 里的格子横向排列，放不下时自动换行。</p> <br><blockquote> <br> <p>注意：<code>flex-wrap: wrap</code> 只是<strong>允许</strong>换行，真正会不会换行，取决于 item 的宽度基准。</p> <br></blockquote> <br><pre><code class="language-css">.box {<br>  display: flex;      /* 横着排 */<br>  flex-wrap: wrap;    /* 放不下就换行 */<br>}</code></pre> <br><h4 id="%E7%AC%AC%E4%B8%89%E6%AD%A5%EF%BC%9A%E7%BB%99%20.item%20%E5%86%99%20CSS%EF%BC%8C%E5%85%88%E5%86%99%20flex%3A%201%EF%BC%8C%E6%88%91%E4%BB%AC%E5%8F%91%E7%8E%B0%E9%97%AE%E9%A2%98" name="%E7%AC%AC%E4%B8%89%E6%AD%A5%EF%BC%9A%E7%BB%99%20.item%20%E5%86%99%20CSS%EF%BC%8C%E5%85%88%E5%86%99%20flex%3A%201%EF%BC%8C%E6%88%91%E4%BB%AC%E5%8F%91%E7%8E%B0%E9%97%AE%E9%A2%98">第三步：给 .item 写 CSS，先写 flex: 1，我们发现问题</h4> <br><p>如果 <code>.item</code> 里写 <code>flex: 1</code>，格子仍然会挤在一行不换行。</p> <br><p>为什么？</p> <br><p>因为 <code>flex: 1</code> 是 <code>flex: 1 1 0%</code> 的缩写，<code>flex-basis</code> 是 0。</p> <br><p>关键在换行判定发生在拉伸之前：浏览器先按每个格子的<strong>基准宽度（flex-basis）</strong>判断一行放不放得下——<code>flex-basis: 0%</code> 意味着每个格子基准宽度算 0，14 个格子加起来还是 0，浏览器判定"一行完全放得下"，于是全部排进同一行；之后 <code>flex-grow: 1</code> 才把整行空间平分拉满。所以换行永远不会触发。</p> <br><pre><code class="language-css">.item {<br>  flex: 1;   /* 等价于 flex: 1 1 0%，basis 为 0 → 总宽 0 → 永不换行，grow 再拉满整行 */<br>}</code></pre> <br><h4 id="%E7%AC%AC%E5%9B%9B%E6%AD%A5%EF%BC%9A%E6%94%B9%E6%88%90%20flex%3A%200%200%2016.66666%25%EF%BC%8C%E8%BF%99%E6%89%8D%E6%8D%A2%E8%A1%8C" name="%E7%AC%AC%E5%9B%9B%E6%AD%A5%EF%BC%9A%E6%94%B9%E6%88%90%20flex%3A%200%200%2016.66666%25%EF%BC%8C%E8%BF%99%E6%89%8D%E6%8D%A2%E8%A1%8C">第四步：改成 flex: 0 0 16.66666%，这才换行</h4> <br><p>这是淘宝布局的关键：<code>flex</code> 三个值分别是 <code>flex-grow</code>、<code>flex-shrink</code>、<code>flex-basis</code>，基准值相对于父亲的百分比。写死 <code>flex-basis: 16.66666%</code>（1/6），6 个格子基准之和 = 100%，第 7 个超出一行，才会掉行。</p> <br><blockquote> <br> <p><strong>换行看的是 basis 之和超不超 100%，跟 grow/shrink 无关——</strong>这里不采用固定像素宽度（比如 80px），因为固定像素无法随容器自适应拉伸，必须用百分比基准，因此这里必须用百分比基准。</p> <br></blockquote> <br><pre><code class="language-css">.item {<br>  /* flex 三个值：flex-grow flex-shrink flex-basis（基准值，相对父亲的百分比） */<br>  flex: 0 0 16.66666%;   /* 6 个格子 basis 之和 = 100%，第 7 个超一行 → 换行 */<br>  height: 120px;<br>}</code></pre> <br><h4 id="%E7%AC%AC%E4%BA%94%E6%AD%A5%EF%BC%9A%E5%8F%91%E7%8E%B0%E5%8D%A1%E7%89%87%E9%A1%B6%E6%BB%A1%E5%B1%8F%E5%B9%95%E4%BA%86" name="%E7%AC%AC%E4%BA%94%E6%AD%A5%EF%BC%9A%E5%8F%91%E7%8E%B0%E5%8D%A1%E7%89%87%E9%A1%B6%E6%BB%A1%E5%B1%8F%E5%B9%95%E4%BA%86">第五步：发现卡片顶满屏幕了</h4> <br><p>页面内容不能顶满整个浏览器宽度，得有个"版心"把内容框在中间、限个宽度。于是外面再套一层 <code>.w</code>，负责"整体居中、限宽"。如果只在 <code>.box</code> 上加 margin，无法保证左右对齐，所以额外套一个 <code>.w</code> 盒子，确保内容在版心内移动。</p> <br><pre><code class="language-html"><div class="w"><br>  <div class="box"><br>    <div class="item">1</div><br>    <div class="item">2</div><br>    <!-- ... 14 个 item --><br>  </div><br></div></code></pre> <br><pre><code class="language-css">.w {<br>  width: 80%;<br>  margin: 20px auto;<br>}</code></pre> <br><h4 id="%E7%AC%AC%E5%85%AD%E6%AD%A5%EF%BC%9A%E5%8F%91%E7%8E%B0%E7%BC%9D%E9%9A%99%E5%92%8C%E8%83%8C%E6%99%AF%E9%94%99%E4%BD%8D" name="%E7%AC%AC%E5%85%AD%E6%AD%A5%EF%BC%9A%E5%8F%91%E7%8E%B0%E7%BC%9D%E9%9A%99%E5%92%8C%E8%83%8C%E6%99%AF%E9%94%99%E4%BD%8D">第六步：发现缝隙和背景错位</h4> <br><p>卡片之间需要有 16px 的缝，这是设计稿上和商品页需要的间距数据。</p> <br><p>第一反应是给每个格子加右外边距：</p> <br><pre><code class="language-css">.item {<br>  margin-right: 16px;   /* 想让卡片之间空 16px，先试试 margin */<br>}</code></pre> <br><p>刷新一看，第 6 个格子被挤到第二行了。因为 margin 控制盒子<strong>外面</strong>，第 6 个格子算上自己的 16px 右边距，总宽度超了一行。想留住就得写 <code>.item:nth-child(6n) { margin-right: 0 }</code> 把每行最后一个的边距清掉——但是新的问题出现：换行后每行的第六位还会变，非常难以优雅控制。</p> <br><p>那就换 padding，padding 可以在盒子内部增加距离：</p> <br><pre><code class="language-css">.item {<br>  padding: 0 8px;<br>}</code></pre> <br><p>左边卡片让出 8px、右边卡片让出 8px，拼起来正好是 16px。</p> <br><p>刷新：缝呢？？粉色还是糊成一片。</p> <br><p>背景色在 item 上，而 padding 区也是 item 的一部分，背景色体现不出留白。</p> <br><p>这才发现 item 一个盒子无法完成同时用 padding 留白，同时保证背景颜色。于是我们就拆成两层，各司其职：<code>.item</code> 只管站位和留白；<code>.content</code> 套在 item 里面，背景在它身上。</p> <br><blockquote> <br> <p>注意：<code>padding: 0 8px</code> 处理，靠开头重置里的 <code>box-sizing: border-box</code> 来控制。</p> <br></blockquote> <br><pre><code class="language-html"><div class="w"><br>  <div class="box"><br>    <div class="item"><br>      <div class="content">1</div><br>    </div><br>    <div class="item"><br>      <div class="content">2</div><br>    </div><br>    <!-- ... 14 个 item --><br>  </div><br></div></code></pre> <br><pre><code class="language-css">.item {<br>  flex: 0 0 16.66666%;<br>  height: 120px;<br>  margin-bottom: 16px;   /* 行间距 */<br>  padding: 0 8px;        /* 左右各 8px = 槽宽的一半 */<br>}<br><br>.item .content {<br>  width: 100%;<br>  height: 100%;<br>  background-color: pink;   /* 背景画在 content 上，缝隙才露得出来 */<br>}</code></pre> <br><h4 id="%E7%AC%AC%E4%B8%83%E6%AD%A5%E4%B9%8B%E5%89%8D%EF%BC%9A%E8%AE%BE%E7%BD%AE%E4%B8%80%E4%B8%AA%20footer%20%E6%9D%A5%E8%A7%82%E6%B5%8B%E6%98%AF%E5%90%A6%E4%B8%8E%E4%B8%8B%E9%9D%A2%E9%A1%B5%E9%9D%A2%E5%AF%B9%E9%BD%90" name="%E7%AC%AC%E4%B8%83%E6%AD%A5%E4%B9%8B%E5%89%8D%EF%BC%9A%E8%AE%BE%E7%BD%AE%E4%B8%80%E4%B8%AA%20footer%20%E6%9D%A5%E8%A7%82%E6%B5%8B%E6%98%AF%E5%90%A6%E4%B8%8E%E4%B8%8B%E9%9D%A2%E9%A1%B5%E9%9D%A2%E5%AF%B9%E9%BD%90" style="background-color:transparent">第七步之前：设置一个 footer 来观测是否与下面页面对齐</h4> <br><pre><code class="language-html"><div class="footer"></div></code></pre> <br><pre><code class="language-css">.footer {<br>  width: 80%;<br>  height: 20px;<br>  margin: 0 auto;<br>  background-color: #ccc;<br>}</code></pre> <br><h4 id="%E7%AC%AC%E4%B8%83%E6%AD%A5%EF%BC%9A%E5%8F%91%E7%8E%B0%E9%A6%96%E5%B0%BE%E5%AF%B9%E4%B8%8D%E9%BD%90%EF%BC%8C%E7%94%A8%E8%B4%9F%20margin%20%E4%BF%AE%E6%AD%A3" name="%E7%AC%AC%E4%B8%83%E6%AD%A5%EF%BC%9A%E5%8F%91%E7%8E%B0%E9%A6%96%E5%B0%BE%E5%AF%B9%E4%B8%8D%E9%BD%90%EF%BC%8C%E7%94%A8%E8%B4%9F%20margin%20%E4%BF%AE%E6%AD%A3" style="background-color:transparent">第七步：发现首尾对不齐，用负 margin 修正</h4> <br><p>因为每个 item 有 <code>padding: 0 8px</code>，第一个 item 的卡片会缩进 8px，和版心对不齐。于是给 <code>.box</code> 加 <code>margin: 0 -8px</code>，向左右各外扩 8px，抵消首尾的内边距。这是负 margin 在栅格布局中的核心应用。</p> <br><blockquote> <br> <p>注意前提：<code>margin: 0 -8px</code> 能成立，是因为 <code>.w</code> 只占 80% 宽、两侧有大量空余，外扩 8px 不会顶到屏幕边；如果版心是 100% 宽，负 margin 会让内容超出视口、可能出现横向滚动条。</p> <br></blockquote> <br><pre><code class="language-css">.box {<br>  display: flex;<br>  flex-wrap: wrap;<br>  margin-left: -8px;    /* 负边距：抵消首尾 item 的 padding */<br>  margin-right: -8px;<br>}</code></pre> <br><p>所以最终结构出现：</p> <br><pre><code class="language-html"><div class="w">              <!-- 第1层：版心，负责"整体居中、限宽" --><br>  <div class="box">          <!-- 第2层：flex容器，负责"横排+换行" --><br>    <div class="item">       <!-- 第3层：栅格格子，负责"占多宽、留缝隙" --><br>      <div class="content">1</div>  <!-- 第4层：真正可见的卡片 --><br>    </div><br>    ... 14 个 item<br>  </div><br></div><br><div class="footer"></div>   <!-- 底部灰色条，用来验证对齐 --></code></pre> <br><p>顺序就是：<strong>版心(w) → 弹性盒(box) → 格子(item) → 卡片(content)</strong>。下面按这个思路，一层一层讲每一层到底在解决什么问题。</p> <br><h3 id="%E4%BA%8C%E3%80%81%E9%80%90%E5%B1%82%E5%88%86%E6%9E%90" name="%E4%BA%8C%E3%80%81%E9%80%90%E5%B1%82%E5%88%86%E6%9E%90">二、逐层分析</h3> <br><h4 id="%E7%AC%AC1%E5%B1%82%20.w%20%E2%80%94%E2%80%94%20%E7%89%88%E5%BF%83" name="%E7%AC%AC1%E5%B1%82%20.w%20%E2%80%94%E2%80%94%20%E7%89%88%E5%BF%83">第1层 .w —— 版心</h4> <br><pre><code class="language-css">.w {<br>  width: 80%;<br>  margin: 20px auto;<br>}</code></pre> <br><p>页面内容不顶满屏幕，而是占 80% 宽、左右居中（<code>margin: auto</code>），这就是"版心"。注意它<strong>没有 padding</strong>，对齐问题全部交给下一层处理。</p> <br><h4 id="%E7%AC%AC2%E5%B1%82%20.box%20%E2%80%94%E2%80%94%20flex%20%E5%AE%B9%E5%99%A8" name="%E7%AC%AC2%E5%B1%82%20.box%20%E2%80%94%E2%80%94%20flex%20%E5%AE%B9%E5%99%A8">第2层 .box —— flex 容器</h4> <br><pre><code class="language-css">.box {<br>  display: flex;<br>  flex-wrap: wrap;          /* 关键①：允许换行 */<br>  margin-left: -8px;        /* 关键②：负边距 */<br>  margin-right: -8px;<br>}</code></pre> <br><ul><li><code>flex-wrap: wrap</code>：一行放不下就掉到第二行。没有这句，14 个格子塞在一行；</li><li><code>margin: 0 -8px</code>：向左右各"伸出"8px，作用是抵消首尾格子的内边距。</li></ul> <br><h4 id="%E7%AC%AC3%E5%B1%82%20.item%20%E2%80%94%E2%80%94%20%E6%A0%85%E6%A0%BC%E6%A0%BC%E5%AD%90%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89" name="%E7%AC%AC3%E5%B1%82%20.item%20%E2%80%94%E2%80%94%20%E6%A0%85%E6%A0%BC%E6%A0%BC%E5%AD%90%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89">第3层 .item —— 栅格格子（重点）</h4> <br><pre><code class="language-css">.item {<br>  flex: 0 0 16.66666%;      /* 关键：每个格子占 1/6 宽，一行 6 个 */<br>  height: 120px;<br>  margin-bottom: 16px;      /* 行与行之间的间距 */<br>  padding: 0 8px;           /* 左右各 8px 内边距 = 槽宽的一半 */<br>}</code></pre> <br><p><strong><code>flex: 0 0 16.66666%</code> 三个数的含义</strong>：</p> <br><ul><li><code>flex-grow: 0</code>——不拉伸；</li><li><code>flex-shrink: 0</code>——不收缩（挤不下直接换行）；</li><li><code>flex-basis: 16.66666%</code>——基准宽度 = 父盒子的 1/6（100 ÷ 6）。</li></ul> <br><p>三个数合起来：<strong>每个格子严格占 1/6 宽</strong>，第 7 个自动掉行。</p> <br><p><strong><code>padding: 0 8px</code> 是缝隙的来源</strong>：格子本身不画背景，左右各留 8px 内边距，相邻两个格子的 padding 拼起来 = 16px 缝隙。</p> <br><p><strong><code>margin-bottom: 16px</code></strong>：制造行间距（老写法，现在可以用 <code>row-gap: 16px</code> 替代）。</p> <br><h4 id="%E7%AC%AC4%E5%B1%82%20.content%20%E2%80%94%E2%80%94%20%E5%8D%A1%E7%89%87" name="%E7%AC%AC4%E5%B1%82%20.content%20%E2%80%94%E2%80%94%20%E5%8D%A1%E7%89%87">第4层 .content —— 卡片</h4> <br><pre><code class="language-css">.item .content {<br>  width: 100%;<br>  height: 100%;<br>  background-color: pink;<br>}</code></pre> <br><p>item 的 padding 区域没有背景色，缝隙才能露出来。</p> <br><h3 id="%E4%B8%89%E3%80%81%E6%A0%B8%E5%BF%83%E6%8A%80%E5%B7%A7%EF%BC%9A%E8%B4%9F%20margin%20%E4%B8%BA%E4%BB%80%E4%B9%88%E8%83%BD%E8%AE%A9%E9%A6%96%E5%B0%BE%E8%B4%B4%E9%BD%90%EF%BC%9F" name="%E4%B8%89%E3%80%81%E6%A0%B8%E5%BF%83%E6%8A%80%E5%B7%A7%EF%BC%9A%E8%B4%9F%20margin%20%E4%B8%BA%E4%BB%80%E4%B9%88%E8%83%BD%E8%AE%A9%E9%A6%96%E5%B0%BE%E8%B4%B4%E9%BD%90%EF%BC%9F" style="background-color:transparent">三、核心技巧：负 margin 为什么能让首尾贴齐？</h3> <br><p>假设版心 <code>.w</code> 宽 600px：</p> <br><p><strong>加上 <code>margin: 0 -8px</code> 后：</strong></p> <br><ul><li><code>.box</code> 向左右各外扩 8px，可用宽度变成 616px；</li><li>第一个 item 从外扩后的起点开始排，它的 <code>padding-left: 8px</code> 刚好把卡片推回到版心边缘</li><li>右边同理。</li></ul> <br><p>而中间的缝隙不受影响：相邻格子之间仍然是 8px + 8px = 16px。</p> <br><p><strong>padding 负责中间有缝，负 margin 负责首尾对齐</strong>，两个配合实现栅格布局。</p>
