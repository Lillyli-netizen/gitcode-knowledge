<br><p><strong>作用</strong>：重复执行一段代码。</p> <br><p><strong>优点</strong>：把变量初始化、循环条件、变量更新三部分集中写在圆括号内，结构清晰、一目了然，是最常用的循环形式。</p> <br><h5 id="1.1.1%20%E8%AF%AD%E6%B3%95%E4%B8%8E%E6%89%A7%E8%A1%8C%E6%B5%81%E7%A8%8B" name="1.1.1%20%E8%AF%AD%E6%B3%95%E4%B8%8E%E6%89%A7%E8%A1%8C%E6%B5%81%E7%A8%8B">1.1.1 语法与执行流程</h5> <br><pre><code class="language-javascript">for (变量起始值; 终止条件; 变量变化量) {<br>    // 循环体<br>}<br></code></pre> <br><p><strong>执行流程</strong>：</p> <br><ol><li>执行变量起始值（初始化），<strong>整个循环过程中只执行一次</strong>；</li><li>判断循环条件：满足（true）则继续，不满足（false）则退出循环；</li><li>执行循环体；</li><li>执行变量变化量（如 <code>i++</code>），然后回到第 2 步继续判断，如此反复。</li></ol> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">for (let i = 1; i <= 3; i++) {<br>    document.write('我会循环三次<br>');<br>}<br></code></pre> <br><p>注意：<strong><code>let i = 1</code> 只在循环开始时执行一次</strong>；如果把声明写在循环体内，每次循环都会执行到，属于重复声明，不符合语法规范。</p> <br><h5 id="1.1.2%20for%20%E5%BE%AA%E7%8E%AF%E7%BB%83%E4%B9%A0" name="1.1.2%20for%20%E5%BE%AA%E7%8E%AF%E7%BB%83%E4%B9%A0">1.1.2 for 循环练习</h5> <br><p><strong>练习 1</strong>：利用 for 循环输出 1~100 岁</p> <br><pre><code class="language-javascript">for (let i = 1; i <= 100; i++) {<br>    document.write(`${i}岁<br>`);<br>}<br></code></pre> <br><p><strong>练习 2</strong>：求 1~100 之间所有偶数的和</p> <br><pre><code class="language-javascript">let sum = 0;<br>for (let i = 1; i <= 100; i++) {<br>    if (i % 2 === 0) {<br>        sum += i;<br>    }<br>}<br>console.log(sum); // 2550<br></code></pre> <br><p><strong>注意</strong>：累加变量必须<strong>先声明并初始化为 0</strong>。如果未声明就直接写 <code>sum += i</code>，变量的值是 undefined，参与运算会得到 NaN，还可能导致脚本报错中断。</p> <br><p><strong>拓展</strong>：一次循环同时求出奇数和与偶数和（三元表达式写法）：</p> <br><pre><code class="language-javascript"><script><br>    let even = 0; // 偶数和<br>    let odd = 0;  // 奇数和<br>    for (let i = 1; i <= 100; i++) {<br>        even += i % 2 === 0 ? i : 0;<br>        odd += i % 2 === 1 ? i : 0;<br>    }<br>    document.write(`1-100之间的偶数和为：${even}<br>`);<br>    document.write(`1-100之间的奇数和为：${odd}`);<br></script><br></code></pre> <br><p>知识点：<code>i % 2 === 0 ? i : 0</code> 是三元表达式——条件成立取 <code>i</code>，不成立取 <code>0</code>，相当于简化的 if 判断累加。</p> <br><p><strong>练习 3</strong>：页面中打印 5 个小星星 ★★★★★</p> <br><pre><code class="language-javascript">for (let i = 1; i <= 5; i++) {<br>    document.write('★');<br>}<br></code></pre> <br><p><strong>练习 4</strong>：for 循环的最大价值 —— 遍历数组</p> <br><p><strong>需求</strong>：请将数组 <code>['马超', '赵云', '张飞', '关羽', '黄忠']</code> 依次打印出来。</p> <br><pre><code class="language-javascript">let arr = ['马超', '赵云', '张飞', '关羽', '黄忠'];<br>for (let i = 0; i < arr.length; i++) {<br>    document.write(arr[i] + '<br>');<br>}<br></code></pre> <br><p><strong>知识点</strong>：</p> <br><ul><li>数组下标从 0 开始，所以循环变量 <code>i</code> 必须从 0 开始；</li><li>最后一个元素的下标是 <code>arr.length - 1</code>，因此循环条件写成 <code>i < arr.length</code>；</li><li>用循环依次访问数组中每一个元素的过程，称为<strong>遍历数组</strong>。</li></ul> <br><h5 id="1.1.3%20%E9%80%80%E5%87%BA%E5%BE%AA%E7%8E%AF" name="1.1.3%20%E9%80%80%E5%87%BA%E5%BE%AA%E7%8E%AF">1.1.3 退出循环</h5> <br><table><thead><tr><th>关键字</th><th>作用</th><th>使用场景</th></tr></thead><tbody><tr><td><code>continue</code></td><td>跳过本次循环中剩余的语句，直接进入变量更新，开始下一次循环</td><td>一般用于排除或跳过某个特定值</td></tr><tr><td><code>break</code></td><td>立即退出整个 for 循环</td><td>一般用于结果已经得到，后续循环不需要再执行</td></tr></tbody></table> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript"><script><br>    // continue：跳过本次循环，输出 1、2、4、5<br>    for (let i = 1; i <= 5; i++) {<br>        if (i === 3) {<br>            continue; // 跳过本次循环剩余语句，直接进入 i++，开始下一次循环<br>        }<br>        document.write(i + '<br>');<br>    }<br></script><br></code></pre> <br><pre><code class="language-javascript"><script><br>    // break：退出整个循环，输出 1、2<br>    for (let i = 1; i <= 5; i++) {<br>        if (i === 3) {<br>            break; // 立即结束整个循环<br>        }<br>        document.write(i + '<br>');<br>    }<br></script><br></code></pre> <br><p><strong>了解</strong>：</p> <br><ol><li><code>while (true)</code> 可以构造无限循环，需要配合 <code>break</code> 退出循环；</li><li><code>for(;;)</code> 同样可以构造无限循环，也需要配合 <code>break</code> 退出循环。</li></ol> <br><h5 id="1.1.4%20for%20%E5%BE%AA%E7%8E%AF%E5%92%8C%20while%20%E5%BE%AA%E7%8E%AF%E7%9A%84%E5%8C%BA%E5%88%AB" name="1.1.4%20for%20%E5%BE%AA%E7%8E%AF%E5%92%8C%20while%20%E5%BE%AA%E7%8E%AF%E7%9A%84%E5%8C%BA%E5%88%AB">1.1.4 for 循环和 while 循环的区别</h5> <br><table><thead><tr><th>循环类型</th><th>适用场景</th></tr></thead><tbody><tr><td><strong>for 循环</strong></td><td>循环次数<strong>明确</strong>时推荐使用</td></tr><tr><td><strong>while 循环</strong></td><td>循环次数<strong>不明确</strong>时推荐使用</td></tr></tbody></table> <br><h4 id="1.2%20for%20%E5%BE%AA%E7%8E%AF%E5%B5%8C%E5%A5%97" name="1.2%20for%20%E5%BE%AA%E7%8E%AF%E5%B5%8C%E5%A5%97">1.2 for 循环嵌套</h4> <br><h5 id="1.2.1%20%E5%B5%8C%E5%A5%97%E8%AF%AD%E6%B3%95" name="1.2.1%20%E5%B5%8C%E5%A5%97%E8%AF%AD%E6%B3%95">1.2.1 嵌套语法</h5> <br><pre><code class="language-javascript">for (外层变量初始化; 循环条件; 变量更新) {<br>    for (内层变量初始化; 循环条件; 变量更新) {<br>        // 循环体<br>    }<br>}<br></code></pre> <br><p>执行特点：外层循环执行<strong>一次</strong>，内层循环完整执行<strong>一轮</strong>。</p> <br><h5 <br><p><strong>拆解</strong>：外层循环表示"第几天"，内层循环表示"当天记住的第几个单词"，即 3 天 × 每天 5 个。</p> <br><pre><code class="language-javascript"><script><br>    for (let i = 1; i <= 3; i++) {<br> 2</strong>：打印三角形星星（第一行 1 个星，第二行 2 个星，以此类推）</p> <br><p><strong>分析</strong>：</p> <br><ol><li>使用双重 for 循环；</li><li>外层循环控制行数，内层循环控制每行星星的个数；</li><li>内层循环的次数与行号一一对应：第 i 行打印 i 个星。</li></ol> <br><pre><code name="%E4%BA%8C%E3%80%81%E6%95%B0%E7%BB%84">二、数组</h3> <br><h4 id="2.1%20%E6%95%B0%E7%BB%84%E6%98%AF%E4%BB%80%E4%B9%88" name="2.1%20%E6%95%B0%E7%BB%84%E6%98%AF%E4%BB%80%E4%B9%88">2.1 数组是什么</h4> <br><p><strong>数组（Array）</strong> 是一种可以按顺序保存多个数据的数据类型。</p> <br><p><strong>为什么需要数组</strong>：要保存一个班里所有同学的姓名，如果每个名字都单独声明一个变量会非常繁琐；把多个数据保存到一个数组里，用一个变量统一管理，非常方便。</p> <br><h4 id="2.2%20%E6%95%B0%E7%BB%84%E7%9A%84%E5%9F%BA%E6%9C%AC%E4%BD%BF%E7%94%A8" name="2.2%20%E6%95%B0%E7%BB%84%E7%9A%84%E5%9F%BA%E6%9C%AC%E4%BD%BF%E7%94%A8">2.2 数组的基本使用</h4> <br><h5 id="2.2.1%20%E5%A3%B0%E6%98%8E%E8%AF%AD%E6%B3%95" name="2.2.1%20%E5%A3%B0%E6%98%8E%E8%AF%AD%E6%B3%95">2.2.1 声明语法</h5> <br><pre><code class="language-javascript">// 字面量方式（推荐）<br>let 数组名 = [数据1, 数据2, ..., 数据n];<br><br>// 构造函数方式<br>let arr = new Array(数据1, 数据2, ..., 数据n);<br></code></pre> <br><p><strong>知识点（什么是构造函数）</strong>：</p> <br><ul><li><code>Array</code> 是 JavaScript 内置的构造函数，通过 <code>new Array(...)</code> 可以创建一个数组对象；</li><li>构造函数首字母约定大写，配合 <code>new</code> 关键字调用，用来"批量创建"同类对象；</li><li>日常开发推荐使用字面量 <code>[]</code> 写法，更简洁；</li><li>易错点：<code>new Array(3)</code> 只传一个数字时，创建的是<strong>长度为 3 的空数组</strong>，而不是包含元素 3 的数组。</li></ul> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">let names = ['小明', '小刚', '小红', '小丽', '小米'];<br></code></pre> <br><p><strong>要点</strong>：</p> <br><ul><li>数组按顺序保存，每个数据都有自己的编号；</li><li>编号从 0 开始：小明编号 0，小刚编号 1，以此类推；</li><li>数据的编号称为<strong>索引（下标）</strong>；</li><li>数组可以存储任意类型的数据。</li></ul> <br><h5 id="2.2.2%20%E5%8F%96%E5%80%BC%E8%AF%AD%E6%B3%95" name="2.2.2%20%E5%8F%96%E5%80%BC%E8%AF%AD%E6%B3%95">2.2.2 取值语法</h5> <br><pre><code class="language-javascript">数组名[下标]<br></code></pre> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">let names = ['小明', '小刚', '小红', '小丽', '小米'];<br>console.log(names[0]); // 小明<br>console.log(names[1]); // 小刚<br></code></pre> <br><p>取出的元素是什么类型，就按该类型的特点使用；访问不存在的下标会返回 <code>undefined</code>。</p> <br><h5 id="2.2.3%20%E4%B8%80%E4%BA%9B%E6%9C%AF%E8%AF%AD" name="2.2.3%20%E4%B8%80%E4%BA%9B%E6%9C%AF%E8%AF%AD">2.2.3 一些术语</h5> <br><table><thead><tr><th>术语</th><th>说明</th></tr></thead><tbody><tr><td><strong>元素</strong></td><td>数组中保存的每个数据</td></tr><tr><td><strong>下标（索引）</strong></td><td>数组中数据的编号，从 0 开始</td></tr><tr><td><strong>长度</strong></td><td>数组中元素的个数，通过 <code>length</code> 属性获得</td></tr></tbody></table> <br><pre><code class="language-javascript">let names = ['小明', '小刚', '小红', '小丽', id="2.2.4%20%E9%81%8D%E5%8E%86%E6%95%B0%E7%BB%84%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89" name="2.2.4%20%E9%81%8D%E5%8E%86%E6%95%B0%E7%BB%84%EF%BC%88%E9%87%8D%E7%82%B9%EF%BC%89">2.2.4 遍历数组（重点）</h5> <br><p><strong>目标</strong>：能够遍历输出数组里面的元素。</p> <br><p>用循环把数组中每个元素都访问一遍，一般使用 for 循环。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">for (let i = 0; i < 数组名.length; i++) {<br>    数组名[i]<br>}<br></code></pre> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">let nums = [10, 20, 30, 40, 50];<br>for (let i = 0; i < nums.length; i++) {<br>    document.write(nums[i] + '<br>');<br>}<br></code></pre> <br><h5 id="2.2.5%20%E6%95%B0%E7%BB%84%E7%BB%83%E4%B9%A0" name="2.2.5%20%E6%95%B0%E7%BB%84%E7%BB%83%E4%B9%A0">2.2.5 数组练习</h5> <br><p><strong>练习 1</strong>：数组求和与平均值</p> <br><p><strong>需求</strong>：求数组 <code>[2, 6, 1, 7, 4]</code> 里面所有元素的和以及平均值。</p> <br><p><strong>分析</strong>：</p> <br><ol><li>声明累加变量 sum 并初始化为 0；</li><li>遍历数组，把每个元素累加到 sum 中；</li><li>用 sum 除以数组长度得到平均值。</li></ol> <br><pre><code class="language-javascript">let arr = [2, 6, 1, 7, 4];<br>let sum = 0;<br>for (let i = 0; i < arr.length; i++) {<br>    sum += arr[i];<br>}<br>let avg = sum / arr.length;<br>console.log(`和：${sum}，平均值：${avg}`); // 和：20，平均值：4<br></code></pre> <br><p><strong>拓展</strong>：平均值需要保留两位小数时，使用 <code>toFixed(2)</code>（注意它返回字符串）：</p> <br><pre><code class="language-javascript">document.write('数组的平均值为：' + avg.toFixed(2));<br></code></pre> <br><p><strong>练习 2</strong>：数组求最大值和最小值</p> <br><p><strong>需求</strong>：求数组 <code>[2, 6, 1, 77, 52, 25, 7]</code> 中的最大值和最小值。</p> <br><p><strong>分析</strong>：</p> <br><ol><li>声明变量 max、min，并用数组的第一个元素 <code>arr[0]</code> 初始化；</li><li>从下标 1 开始遍历，逐个与 max、min 比较；</li><li>比 max 大就更新 max，比 min 小就更新 min；</li><li>循环结束后输出 max 和 min。</li></ol> <br><p><strong>知识点（为什么用 arr[0] 初始化，而不是 0 或其他数字）</strong>：</p> <br><p>如果初始化为假定的数字（比如 0），当数组中所有元素都比它小时结果就会出错——例如数组元素全是负数时，max 永远是 0。<strong>用 <code>arr[0]</code> 作为初始基准，基准一定来自数组内部</strong>，对任何数据都成立。</p> <br><pre><code class="language-javascript">let arr = [2, 6, 1, 77, 52, 25, 7];<br>let max = arr[0];<br>let min = arr[0];<br>for (let i = 1; i < arr.length; i++) {<br>    if (arr[i] > max) {<br>        max = arr[i];<br>    }<br>    if (arr[i] < min) {<br>        min = arr[i];<br>    }<br>}<br>console.log(`最大值：${max}，最小值：${min}`); // 最大值：77，最小值：1<br></code></pre> <br><p><strong>拓展写法</strong>：用三元表达式代替 if，效果等价：</p> <br><pre><code class="language-javascript">max = arr[i] > max ? arr[i] : max;<br></code></pre> <br><p>两种写法选一种即可，同一轮比较不要重复判断；<strong>if 结构可读性更好，推荐优先使用</strong>。</p> <br><p><strong>综合拓展</strong>（一次循环同时求和、平均值、最大值、最小值）：</p> <br><pre><code class="language-javascript"><script><br>    let arr = [1, 2, 3, 4, 5];<br>    let sum = 0;<br>    let max = arr[0];<br>    let min = arr[0];<br>    for (let i = 0; i < arr.length; i++) {<br>        sum += arr[i];<br>        if (arr[i] > max) {<br>            max = arr[i];<br>        }<br>        if (arr[i] < min) {<br>            min = arr[i];<br>        }<br>    }<br>    document.write('数组的和为：' + sum + '<br>');<br>    document.write('数组的平均值为：' + (sum / arr.length).toFixed(2) + '<br>');<br>    document.write('数组的最大值为：' + max + '<br>');<br>    document.write('数组的最小值为：' + min);<br></script><br></code></pre> <br><p>知识点：一个循环体内可以同时完成多项统计，避免重复遍历数组。</p> <br><table><thead><tr><th>操作</th><th>方法</th><th>说明</th></tr></thead><tbody><tr><td><strong>查</strong></td><td><code>数组[下标]</code></td><td>访问数组数据</td></tr><tr><td><strong>改</strong></td><td><code>数组[下标] 删除的个数)</code></td><td>删除指定元素</td></tr></tbody></table> <br><h5 id="2.3.1%20%E6%96%B0%E5%A2%9E%20%E2%80%94%E2%80%94%20push" name="2.3.1%20%E6%96%B0%E5%A2%9E%20%E2%80%94%E2%80%94%20push">2.3.1 新增 —— push</h5> <br><p><strong>目标</strong>：掌握利用 push 向数组添加元素。</p> <br><p><code>arr.push()</code> 方法将一个或多个元素添加到数组的<strong>末尾</strong>，并返回该数组的<strong>新长度</strong>（重点）。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">arr.push(元素1, ..., 元素n)<br></code></pre> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">// 一次添加一个元素<br>let arr1 = ['red', 'green', 'pink', 'hotpink']<br></code></pre> <br><h5 id="2.3.2%20%E6%96%B0%E5%A2%9E%20%E2%80%94%E2%80%94%20unshift" name="2.3.2%20%E6%96%B0%E5%A2%9E%20%E2%80%94%E2%80%94%20unshift">2.3.2 新增 —— unshift</h5> <br><p><code>arr.unshift()</code> 方法将一个或多个元素添加到数组的<strong>开头</strong>，并返回该数组的<strong>新长度</strong>。</p> <br><p><strong>语法</strong>：</p> <br><pre><code ['pink', 'hotpink', 'red', 'green']<br></code></pre> <br><p><strong>小结</strong>：</p> <br><ol><li>想在数组<strong>末尾</strong>添加元素用 <code>arr.push()</code>，想在<strong>开头</strong>添加用 <code>arr.unshift()</code>；</li><li>两者都可以一次添加一个或多个元素，返回值都是数组的新长度；</li><li>开发中最常用的是 <code>arr.push()</code>。</li></ol> <br><p><strong>重点案例</strong>：数组筛选</p> <br><p><strong>需求</strong>：将数组 <code>[2, 0, <br><p><strong>目标</strong>：能够删除数组元素。</p> <br><p><code>arr.pop()</code> 方法删除数组的<strong>最后一个</strong>元素，并返回<strong>被删除元素</strong>的值。每次调用只能删除一个元素。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">arr.pop()<br></code></pre> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">let arr = ['red', 'green'];<br>arr.pop();<br>console.log(arr); // ['red']<br></code></pre> <br><h5 id="2.3.4%20%E5%88%A0%E9%99%A4%20%E2%80%94%E2%80%94%20shift" name="2.3.4%20%E5%88%A0%E9%99%A4%20%E2%80%94%E2%80%94%20shift">2.3.4 删除 —— shift</h5> <br><p><code>arr.shift()</code> 方法删除数组的<strong>第一个</strong>元素，并返回<strong>被删除元素</strong>的值。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">arr.shift()<br></code></pre> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">let arr = ['red', 'green'];<br>arr.shift();<br>console.log(arr); // ['green']<br></code></pre> <br><h5 id="2.3.5%20%E5%88%A0%E9%99%A4%20%E2%80%94%E2%80%94%20splice" name="2.3.5%20%E5%88%A0%E9%99%A4%20%E2%80%94%E2%80%94%20splice">2.3.5 删除 —— splice</h5> <br><p><code>arr.splice()</code> 方法删除<strong>指定位置</strong>的元素。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">arr.splice(start, deleteCount)<br>//       起始下标    删除的个数<br></code></pre> <br><p><strong>参数说明</strong>：</p> <br><ul><li><strong>start（起始位置）</strong>：指定修改的开始位置（下标从 0 计数）；</li><li><strong>deleteCount（删除个数）</strong>：要移除的元素个数（可选，省略时从起始位置一直删除到末尾）。</li></ul> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">let arr = ['red', 'green', 'blue', 'pink'];<br>arr.splice(1, 2); // 从下标 1 开始，删除 2 个元素<br>console.log(arr); // ['red', 'pink']<br></code></pre> <br><p><strong>综合练习</strong>（三种删除方法一起使用）：</p> <br><pre><code class="language-javascript"><script><br>    let arr = [2, 0, 6, 77, 9, 54, 3, 78, 7];<br><br>    arr.shift();      // 删除第一个元素 → [0, 6, 77, 9, 54, 3, 78, 7]<br>    console.log(arr);<br>    arr.pop();        // 删除最后一个元素 → [0, 6, 77, 9, 54, 3, 78]<br>    console.log(arr);<br>    arr.splice(2, 1); // 从下标 2 开始删除 1 个元素（77） → [0, 6, 9, 54, 3, 78]<br>    console.log(arr);<br></script><br></code></pre> <br><p><strong>注意（console.log 打印数组的机制）</strong>：<code>console.log(arr)</code> 打印的是数组本身的<strong>引用</strong>，不是打印那一刻的快照。多次打印指向同一个数组，在控制台展开查看时，显示的是数组的<strong>最新状态</strong>。如果想记录每一步当时的值，可以打印副本：</p> <br><pre><code class="language-javascript">console.log([...arr]);            // 展开成新数组（副本）<br>console.log(JSON.stringify(arr)); // 转成字符串输出<br></code></pre> <br><p><strong>使用场景</strong>：</p> <br><ol><li>随机抽奖：中奖用户需要从数组中删除，不允许重复抽奖；</li><li>点击删除按钮：相关数据从商品列表中删除；</li><li>splice 在后续开发和课程中会经常用到。</li></ol> <br><p><strong>小结</strong>：</p> <br><ol><li>想删除数组<strong>末尾</strong>的 1 个元素用 <code>arr.pop()</code>，不带参数，返回被删除的元素；</li><li>想删除数组<strong>开头</strong>的 1 个元素用 <code>arr.shift()</code>，不带参数，返回被删除的元素；</li><li>想删除<strong>指定</strong>的元素用 <code>arr.splice(起始位置, 删除个数)</code>，开发中很常用，比如随机抽奖、删除指定商品等。</li></ol> <br><h3 id="%E4%B8%89%E3%80%81%E7%BB%BC%E5%90%88%E6%A1%88%E4%BE%8B" name="%E4%B8%89%E3%80%81%E7%BB%BC%E5%90%88%E6%A1%88%E4%BE%8B">三、综合案例</h3> <br><h4 id="3.1%20%E6%A0%B9%E6%8D%AE%E6%95%B0%E6%8D%AE%E7%94%9F%E6%88%90%E6%9F%B1%E5%BD%A2%E5%9B%BE" name="3.1%20%E6%A0%B9%E6%8D%AE%E6%95%B0%E6%8D%AE%E7%94%9F%E6%88%90%E6%9F%B1%E5%BD%A2%E5%9B%BE">3.1 根据数据生成柱形图</h4> <br><p><strong>需求</strong>：用户输入四个季度的数据，生成柱形图。</p> <br><p><strong>分析</strong>：</p> <br><ol><li>需要输入 4 次：利用循环弹出 4 次输入框，把数据依次 <code>push</code> 到数组中；</li><li>遍历数组，根据每个数据生成一个柱形，渲染到页面中；</li><li>柱形就是 div 盒子：宽度固定，高度等于用户输入的数据；div 内部包含显示数值的 span 和"第 n 季度"标题 h4。</li></ol> <br><p><strong>开发思路（先写死，再动态）</strong>：</p> <br><ol><li><strong>第一步——写死结构</strong>：先用静态 HTML 写出一根柱子的结构和样式，把布局效果调整好；</li><li><strong>第二步——动态生成</strong>：确认静态效果无误后，把静态结构改写成"循环 + 模板字符串"动态输出，数据来源换成用户输入。</li></ol> <br><p><strong>第一步：静态结构（写死）</strong></p> <br><pre><code class="language-javascript"><style><br>    * {<br>        margin: 0;<br>        padding: 0;<br>    }<br><br>    .box {<br>        display: flex;              /* 弹性布局：让柱子横向排列 */<br>        justify-content: space-around;<br>        align-items: flex-end;      /* 底部对齐：柱子从下往上生长 */<br>        width: 700px;<br>        height: 300px;<br>        border-left: 1px solid pink;<br>        border-bottom: 1px solid pink;<br>        margin: 50px auto;<br>    }<br><br>    .box > div {<br>        display: flex;<br>        flex-direction: column;     /* 数值和标题上下排列 */<br>        justify-content: space-between;<br>        width: 50px;<br>        background-color: pink;<br>    }<br><br>    .box div span {<br>        margin-top: -20px;          /* 把数值顶到柱子上方 */<br>    }<br><br>    .box div h4 {<br>        margin-bottom: -35px;       /* 把标题压到坐标轴下方 */<br>        width: 70px;<br>        margin-left: -10px;<br>    }<br></style><br><br><body><br>    <div class="box"><br>        <div style="height: 123px;"><br>            <span>123</span><br>            <h4>第1季度</h4><br>        </div><br>        <div style="height: 156px;"><br>            <span>156</span><br>            <h4>第2季度</h4><br>        </div><br>        <div style="height: 120px;"><br>            <span>120</span><br>            <h4>第3季度</h4><br>        </div><br>        <div style="height: 210px;"><br>            <span>210</span><br>            <h4>第4季度</h4><br>        </div><br>    </div><br></body><br></code></pre> <br><p><strong>第二步：JS 动态生成</strong></p> <br><pre><code class="language-javascript"><script><br>    // 1. 循环 4 次弹出输入框，把数据存入数组<br>    let arr = [];<br>    for (let i = 0; i < 4; i++) {<br>        arr.push(+prompt(`第${i + 1}季度的销售额是：`));<br>    }<br><br>       <span>${arr[i]}</span><br>                <h4>第${i + 1}季度</h4><br>            </div><br>        `);<br>    }<br>    document.write('</div>');<br></script><br></code></pre> <br><p><strong>注意（prompt 的返回值）</strong>：<code>prompt()</code> 返回的是<strong>字符串</strong>，用 <code>+</code> 转换为数字是规范做法。本例中字符串直接拼进 style 也能显示，但后续参与计算（比较、求和等）时必须转换为数字。</p> <br><p><strong>知识点（静态与动态的对应关系）</strong>：</p> <br><ul><li>动态版本循环体内的一个 div，正好对应静态版本中的一根柱子；</li><li><code>i</code> 从 0 开始遍历数组，所以标题写成 <code>第${i + 1}季度</code>；</li><li>CSS 布局要点：<code>.box</code> 用 <code>align-items: flex-end</code> 让所有柱子底部对齐；每根柱子内部用 <code>flex-direction: column</code> 配合 <code>justify-content: space-between</code>，让数值在上、标题在下。</li></ul> <br><h4 id="3.2%20%E5%86%92%E6%B3%A1%E6%8E%92%E5%BA%8F" name="3.2%20%E5%86%92%E6%B3%A1%E6%8E%92%E5%BA%8F">3.2 冒泡排序</h4> <br><p><strong>冒泡排序</strong>是一种简单的排序算法：</p> <br><ul><li>它重复地走访要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来；</li><li>走访数列的工作重复进行，直到没有需要交换的元素为止，此时数列已经排序完成；</li><li>这个算法名字的由来：越小的元素会经由交换慢慢"浮"到数列的顶端；</li><li>例如数组 <code>[2, 3, 1, 4, 5]</code> 排序后成为 <code>[1, 2, 3, 4, 5]</code>（升序）或 <code>[5, 4, 3, 2, 1]</code>（降序）。</li></ul> <br><p><strong>分析</strong>（以 <code>[5, 4, 3, 2, 1]</code> 升序排列为例）：</p> <br><ol><li><strong>一共需要的趟数</strong>（外层 for 循环）：5 个数据一共需要走 4 趟，即 <code>arr.length - 1</code> 趟；</li><li><strong>每一趟的比较次数</strong>（内层 for 循环）：第 1 趟比较 4 次，第 2 趟比较 3 次，依次递减。第 i 趟（i 从 0 开始）比较 <code>arr.length - 1 - i</code> 次，因为每走完一趟，就有一个最大值"沉"到末尾，不再参与比较；</li><li><strong>交换两个变量</strong>：借助临时变量 temp 完成交换。</li></ol> <br><p><strong>参考代码</strong>：</p> <br><pre><code class="language-javascript">let arr = [5, 4, 3, 2, 1];<br>for (let i = 0; i < arr.length - 1; i++) {         // 外层：控制趟数<br>    for (let j = 0; j < arr.length - 1 - i; j++) { // 内层：控制每趟比较次数<br>        if (arr[j] > arr[j + 1]) {                 // 前一个比后一个大就交换<br>            let temp = arr[j];<br>            arr[j] = arr[j + 1];<br>            arr[j + 1] = temp;<br>        }<br>    }<br>}<br>console.log(arr); // [1, 2, 3, 4, 5]<br></code></pre> <br><h4 id="3.3%20%E6%95%B0%E7%BB%84%E6%8E%92%E5%BA%8F%20%E2%80%94%E2%80%94%20sort" name="3.3%20%E6%95%B0%E7%BB%84%E6%8E%92%E5%BA%8F%20%E2%80%94%E2%80%94%20sort">3.3 数组排序 —— sort</h4> <br><p><code>arr.sort()</code> 方法可以对数组排序（会<strong>修改原数组</strong>）。</p> <br><p><strong>注意</strong>：不传参数时，sort 按字符串的顺序排序，对数字排序会出错（例如 <code>[1, 10, 2]</code>），所以给数字排序必须传入比较函数。</p> <br><pre><code class="language-javascript">let arr = [4, 2, 5, 1, 3];<br><br>// 升序排列写法<br>arr.sort(function (a, b) {<br>    return a - b;<br>});<br>console.log(arr); // [1, 2, 3, 4, 5]<br><br>// 降序排列写法<br>arr.sort(function (a, b) {<br>    return b - a;<br>});<br>console.log(arr); // [5, 4, 3, 2, 1]<br></code></pre> <br><p>比较规则：返回值 <code>a - b > 0</code> 时，a 排在 b 的后面（升序）；返回 <code>b - a</code> 则相反（降序）。</p>
