name="1.1%20%E8%B5%8B%E5%80%BC%E8%BF%90%E7%AE%97%E7%AC%A6" style="background-color:transparent">1.1 赋值运算符</h4> <br><p><strong>目标</strong>：能够使用赋值运算符简化代码。</p> <br><p>赋值运算符用于对变量进行赋值。最基本的赋值运算符是 <code>=</code>：把等号右边的值赋给左边的变量，等号左边必须是<strong>变量（一个"容器"）</strong>，不能是字面量。</p> <br><table><thead><tr><th>运算符</th><th>说明</th><th>示例</th><th>等价于</th></tr></thead><tbody><tr><td><code>=</code></td><td>赋值</td><td><code>num = 10</code></td><td><code>num = 1<br>console.log(num)   // 2<br>// 复合赋值运算符的简写<br>let num = 1<br>num += 1<br>console.log(num)   // 2</code></pre> <br><h4 id="1.2%20%E4%B8%80%E5%85%83%E8%BF%90%E7%AE%97%E7%AC%A6" name="1.2%20%E4%B8%80%E5%85%83%E8%BF%90%E7%AE%97%E7%AC%A6">1.2 一元运算符</h4> <br><p><strong>目标</strong>：能够使用一元运算符做自增运算。</p> <br><p>JavaScript 的运算符按所需<strong>操作数</strong>的个数，分为一元运算符、二元运算符、三元运算符。</p> <br><p>操作数就是运算符处理的数据。例如 <code>10 + 20</code> 中，<code>+</code> 左右各需要一个操作数（10 和 20），共两个，所以 <code>+</code> 是二元运算符；<code>++</code> 只作用于一个变量，所以是一元运算符；<code>?:</code> 需要条件和两个候选值共三部分，是唯一的三元运算符。</p> <br><blockquote> <br> <p>补充：而<strong>表达式</strong>是由数字、变量和运算符组成、能够计算出一个值的代码，例如 <code>10 + 20</code>、<code>num++</code>。</p> <br></blockquote> <br><table><thead><tr><th>类型</th><th>说明</th><th>示例</th></tr></thead><tbody><tr><td><strong>一元运算符</strong></td><td>只需要 1 个操作数</td><td><code>++num</code>、<code>!true</code></td></tr><tr><td><strong>二元运算符</strong></td><td>需要 2 个操作数</td><td><code>10 + 20</code></td></tr><tr><td><strong>三元运算符</strong></td><td>需要 3 个操作数</td><td><code>条件 ? 值1 : 值2</code></td></tr></tbody></table> <br><h5 id="1.2.1%20%E8%87%AA%E5%A2%9E%E5%92%8C%E8%87%AA%E5%87%8F" name="1.2.1%20%E8%87%AA%E5%A2%9E%E5%92%8C%E8%87%AA%E5%87%8F">1.2.1 自增和自减</h5> <br><table><thead><tr><th>符号</th><th>作用</th></tr></thead><tbody><tr><td><code>++</code></td><td>让变量的值 +1</td></tr><tr><td><code>--</code></td><td>让变量的值 -1</td></tr></tbody></table> <br><p><strong>使用场景</strong>：经常用于计数。比如要进行 10 次操作，用它来记录已经进行了多少次。</p> <br><h5 id="1.2.2%20%E5%89%8D%E7%BD%AE%E8%87%AA%E5%A2%9E%E5%92%8C%E5%90%8E%E7%BD%AE%E8%87%AA%E5%A2%9E" name="1.2.2%20%E5%89%8D%E7%BD%AE%E8%87%AA%E5%A2%9E%E5%92%8C%E5%90%8E%E7%BD%AE%E8%87%AA%E5%A2%9E">1.2.2 前置自增和后置自增</h5> <br><table><thead><tr><th>类型</th><th>语法</th><th>说明</th><th>记忆口诀</th></tr></thead><tbody><tr><td><strong>前置自增</strong></td><td><code>++num</code></td><td>先自加，再使用</td><td><code>++</code> 在前先加</td></tr><tr><td><strong>后置自增</strong></td><td><code>num++</code></td><td>先使用，再自加</td><td><code>++</code> 在后后加</td></tr></tbody></table> <br><p><strong>后置自增的 +1 到底什么时候发生？</strong></p> <br><p>——在<strong>取出变量当前值之后立刻发生</strong>，也就是在执行下一行代码之前就完成了，不需要等到整个程序结束。只是它参与<strong>当前运算时用的是自增前的旧值</strong>。</p> <br><p><strong>示例</strong>：</p> <br><pre><code class="language-javascript">// 前置自增：先自加再使用<br>let i = 1<br>console.log(++i + 2)   // 4<br>// i 先自加变成 2，再拿 2 和后面的 2 相加<br>// 后置自增：先使用再自加<br>let i = 1<br>console.log(i++ + 2)   // 3<br>// 先取 i 的旧值 1 与 2 相加，取值之后 i 立刻变成 2</code></pre> <br><h5 id="1.2.3%20%E4%BD%BF%E7%94%A8%E5%BB%BA%E8%AE%AE" name="1.2.3%20%E4%BD%BF%E7%94%A8%E5%BB%BA%E8%AE%AE">1.2.3 使用建议</h5> <br><ol><li><strong>前置自增和后置自增独立使用时没有差别</strong>，都是让变量 +1。</li><li>实际开发中自增运算符基本都是<strong>独立使用</strong>。</li><li>其中后置自增 <code>i++</code> 使用相对更多。</li></ol> <br><p><strong>面试题</strong>：</p> <br><pre><code class="language-javascript">let i = 1<br>console.log(i++ + ++i + i)   // 7<br></code></pre> <br><blockquote> <br> <p>解析（关键：i 始终是<strong>同一个变量</strong>，每一步都在改变它的值）：</p> <br> <ol><li><code>i++</code>：先取旧值 <strong>1</strong> 参与加法，随后 i 变成 2</li><li><code>++i</code>：i 先变成 <strong>3</strong>，再取 3 参与加法</li><li><code>i</code>：当前值就是 <strong>3</strong></li></ol> <br></blockquote> <br><p>所以结果是 <code>1 + 3 + 3 = 7</code>。</p> <br><h4 id="1.3%20%E6%AF%94%E8%BE%83%E8%BF%90%E7%AE%97%E7%AC%A6" name="1.3%20%E6%AF%94%E8%BE%83%E8%BF%90%E7%AE%97%E7%AC%A6">1.3 比较运算符</h4> <br><p><strong>目标</strong>：能使用常见的比较运算符进行比较运算。</p> <br><p><strong>使用场景</strong>：比较两个数据的大小、是否相等。</p> <br><table><thead><tr><th>运算符</th><th>说明</th></tr></thead><tbody><tr><td><code>></code></td><td>左边是否大于右边</td></tr><tr><td><code><</code></td><td>左边是否小于右边</td></tr><tr><td><code>>=</code></td><td>左边是否大于或等于右边</td></tr><tr><td><code><=</code></td><td>左边是否小于或等于右边</td></tr><tr><td><code>==</code></td><td>左右两边的<strong>值</strong>是否相等（不比较类型）</td></tr><tr><td><code>===</code></td><td>左右两边<strong>类型和值</strong>都相等（全等）</td></tr><tr><td><code>!=</code></td><td>左右两边的值是否不相等（不比较类型）</td></tr><tr><td><code>!==</code></td><td>左右两边是否不全等（类型或值有一个不同）</td></tr></tbody></table> <br><blockquote> <br> <p>比较运算的结果是 boolean 类型，只会得到 <code>true</code> 或 <code>false</code>。</p> <br></blockquote> <br><p><strong>单等、双等、三等区别</strong>：</p> <br><table><thead><tr><th>运算符</th><th>名称</th><th>说明</th></tr></thead><tbody><tr><td><code>=</code></td><td>赋值</td><td>把右边的值赋给左边的变量</td></tr><tr><td><code>==</code></td><td>相等</td><td>只要求值相等，不要求类型相同</td></tr><tr><td><code>===</code></td><td>全等</td><td>要求值和类型都相同</td></tr></tbody></table> <br><blockquote> <br> <p><strong>开发中判断是否相等，强烈推荐使用 <code>===</code>。</strong></p> <br></blockquote> <br><h5 id="1.3.1%20%E6%AF%94%E8%BE%83%E8%BF%90%E7%AE%97%E7%AC%A6%E7%9A%84%E7%BB%86%E8%8A%82" name="1.3.1%20%E6%AF%94%E8%BE%83%E8%BF%90%E7%AE%97%E7%AC%A6%E7%9A%84%E7%BB%86%E8%8A%82">1.3.1 比较运算符的细节</h5> <br><ol><li> <p><strong>字符串比较</strong>：按字符的编码逐个比较（英文字母、数字的编码就是<strong> ASCII 码</strong>），从左往右依次比较。第一位不同就直接出结果；第一位相同再比较第二位，以此类推。</p> </li><li> <p><strong>NaN 不等于任何值，包括它自己</strong>：<code>NaN == NaN</code> 和 <code>NaN === NaN</code> 结果都是 <code>false</code>。</p> </li></ol> <br><p>因此"涉及 NaN 的比较都是 false"只对<strong>相等/大小</strong>比较成立，而 <code>NaN != NaN</code> 反而是 <code>true</code>。要判断一个值是不是 NaN，应使用 <code>Number.isNaN(值)</code>。</p> <br><ol><li> <p><strong>尽量不要直接比较小数</strong>，因为小数有精度问题。例如 <code>0.1 + 0.2</code> 的结果是 <code>0.30000000000000004</code>，不等于 0.3；整数在安全范围内比较不受影响。</p> </li><li> <p><strong>使用 <code>==</code> 比较不同类型时会发生隐式转换</strong>：多数情况是把两边转成 number 再比值（如 <code>'1'</code> 转成 <code>1</code>）。但有一条特殊规则——<code>null</code> 和 <code>undefined</code> 互相宽松相等：<code>null == undefined</code> 为 <code>true</code>，它们与其他任何值都不宽松相等。</p> </li><li> <p>开发中要做准确比较时，统一使用 <code>===</code> 或 <code>!==</code>。</p> </li></ol> <br><pre><code class="language-javascript">console.log(1 > 2)    // false<br>console.log(1 < 2)    // true<br>console.log(1 >= 2)   // false<br>console.log(1 <= 2)   // true<br>console.log(1 == 2)   // false<br>console.log(1 != 2)   // true<br>console.log(1 === 2)  // false<br>console.log(1 !== 2)  // true<br>// == 只比较值（发生隐式转换），=== 值和类型都比较<br>console.log(1 === '1')  // false：类型不同<br>console.log(1 !== '1')  // true<br>console.log(1 == '1')   // true：'1' 被转成数字 1<br>// null 和 undefined 的特殊规则<br>console.log(undefined == null)   // true：二者宽松相等<br>console.log(undefined === null)  // false：类型不同<br>// NaN 不等于任何值，包括它自己<br>console.log(NaN == NaN)  // false<br>// 字符串按字符编码逐位比较<br>console.log('a' < 'b')   // true<br>console.log('aa' > 'ab') // false：第一位相同，第二位 a < b<br>console.log('aa' < 'ab') // true</code></pre> <br><h4 id="1.4%20%E9%80%BB%E8%BE%91%E8%BF%90%E7%AE%97%E7%AC%A6" name="1.4%20%E9%80%BB%E8%BE%91%E8%BF%90%E7%AE%97%E7%AC%A6">1.4 逻辑运算符</h4> <br><p><strong>目标</strong>：掌握逻辑运算符，为程序"能思考"做准备。</p> <br><p><strong>使用场景</strong>：逻辑运算符用来解决多重条件判断。</p> <br><p><strong>提问</strong>：如果想判断变量 num 是否大于 5 且小于 10，怎么办？</p> <br><ul><li>错误写法：<code>5 < num < 10</code>。JavaScript 不支持数学中的连写，它会被从左到右算成 <code>(5 < num) < 10</code>，变成拿布尔值和 10 比较，结果没有判断意义。</li><li>正确写法：<code>num > 5 && num < 10</code>，拆成两个比较，再用逻辑运算符连接。</li></ul> <br><table><thead><tr><th>符号</th><th>名称</th><th>日常读法</th><th>特点</th><th>口诀</th></tr></thead><tbody><tr><td><code>&&</code></td><td>逻辑与</td><td>并且</td><td>两边都为 true，结果才为 true</td><td>一假则假</td></tr><tr><td><code>\|\|</code></td><td>逻辑或</td><td>或者</td><td>两边有一个为 true，结果就为 true</td><td>一真则真</td></tr><tr><td><code>!</code></td><td>逻辑非</td><td>取反</td><td>true 变 false，false 变 true</td><td>真变假，假变真</td></tr></tbody></table> <br><p><strong>示例 1</strong>：判断一个数能被 4 整除，但不能被 100 整除。</p> <br><pre><code class="language-javascript">let num = +prompt('请输入一个数')<br>// % 是取余：余数为 0 说明能整除；/ 算的是商，判断"整除"永远看余数是否为 0<br>alert(num % 4 === 0 && num % 100 !== 0)<br></code></pre> <br><p></p> <br><blockquote> <br> <p><code>/</code> 算的是商，<code>%</code> 算的是余数，<strong>“整除”永远看余数是否为 0</strong>。</p> <br></blockquote> <br><p><strong>示例 2</strong>：三个逻辑运算符的基本运算结果。</p> <br><pre><code class="language-javascript">// 1. 逻辑与 &&：一假则假<br>console.log(true && false)   // false<br>console.log(true && true)    // true<br>console.log(false && true)   // false<br>console.log(false && false)  // false<br>// 2. 逻辑或 ||：一真则真<br>console.log(true || true)    // true<br>console.log(false || true)   // true<br>console.log(false || false)  // false<br>// 3. 逻辑非 !：取反<br>console.log(!true)   // false<br>console.log(!false)  // true<br>// 区间判断必须拆成两个条件<br>let num = 2<br>console.log(num > 5 && num < 10) // false</code></pre> <br><h4 id="1.5%20%E8%BF%90%E7%AE%97%E7%AC%A6%E4%BC%98%E5%85%88%E7%BA%A7" name="1.5%20%E8%BF%90%E7%AE%97%E7%AC%A6%E4%BC%98%E5%85%88%E7%BA%A7">1.5 运算符优先级</h4> <br><p><strong>目标</strong>：掌握运算符优先级，能判断运算符执行的顺序。</p> <br><table><thead><tr><th>优先级</th><th>运算符</th><th>顺序</th></tr></thead><tbody><tr><td>1</td><td>小括号</td><td><code>()</code></td></tr><tr><td>2</td><td>一元运算符</td><td><code>++</code>、<code>--</code>、<code>!</code></td></tr><tr><td>3</td><td>算术运算符</td><td>先 <code>*</code>、<code>/</code>、<code>%</code>，后 <code>+</code>、<code>-</code></td></tr><tr><td>4</td><td>关系运算符</td><td><code>></code>、<code>>=</code>、<code><</code>、<code><=</code></td></tr><tr><td>5</td><td>相等运算符</td><td><code>==</code>、<code>!=</code>、<code>===</code>、<code>!==</code></td></tr><tr><td>6</td><td>逻辑运算符</td><td>先 <code>&&</code>，后 <code>\|\|</code></td></tr><tr><td>7</td><td>赋值运算符</td><td><code>=</code></td></tr><tr><td>8</td><td>逗号运算符</td><td><code>,</code></td></tr></tbody></table> <br><blockquote> <br> <p><strong>重点</strong>：</p> <br> <ul><li>一元运算符里的<strong>逻辑非 <code>!</code></strong> 优先级很高</li><li><strong>逻辑与 <code>&&</code> 比逻辑或 <code>||</code> 优先级高</strong></li></ul> <br></blockquote> <br><p><strong>练习</strong>：</p> <br><pre><code class="language-javascript">let a = 3 > 5 && 2 < 7 && 3 == 4<br>console.log(a)   // false<br>let b = 3 <= 4 || 3 > 1 || 3 != 2<br>console.log(b)   // true<br>let c = 2 == '2'<br>console.log(c)   // true<br>let d = !c || b && a<br>console.log(d)   // false</code></pre> <br><p>最后一题解析：<code>&&</code> 优先级高于 <code>||</code>，先算 <code>b && a</code>（<code>true && false</code> → <code>false</code>），再算 <code>!c</code>（<code>!true</code> → <code>false</code>），最后 <code>false || false</code> 结果为 <code>false</code>。</p> <br><h3 id="%E4%BA%8C%E3%80%81%E8%AF%AD%E5%8F%A5" name="%E4%BA%8C%E3%80%81%E8%AF%AD%E5%8F%A5">二、语句</h3> <br><h4 id="2.1%20%E8%A1%A8%E8%BE%BE%E5%BC%8F%E5%92%8C%E8%AF%AD%E5%8F%A5" name="2.1%20%E8%A1%A8%E8%BE%BE%E5%BC%8F%E5%92%8C%E8%AF%AD%E5%8F%A5">2.1 表达式和语句</h4> <br><table><thead><tr><th>类型</th><th>说明</th><th>示例</th></tr></thead><tbody><tr><td><strong>表达式</strong></td><td>可以被求值的代码，引擎会把它计算出一个结果</td><td><code>3 + 4</code>、<code>num = 3 + 4</code>（赋值表达式的值就是被赋的值）</td></tr><tr><td><strong>语句</strong></td><td>一段可以执行的代码</td><td><code>if</code> 语句、<code>for</code> 循环、<code>break</code>、<code>continue</code></td></tr></tbody></table> <br><blockquote> <br> <p><code>注意：而prompt()</code>、<code>alert()</code> 这类函数调用本质是<strong>表达式（有返回值</strong>），单独成行时也叫"表达式语句"。</p> <br></blockquote> <br><p><strong>区别</strong>：</p> <br><ul><li>表达式因为有值，可以写在赋值语句的右侧，例如 <code>let sum = i + 1</code>。</li><li><code>for</code>、<code>break</code>、<code>continue</code> 等语句没有值，不能放在赋值号右侧。</li><li><code>alert()</code> 写法上虽然可以赋值（<code>let x = alert(1)</code>），但它没有返回值，x 会得到 <code>undefined</code>，实际开发不会这么写。</li><li>像 <code>sum += i</code> 这样单独成行的表达式，既是表达式（有值），又作为一条语句执行，这就是"表达式语句"。</li></ul> <br><h4 id="2.2%20%E5%88%86%E6%94%AF%E8%AF%AD%E5%8F%A5" name="2.2%20%E5%88%86%E6%94%AF%E8%AF%AD%E5%8F%A5">2.2 分支语句</h4> <br><h5 id="2.2.1%20%E7%A8%8B%E5%BA%8F%E4%B8%89%E5%A4%A7%E6%B5%81%E7%A8%8B%E6%8E%A7%E5%88%B6%E8%AF%AD%E5%8F%A5" name="2.2.1%20%E7%A8%8B%E5%BA%8F%E4%B8%89%E5%A4%A7%E6%B5%81%E7%A8%8B%E6%8E%A7%E5%88%B6%E8%AF%AD%E5%8F%A5">2.2.1 程序三大流程控制语句</h5> <br><table><thead><tr><th>结构</th><th>说明</th><th>执行路径</th></tr></thead><tbody><tr><td><strong>顺序结构</strong></td><td>代码从上往下依次执行</td><td>代码1 → 代码2 → 代码3</td></tr><tr><td><strong>分支结构</strong></td><td>根据条件选择执行代码</td><td>满足条件执行代码2，不满足执行代码3</td></tr><tr><td><strong>循环结构</strong></td><td>某段代码被重复执行</td><td>代码1 → 重复执行某段代码多次 → 代码3</td></tr></tbody></table> <br><h5 id="2.2.2%20if%20%E8%AF%AD%E5%8F%A5" name="2.2.2%20if%20%E8%AF%AD%E5%8F%A5">2.2.2 if 语句</h5> <br><p>if 语句有三种使用方式：单分支、双分支、多分支。</p> <br><p><strong>（1）单分支</strong></p> <br><pre><code class="language-javascript">if (条件) {<br>    满足条件要执行的代码<br>}<br></code></pre> <br><ul><li>小括号内的条件为 true 时，进入大括号执行代码。</li><li>小括号内的结果若不是布尔类型，会发生隐式转换转为布尔类型。</li><li>如果大括号里只有一个语句，大括号可以省略，但不提倡这么做。</li></ul> <br><pre><code class="language-javascript">// 条件为 true 才执行<br>if (false) {<br>  console.log('不会执行')<br>}<br>if (true) {<br>  console.log('会执行')<br>}<br>if (1 > 2) {<br>  console.log('不会执行，条件不成立')<br>}<br>// 条件位置不是布尔值时，会隐式转换为布尔值<br>// 假值（转为 false）：0、NaN、''（空字符串）、null、undefined<br>// 其余都为 true，包括负数和非空字符串（' ' 空格字符串也是 true）<br>if (-2) {<br>console.log('非 0 数字为 true')<br>}<br>if ('') {<br>console.log('空字符串为 false，不会执行')<br>}<br>if ('hello') {<br>console.log('非空字符串为 true')<br>}<br>if (undefined) {<br>console.log('undefined 为 false，不会执行')<br>}<br>if (null) {<br>console.log('null 为 false，不会执行')<br>}<br>if (NaN) {<br>console.log('NaN 为 false，不会执行')<br>}</code></pre> <br><p><strong>案例</strong>：用户输入高考成绩，如果分数大于 700，提示恭喜。</p> <br><pre><code class="language-javascript">let score = +prompt('请输入高考成绩：')<br>if (score > 700) {<br>  alert('恭喜！')<br>}<br></code></pre> <br><p><strong>（2）双分支</strong></p> <br><pre><code class="language-javascript">if (条件) {<br>    满足条件要执行的代码<br>} else {<br>    不满足条件执行的代码<br>}<br></code></pre> <br><p><strong>案例</strong>：判断用户登录。</p> <br><pre><code class="language-javascript">let uname = prompt('请输入用户名：')<br>let pwd = prompt('请输入密码：')<br>if (uname === 'admin' && pwd === '123456') {<br>  alert('登录成功')<br>} else {<br>  alert('用户名或密码错误')<br>}<br></code></pre> <br><p><strong>案例</strong>：判断闰年。</p> <br><p>闰年规则：能被 4 整除但不能被 100 整除，<strong>或者</strong>能被 400 整除。需要用逻辑运算符把多个条件组合起来。</p> <br><pre><code class="language-javascript">let year = +prompt('请输入年份：')<br>if ((year % 4 === 0 && year % 100 !== 0) || year % 400 === 0) {<br>  alert(`${year}年是闰年`)<br>} else {<br>  alert(`${year}年是平年`)<br>}<br></code></pre> <br><p><strong>（3）多分支</strong></p> <br><pre><code class="language-javascript">if (条件1) {<br>    代码1<br>} else if (条件2) {<br>    代码2<br>} else if (条件3) {<br>    代码3<br>} else {<br>    代码n   // 兜底处理<br>}<br></code></pre> <br><p><strong>使用场景</strong>：适合有多个结果的时候，比如成绩分为优、良、及格、不及格。</p> <br><p><strong>案例</strong>：输入成绩，输出等级。</p> <br><pre><code class="language-javascript">let score = +prompt('请输入成绩：')<br>if (score >= 90) {<br>  alert('优秀')<br>} else if (score >= 70) {<br>  alert('良好')<br>} else if (score >= 60) {<br>  alert('及格')<br>} else {<br>  alert('不及格')<br>}<br></code></pre> <br><p><strong>为什么不用重复写上界？</strong></p> <br><blockquote> <br> <p>多分支从上往下判断，命中一个分支后整个 if 结构就结束了，所以能走到下一个 <code>else if</code>，本身就说明不满足前面所有条件。条件按从大到小写、且边界符号统一（都用 <code>>=</code>）时，只需判断一个边界：</p> <br></blockquote> <br><pre><code class="language-javascript">if (score >= 90) {<br>  alert('优秀')   // 走到这里说明 score >= 90<br>} else if (score >= 70) {<br>  alert('良好')   // 走到这里说明 score < 90，只需再判断 >= 70<br>} else if (score >= 60) {<br>  alert('及格')   // 此时 60 <= score < 70<br>} else {<br>  alert('不及格') // 其余所有情况兜底<br>}<br></code></pre> <br><p>本案例的常见错误：</p> <br><ol><li><strong>边界符号不统一</strong>：<code>></code> 和 <code>>=</code> 混用，会导致 90、60 这种<strong>临界分数漏判或归错等级</strong>。</li><li><strong>出现永远走不到的分支</strong>：例如在 <code>score >= 60</code>（及格）之后再写一个 <code>else if (score > 60)</code>，能走到这里的分数已经小于 60，该分支永远不会执行，而且"大于 60 输出不及格"语义本身也写反了。</li><li><strong>输入非法值</strong>：如输入超过 100 或负数，本例由 else 统一兜底，需要更严谨时可单独判断。</li></ol> <br><h5 id="2.2.3%20%E4%B8%89%E5%85%83%E8%BF%90%E7%AE%97%E7%AC%A6" name="2.2.3%20%E4%B8%89%E5%85%83%E8%BF%90%E7%AE%97%E7%AC%A6">2.2.3 三元运算符</h5> <br><p><strong>目标</strong>：能利用三元运算符执行满足条件的语句。</p> <br><p><strong>使用场景</strong>：比 if 双分支更简单的写法。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">条件 ? 表达式1 : 表达式2<br></code></pre> <br><p>条件为 true 时，整个表达式的结果取表达式1的值；为 false 时取表达式2的值。</p> <br><blockquote> <br> <p>三元运算符的结果是一个<strong>值</strong>，一般用来取值。</p> <br></blockquote> <br><p><strong>案例</strong>：判断两个数的最大值。</p> <br><pre><code class="language-javascript">let num1 = +prompt('请输入第一个数：')<br>let num2 = +prompt('请输入第二个数：')<br>let max = num1 > num2 ? num1 : num2   // 把三元的结果赋给变量<br>console.log(max)<br></code></pre> <br><p>也可以直接把三元表达式放进模板字符串中取值：</p> <br><pre><code class="language-javascript">console.log(`较大的是${num1 > num2 ? num1 : num2}`)<br></code></pre> <br><blockquote> <br> <p>注意：三元运算符设计用途是"<strong>取值</strong>"，应出现在需要值的地方（赋值右侧、模板字符串里）。像 <code>条件 ? console.log(a) : console.log(b)</code> 这样把整条语句塞进两个分支虽然能运行，但不推荐。</p> <br></blockquote> <br><p><strong>案例</strong>：数字补 0。</p> <br><pre><code class="language-javascript">let num = +prompt('请输入一个数：')<br>let result = num < 10 ? '0' + num : num   // 小于 10 在前面补 0<br>document.write(result)<br></code></pre> <br><blockquote> <br> <p>要点：只判断一次即可，<code>10</code> 是两位数不应补 0。如果再叠加一次反向判断（<code>num > 10 ? num : '0' + num</code>），当 num 为 10 时会被错误拼成 <code>'010'</code>。</p> <br></blockquote> <br><h5 id="2.2.4%20switch%20%E8%AF%AD%E5%8F%A5" name="2.2.4%20switch%20%E8%AF%AD%E5%8F%A5">2.2.4 switch 语句</h5> <br><p><strong>目标</strong>：能利用 switch 执行满足条件的语句。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-javascript">switch (数据) {<br>    case 值1:<br>        代码1<br>        break<br>    case 值2:<br>        代码2<br>        break<br>    default:<br>        代码n<br>        break<br>}<br></code></pre> <br><p><strong>释义</strong>：找到跟小括号里的数据<strong>全等（<code>===</code>）</strong>的 case 值，执行对应代码；没有全等匹配时执行 default 里的代码。</p> <br><p><strong>注意事项</strong>：</p> <br><ol><li>switch case 一般用于<strong>等值判断</strong>，不适合区间判断（区间判断用 if 多分支）。</li><li>一般需要配合 <strong>break</strong> 使用；不写 break 会发生 <strong>case 穿透</strong>：从命中的 case 开始，后面的 case 代码会连续执行，不再判断。</li><li>default 写在最后且后面没有其他 case 时，它后面的 break 可以省略；但为了风格统一、防止以后调整分支顺序时出错，建议每个分支都写 break。</li></ol> <br><pre><code class="language-javascript">switch (num) {<br>  case 1:<br>    console.log('1')<br>    break   // 跳出 switch；不写会继续执行下一个 case（case 穿透）<br>  case 2:<br>    console.log('2')<br>    break<br>  default:<br>    console.log('其他')  // num 不全等于任何 case 时执行<br>    break                // default 在最后，可省略<br>}<br></code></pre> <br><p><strong>案例</strong>：简单计算器。</p> <br><pre><code class="language-javascript">let num1 = +prompt('请输入第一个数字：')      // 前加 +，把输入转成数值<br>let num2 = +prompt('请输入第二个数字：')<br>let operator = prompt('请输入运算符（+ - * /）：')  // 运算符是符号，必须保持字符串<br>let result<br>switch (operator) {<br>  case '+':<br>    result = num1 + num2<br>    break<br>  case '-':<br>    result = num1 - num2<br>    break<br>  case '*':<br>    result = num1 * num2<br>    break<br>  case '/':<br>    result = num1 / num2<br>    break<br>  default:<br>    alert('输入的运算符有误')<br>}<br>alert(`计算结果：${result}`)<br></code></pre> <br><p>要点：两个数字前用 <code>+</code> 转成数值类型才能做数学运算；运算符不能加 <code>+</code>（字符串符号转数值会得到 <code>NaN</code>），保持字符串才能和 case 后的值全等匹配。</p> <br><h4 id="2.3%20%E5%BE%AA%E7%8E%AF%E7%BB%93%E6%9E%84" name="2.3%20%E5%BE%AA%E7%8E%AF%E7%BB%93%E6%9E%84">2.3 循环结构</h4> <br><p><strong>目标</strong>：掌握循环结构，实现一段代码重复执行。</p> <br><h5 id="2.3.1%20%E6%96%AD%E7%82%B9%E8%B0%83%E8%AF%95" name="2.3.1%20%E6%96%AD%E7%82%B9%E8%B0%83%E8%AF%95">2.3.1 断点调试</h5> <br><p><strong>作用</strong>：学习时帮助理解代码运行过程，工作时更快找到 bug。</p> <br><p><strong>浏览器打开调试界面</strong>：</p> <br><ol><li>按 F12 打开开发者工具，切换到 <strong>Sources（源代码）</strong> 面板。</li><li>在文件列表中选择代码文件，<strong>点击行号</strong>添加断点（再次点击可取消）。</li><li>刷新页面，程序执行到断点处会暂停。</li><li>用 id="2.3.2%20while%20%E5%BE%AA%E7%8E%AF" name="2.3.2%20while%20%E5%BE%AA%E7%8E%AF">2.3.2 while 循环</h5> <br><p><strong>目标</strong>：掌握 while 循环语法，能重复执行某段代码。</p> <br><p><strong>循环</strong>就是重复执行一些操作。while 的意思是"在……期间"，即在满足条件期间，重复执行循环体里的代码。</p> <br><p><strong>（1）基本语法</strong></p> <br><pre><code class="language-javascript">while (循环条件) {<br>    要重复执行的代码（循环体）<br>}<br></code></pre> <br><p><strong>释义</strong>：</p> <br><ul><li>跟 if 语句很像，小括号里的条件为 true 才会进入大括号执行代码。</li><li>区别在于：while 循环体执行完后不会跳出，而是回到小括号再次判断条件；条件仍为 true 就再执行一次，如此反复，直到条件为 false 才跳出。</li></ul> <br><p><strong>（2）循环三要素</strong></p> <br><p>循环的本质：以某个变量为起始值，不断让它变化，慢慢靠近终止条件。</p> <br><ol><li><strong>变量起始值</strong></li><li><strong>终止条件</strong>（没有终止条件会一直循环，造成死循环）</li><li><strong>变量变化量</strong>（一般用自增或自减）</li></ol> <br><pre><code class="language-javascript">let i = 1<br>while (i <= 3) {<br>  document.write('我会循环三次<br>')<br>  i++<br>}<br></code></pre> <br><p><strong>案例</strong>：在页面中输出 10 句"加油coding人"。</p> <br><pre><code class="language-javascript">let i = 1<br>while (i <= 10) {<br>  document.write('加油coding人<br>')<br>  i++<br>}<br></code></pre> <br><p><strong>改进</strong>：让用户输入打印的个数。</p> <br><pre><code class="language-javascript">let count = +prompt('请输入打印次数：')<br>let i = 1<br>while (i <= count) {<br>  document.write('月薪过万<br>')<br>  i++<br>}<br></code></pre> <br><p><strong>（3）while 练习</strong></p> <br><p>循环练习的通用解题套路：</p> <br><ol><li>先搭三要素骨架：循环变量从几开始（<code>let i = 1</code>）、什么时候停（<code>i <= 100</code>）、每次怎么变（<code>i++</code>）。</li><li>需要"总和"就准备一个<strong>累加器</strong>，初始值必须是 0（<code>let sum = 0</code>），循环体里反复 <code>sum += i</code>。</li><li><strong>注意循环体内部的顺序</strong>：先用<strong> i 干活（累加、判断），最后再 <code>i++</code></strong>。如果先自增再累加，会从 2 加到 101，结果错误。</li><li>只统计偶数：在循环体里加 <code>if (i % 2 === 0)</code> 判断，或简写为 <code>even += i % 2 === 0 ? i : 0</code>。</li><li>循环变量从 0 开始也可以（加 0 不影响总和），但要同步检查循环条件和循环体里的语句顺序。</li></ol> <br><p><strong>练习1</strong>：页面输出 1-100。</p> <br><pre><code class="language-javascript">let i = 1<br>while (i <= 100) {<br>  document.write(`${i}<br>`)<br>  i++<br>}<br></code></pre> <br><p><strong>练习2</strong>：计算 1 加到 100 的总和。</p> <br><pre><code class="language-javascript">let i = 1<br>let sum = 0<br>while (i <= 100) {<br>  sum += i<br>  i++<br>}<br>console.log(sum)   // 5050<br></code></pre> <br><p><strong>练习3</strong>：计算 1-100 之间所有偶数的和。</p> <br><pre><code class="language-javascript">let i = 1<br>let sum = 0<br>while (i <= 100) {<br>  if (i % 2 === 0) {<br>    sum += i<br>  }<br>  i++<br>}<br>console.log(sum)   // 2550<br></code></pre> <br><p>一次循环同时求总和与偶数和的写法（注意顺序：<strong>先累加，后自增</strong>）：</p> <br><pre><code class="language-javascript">let num = 1<br>let sum = 0<br>let even = 0<br>while (num <= 100) {<br>  sum += num                          // 先加当前的 num<br>  even += num % 2 === 0 ? num : 0     // 是偶数就加 num，否则加 0<br>  num++                               // 最后再变化<br>}<br>console.log(sum)   // 5050<br>console.log(even)  // 2550<br></code></pre> <br><blockquote> <br> <p>反例：如果写成先 <code>num++</code> 再 <code>sum += num</code>，累加的就是 2~101，总和会变成 5150。</p> <br></blockquote> <br><h5 id="2.3.3%20%E5%BE%AA%E7%8E%AF%E9%80%80%E5%87%BA" name="2.3.3%20%E5%BE%AA%E7%8E%AF%E9%80%80%E5%87%BA" }<br>}<br></code></pre> <br><h3 id="%E4%B8%89%E3%80%81%E7%BB%BC%E5%90%88%E6%A1%88%E4%BE%8B%20%E2%80%94%E2%80%94%20%E7%AE%80%E6%98%93%20ATM%20%E5%8F%96%E6%AC%BE%E6%9C%BA"
