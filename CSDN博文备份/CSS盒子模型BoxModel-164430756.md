中，盒子分为两种主要类型，它们在页面中的表现截然不同。</p> <br><table><thead><tr><th>特性</th><th>区块盒子（Block Box）</th><th>行内盒子（Inline 空间</td><td>由内容撑开</td></tr><tr><td><strong>内边距/外边距</strong></td><td>上下左右内外边距都生效</td><td><strong>垂直方向</strong>（上下）的内外边距<strong>不起效果</strong>；<br /> <strong>水平方向</strong>（左右）的内外边距有效</td></tr><tr><td><strong>常见标签</strong></td><td><code><div></code>、<code><p></code>、<code><h></code>、<code><ul></code>、<code><table></code></td><td><code><span></code>、<code><em></code>、<code><a></code>、<code><strong></code></td></tr></tbody></table> <br><blockquote> <br> <p><strong>小总结</strong>：块级独占一行，宽高有效；行内并排显示，宽高无效，垂直内外边距无效。</p> <br></blockquote> <br><h3 name="%E4%BA%8C%E3%80%81%E7%9B%92%E5%AD%90%E6%A8%A1%E5%9E%8B%E7%9A%84%E5%9B%9B%E5%A4%A7%E7%BB%84%E6%88%90%E9%83%A8%E5%88%86">二、盒子模型的四大组成部分</h3> <br><p>一个完整的盒子由内到外包含四部分：<strong>内容（Content）</strong> → <strong>内边距（Padding）</strong> → <strong>边框（Border）</strong> → <strong>外边距（Margin）</strong>。</p> <br><ol><li><strong>内容（Content）</strong>：显示文字、图片的区域。大小由 <code>width</code> / <code>height</code> 或内容本身撑开。</li><li><strong>内边距（Padding）</strong>：内容区域到边框之间的<strong>内部</strong>间距。</li><li><strong>边框（Border）</strong>：包裹内容和内边距的边界线。</li><li><strong>外边距（Margin）</strong>：盒子<strong>外部</strong>与其他元素之间的间距（不可见）。</li></ol> <br><h3 id="%E4%B8%89%E3%80%81%E8%BE%B9%E6%A1%86%EF%BC%88Border%EF%BC%89" name="%E4%B8%89%E3%80%81%E8%BE%B9%E6%A1%86%EF%BC%88Border%EF%BC%89">三、边框（Border）</h3> <br><h4 <br><h4 id="2.%20%E5%9B%9B%E4%B8%AA%E6%96%B9%E5%90%91%E5%8D%95%E7%8B%AC%E8%AE%BE%E7%BD%AE" name="2.%20%E5%9B%9B%E4%B8%AA%E6%96%B9%E5%90%91%E5%8D%95%E7%8B%AC%E8%AE%BE%E7%BD%AE">2. 四个方向单独设置</h4> <br><p>根据方位名词 <code>top</code>（上）、<code>bottom</code>（下）、<code>left</code>（左）、<code>right</code>（右）分别控制。</p> <br><pre><code class="language-css">div {<br>    border-top: 1px solid pink;     /* 只设上边框 */<br>    border-bottom: 2px solid #000;  /* 只设下边框（常用作分割线） */<br>    border-left: none;              /* 取消左边框 */<br>    border-right: 1px dashed #ccc;<br>}<br></code></pre> <br><h3 name="%E5%9B%9B%E3%80%81%E5%9C%86%E8%A7%92%E8%BE%B9%E6%A1%86%EF%BC%88Border-radius%EF%BC%89">四、圆角边框（Border-radius）</h3> <br><p><code>border-radius</code> 允许设置元素的外边框圆角，让盒子更精致。</p> <br><h4 */<br>}<br></code></pre> <br><h4 id="2.%20%E7%89%B9%E6%AE%8A%E5%BD%A2%E7%8A%B6" name="2.%20%E7%89%B9%E6%AE%8A%E5%BD%A2%E7%8A%B6">2. 特殊形状</h4> <p>不需要圆角的角设置为 <code>0</code> 即可。</p> <br></blockquote> <br><h3 id="%E4%BA%94%E3%80%81%E5%86%85%E8%BE%B9%E8%B7%9D%EF%BC%88Padding%EF%BC%89" name="%E4%BA%94%E3%80%81%E5%86%85%E8%BE%B9%E8%B7%9D%EF%BC%88Padding%EF%BC%89">五、内边距（Padding）</h3> <br><p>内边距位于<strong>边框和内容区域之间</strong>，用于让内容不要紧贴边框，更美观。</p> <br><h4 class="language-css">div {<br>    padding-top: 10px;<br>    padding-bottom: 10px;<br>    padding-left: 20px;<br>    padding-right: 20px;<br>}<br></code></pre> <br><h3 <br><p>外边距是盒子<strong>外部</strong>不可见的空间，用于推开其他元素，拉开距离。</p> <br><h4 40px;</code></td><td>上10，右20，下30，左40</td></tr></tbody></table> <br><h4 id="2.%20%E5%8D%95%E8%BE%B9%E8%AE%BE%E7%BD%AE" name="2.%20%E5%8D%95%E8%BE%B9%E8%AE%BE%E7%BD%AE">2. 单边设置</h4> <br><pre><code <br><p><strong>条件</strong>：块级盒子必须有宽度，且左右外边距设为 <code>auto</code>。</p> <br><pre><code class="language-css">.box {<br>    width: 200px;<br>    height: 200px;<br>    margin: 0 auto;    /* <p><code>margin：auto；（jd写法，示例为b站写法）</code></p> <br></blockquote> <br><h3 <br><p><strong>现象</strong>：两个并列的块级元素，上下外边距会合并为一个，大小取<strong>较大的那个</strong>。</p> <br><pre><code class="language-css">.box1 { margin-bottom: 30px; }<br>.box2 { margin-top: 20px; }<br>/* 实际两个盒子之间的距离是 30px，而不是 50px */<br></code></pre> <br><p><strong>解决方案</strong>：这是浏览器特性，无需解决。我们只需给其中一个盒子设置单边外边距即可，比如只设置 <code>margin-bottom</code>。</p> <br><h4 id="2.%20%E7%88%B6%E5%AD%90%E5%85%B3%E7%B3%BB%20%E2%80%94%E2%80%94%20%E5%A4%96%E8%BE%B9%E8%B7%9D%E5%A1%8C%E9%99%B7%EF%BC%88%E4%B8%A5%E9%87%8D%E9%97%AE%E9%A2%98%EF%BC%89" name="2.%20%E7%88%B6%E5%AD%90%E5%85%B3%E7%B3%BB%20%E2%80%94%E2%80%94%20%E5%A4%96%E8%BE%B9%E8%B7%9D%E5%A1%8C%E9%99%B7%EF%BC%88%E4%B8%A5%E9%87%8D%E9%97%AE%E9%A2%98%EF%BC%89">2. 父子关系 —— 外边距塌陷（严重问题）</h4> <br><p><strong>现象</strong>：给<strong>子盒子</strong>设置上外边距（<code>margin-top</code>），父盒子会跟着一起往下掉（塌陷）。</p> <br><pre><code class="language-css">/* 父盒子没有边框 */<br>.father { width: 300px; background: pink; }<br>.son { width: 100px; height: 100px; margin-top: 50px; }<br>/* 结果：父盒子带着子盒子一起往下掉了50px */<br></code></pre> <br><p><strong>3 种解决方案</strong>：</p> <br><ol><li><strong>给父盒子添加上边框</strong>（<code>border-top: 1px solid transparent;</code>）。</li><li><strong>给父盒子添加上内边距</strong>（<code>padding-top: 1px;</code>）。</li><li><strong>给父盒子添加 <code>overflow: hidden;</code></strong>（触发 BFC，最推荐）。</li></ol> <br><pre><code class="language-css">.father {<br>    overflow: hidden;   /* 完美解决，无副作用 */<br>}<br></code></pre> <br><h3 id="%E5%85%AB%E3%80%81%E7%9B%92%E5%AD%90%E7%9A%84%E5%B0%BA%E5%AF%B8%E8%AE%A1%E7%AE%97%EF%BC%88Box-sizing%EF%BC%89%20%E2%80%94%E2%80%94%20%E6%A0%B8%E5%BF%83%E9%9A%BE%E7%82%B9" name="%E5%85%AB%E3%80%81%E7%9B%92%E5%AD%90%E7%9A%84%E5%B0%BA%E5%AF%B8%E8%AE%A1%E7%AE%97%EF%BC%88Box-sizing%EF%BC%89%20%E2%80%94%E2%80%94%20%E6%A0%B8%E5%BF%83%E9%9A%BE%E7%82%B9">八、盒子的尺寸计算（Box-sizing） —— 核心难点</h3> <br><p>默认情况下（<code>content-box</code>），<code>width</code> 和 <code>height</code> 只代表<strong>内容区域</strong>的大小。一旦添加了 <code>padding</code> 和 <code>border</code>，整个盒子的可见宽度会<strong>被撑大</strong>，这给布局计算带来很大困扰。</p> <br><h4 id="1.%20%E9%BB%98%E8%AE%A4%E6%A8%A1%E5%BC%8F%EF%BC%9Acontent-box%EF%BC%88%E6%A0%87%E5%87%86%E7%9B%92%E6%A8%A1%E5%9E%8B%EF%BC%89" name="1.%20%E9%BB%98%E8%AE%A4%E6%A8%A1%E5%BC%8F%EF%BC%9Acontent-box%EF%BC%88%E6%A0%87%E5%87%86%E7%9B%92%E6%A8%A1%E5%9E%8B%EF%BC%89">1. 默认模式：content-box（标准盒模型）</h4> <br><pre><code class="language-css">/* 默认值，可以不写 */<br>box-sizing: content-box;<br></code></pre> <br><p><strong>公式</strong>：盒子实际宽度 = <code>width</code> + <code>padding</code> + <code>border</code></p> <br><blockquote> <br> <p>如果你设置 <code>width: 200px; padding: 10px; border: 5px;</code>，最终盒子占据宽度为 <strong>230px（因为上下左右都要加上）</strong>。</p> <br></blockquote> <br><h4 id="2.%20%E6%8E%A8%E8%8D%90%E6%A8%A1%E5%BC%8F%EF%BC%9Aborder-box%EF%BC%88%E6%80%AA%E5%BC%82%E7%9B%92%E6%A8%A1%E5%9E%8B%20%2F%20IE%E7%9B%92%E6%A8%A1%E5%9E%8B%EF%BC%89" name="2.%20%E6%8E%A8%E8%8D%90%E6%A8%A1%E5%BC%8F%EF%BC%9Aborder-box%EF%BC%88%E6%80%AA%E5%BC%82%E7%9B%92%E6%A8%A1%E5%9E%8B%20%2F%20IE%E7%9B%92%E6%A8%A1%E5%9E%8B%EF%BC%89">2. 推荐模式：border-box（怪异盒模型 / IE盒模型）</h4> <br><pre><code class="language-css">box-sizing: border-box;<br></code></pre> <br><p><strong>公式</strong>：盒子实际宽度 = <code>width</code>（已包含 <code>padding</code> 和 <code>border</code>）</p> <br><blockquote> <br> <p>如果你设置 <code>width: 200px; padding: 10px; border: 5px;</code>，最终盒子宽度就是 <strong>200px</strong>。浏览器会自动压缩内容区域来容纳内边距和边框。</p> <br></blockquote> <br><p><strong>实际开发中，几乎都会统一重置为 <code>border-box</code></strong>，这样宽度即所见即所得：</p> <br><pre><code class="language-css">/* 通配符重置，包含伪元素 */<br>*,<br>*::before,<br>*::after {<br>    box-sizing: border-box;<br>}<br></code></pre> <br><h3 id="%E4%B9%9D%E3%80%81%E7%9B%92%E5%AD%90%E8%83%8C%E6%99%AF%EF%BC%88Background%EF%BC%89" name="%E4%B9%9D%E3%80%81%E7%9B%92%E5%AD%90%E8%83%8C%E6%99%AF%EF%BC%88Background%EF%BC%89">九、盒子背景（Background）</h3> <br><p>背景用于装饰盒子，包括颜色、图片、位置等。</p> <br><table><thead><tr><th>属性</th><th>作用</th><th>常用值</th><th>示例</th></tr></thead><tbody><tr><td><code>background-color</code></td><td>背景颜色</td><td>颜色值（十六进制、rgb）</td><td><code>background-color: #f0f0f0;</code></td></tr><tr><td><code>background-image</code></td><td>背景图片</td><td><code>url(图片路径)</code></td><td><code>background-image: url(bg.png);</code></td></tr><tr><td><code>background-repeat</code></td><td>是否重复</td><td><code>repeat</code>（默认）、<code>no-repeat</code>、<code>repeat-x</code>、<code>repeat-y</code></td><td><code>background-repeat: no-repeat;</code></td></tr><tr><td><code>background-position</code></td><td>背景定位</td><td><code>x y</code>（方位词、px、%）</td><td><code>background-position: center top;</code></td></tr><tr><td><code>background-size</code></td><td>背景尺寸</td><td><code>cover</code>（覆盖）、<code>contain</code>（包含）、像素/百分比</td><td><code>background-size: cover;</code></td></tr><tr><td><code>background-attachment</code></td><td>背景固定</td><td><code>scroll</code>（滚动）、<code>fixed</code>（固定）</td><td><code>background-attachment: fixed;</code></td></tr></tbody></table> <br><pre><code class="language-css"><style><br>    .box {<br>      width: 400px;<br>      height: 400px;<br>      background-color: pink;<br>      /* 1.背景图片 */<br>      background-image: url(./img/ldh.png);<br><br>      /* 2.背景平铺 */<br>      background-repeat: no-repeat;<br>      /* 按照左上角水平方向平铺 */<br>      background-repeat: repeat-x;<br>      background-repeat: repeat-y;<br><br>      /* 3.背景位置 */<br>      /* 背景位置center center 表示背景图片居中显示，写一个也可以 */<br>      background-position: center center;<br>      /* 背景位置可以是像素值 */<br>      background-position: 100px 100px;<br>      /* 背景位置可以是百分比 */<br>      background-position: 50% 50%;<br>      /* 背景位置可以是关键字 top left bottom right，如果只写一个，默认是另一方向是center */<br>      background-position: top left;<br><br>      /* 4.背景缩放 */<br>      background-size: cover;<br>      background-size: contain;<br>      /* 背景缩放可以是像素值，写一个默认自适应 */<br>      background-size: 200px 200px;<br>      /* 背景缩放可以是百分比 */<br>      background-size: 50% 50%;<br><br>      /* 5.背景固定 fixed 固定的，相对于当前视口 */<br>      background-attachment: fixed;<br>      /* background-attachment: scroll; */<br><br>      /* 复合写法 */<br>      background: pink url(./img/ldh.png) no-repeat center center / cover fixed;<br>    }<br>  </style><br></code></pre> <br><p><strong>背景复合写法（顺序无强制要求，空格隔开）</strong>：</p> <br><pre><code class="language-css">/* 推荐顺序：颜色 图片 重复 固定 位置/尺寸 */<br>background: #fff url(bg.jpg) no-repeat fixed center/cover;</code></pre> <br><p><strong>背景渐变</strong>：</p> <br><ul><li><strong>线性渐变</strong>：<code>background: linear-gradient(to right, #ff6b6b, #4ecdc4);</code></li><li><strong>径向渐变</strong>：<code>background: radial-gradient(circle, #ff9a9e, #fad0c4);</code></li></ul> <br><p><strong>文字背景渐变（高级技巧）</strong>：</p> <br><pre><code class="language-css">h1 {<br>    background: linear-gradient(to right, pink, red);<br>    -webkit-background-clip: text;   /* 背景裁剪到文字 */<br>    -webkit-text-fill-color: transparent; /* 文字填充变透明 */<br>}<br></code></pre> <br><h3 id="%E5%8D%81%E3%80%81%E7%9B%92%E5%AD%90%E9%98%B4%E5%BD%B1%EF%BC%88Box-shadow%EF%BC%89" name="%E5%8D%81%E3%80%81%E7%9B%92%E5%AD%90%E9%98%B4%E5%BD%B1%EF%BC%88Box-shadow%EF%BC%89">十、盒子阴影（Box-shadow）</h3> <br><p>为盒子添加阴影，增加立体感和交互反馈。</p> <br><p><strong>语法</strong>：<code>box-shadow: X轴偏移 Y轴偏移 模糊半径 扩散半径 颜色;</code></p> <br><ul><li><code>X轴偏移</code> 和 <code>Y轴偏移</code>：<strong>必须写</strong>。</li><li>默认是<strong>外阴影</strong>，若改为内阴影加 <code>inset</code>。</li></ul> <br><pre><code class="language-css">.card {<br>    box-shadow: 0 15px 30px rgba(0, 0, 0, 0.1);<br>}<br>/* 鼠标经过阴影加深（结合过渡） */<br>.card:hover {<br>    box-shadow: 0 20px 40px rgba(0, 0, 0, 0.2);<br>}<br></code></pre> <br><h3 id="%E5%8D%81%E4%B8%80%E3%80%81%E8%BF%87%E6%B8%A1%EF%BC%88Transition%EF%BC%89" name="%E5%8D%81%E4%B8%80%E3%80%81%E8%BF%87%E6%B8%A1%EF%BC%88Transition%EF%BC%89">十一、过渡（Transition）</h3> <br><p>过渡用于在属性值变化时<strong>平滑切换</strong>，而不是瞬间突变。常与 <code>:hover</code> 配合使用。</p> <br><blockquote> <br> <p>过渡写在<strong>盒子</strong>身上：transition 要写在<strong>本身</strong>（<code>.box</code>）而不是 <code>:hover</code> 上，这样鼠标移入、移出两个方向都有动画；写在 <code>:hover</code> 上的话，移开时阴影会瞬间消失。</p> <br></blockquote> <br><p><strong>语法</strong>：<code>transition: 过渡的属性 过渡时间 运动曲线 延迟时间(可选);</code></p> <br><ul><li>过渡时间单位是秒（<code>s</code>），如 <code>0.3s</code>。</li><li>如果所有属性都要过渡，属性写 <code>all</code>。</li></ul> <br><table><thead><tr><th>值</th><th>含义</th><th>效果</th></tr></thead><tbody><tr><td>all</td><td>过渡的属性：哪些属性变化时要产生动画。all 表示所有属性；也可以只写某一个，如 <code>transition: box-shadow 0.5s</code></td><td>鼠标悬停时 box-shadow 出现、移开时消失，都会有动画</td></tr><tr><td>0.5s</td><td>过渡时间：动画持续多久</td><td>阴影淡入淡出共 0.5 秒</td></tr><tr><td>ease-in-out</td><td>运动曲线：速度变化的节奏</td><td>先慢 → 中间快 → 结束又慢</td></tr><tr><td>（没写）</td><td>延迟时间：等多久才开始动画</td><td>可选，不写就是 0，立即开始</td></tr></tbody></table> <br><p>常见运动曲线对比：</p> <br><ul><li>ease — 默认，快进慢出</li><li>linear — 匀速</li><li>ease-in — 慢进快出</li><li>ease-out — 快进慢出</li><li>ease-in-out — 两头慢中间快</li><li>steps(n) — 分步跳变，可以做走马灯或逐帧动画</li></ul> <br><pre><code class="language-css">.box {<br>    width: 100px;<br>    transition: all 0.5s;  /* 所有变化都在0.5秒内完成 */<br>}<br>.box:hover {<br>    width: 200px;          /* 宽度会平滑放大 */<br>}<br></code></pre> <br><h3 id="%E5%8D%81%E4%BA%8C%E3%80%81%E6%96%87%E5%AD%97%E6%BA%A2%E5%87%BA%E6%98%BE%E7%A4%BA%E7%9C%81%E7%95%A5%E5%8F%B7%EF%BC%88%E5%AE%9E%E6%88%98%E5%BF%85%E5%A4%87%EF%BC%89" name="%E5%8D%81%E4%BA%8C%E3%80%81%E6%96%87%E5%AD%97%E6%BA%A2%E5%87%BA%E6%98%BE%E7%A4%BA%E7%9C%81%E7%95%A5%E5%8F%B7%EF%BC%88%E5%AE%9E%E6%88%98%E5%BF%85%E5%A4%87%EF%BC%89">十二、CSS 样式初始化（CSS Reset / Normalize）</h3> <br><h4 id="%E4%B8%80%E3%80%81%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E8%BF%9B%E8%A1%8C%E6%A0%B7%E5%BC%8F%E5%88%9D%E5%A7%8B%E5%8C%96%EF%BC%9F" name="%E4%B8%80%E3%80%81%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E8%BF%9B%E8%A1%8C%E6%A0%B7%E5%BC%8F%E5%88%9D%E5%A7%8B%E5%8C%96%EF%BC%9F">一、为什么要进行样式初始化？</h4> <br><p>浏览器（Chrome、Firefox、Safari、Edge 等）为了能让 HTML 在没有 CSS 的情况下也能“勉强可读”，会给元素附加一套<strong>默认样式</strong>（User Agent Stylesheet）。</p> <br><p>不同浏览器的默认样式并不一致，这会导致同一个网页在不同浏览器中呈现出细微但令人头疼的差异。</p> <br><h4 id="1.%20%E5%B8%B8%E8%A7%81%E7%9A%84%E9%BB%98%E8%AE%A4%E6%A0%B7%E5%BC%8F%E5%B7%AE%E5%BC%82%E7%A4%BA%E4%BE%8B" name="1.%20%E5%B8%B8%E8%A7%81%E7%9A%84%E9%BB%98%E8%AE%A4%E6%A0%B7%E5%BC%8F%E5%B7%AE%E5%BC%82%E7%A4%BA%E4%BE%8B">1. 常见的默认样式差异示例</h4> <br><table><thead><tr><th>元素</th><th>各浏览器默认表现差异</th></tr></thead><tbody><tr><td><code><body></code></td><td>内外边距（<code>margin</code> / <code>padding</code>）大小不一致，有的 8px，有的 10px。</td></tr><tr><td><code><h1></code> ~ <code><h6></code></td><td>默认 <code>font-weight</code> 粗细程度不同，<code>font-size</code> 大小不同。</td></tr><tr><td><code><ul></code> / <code><ol></code></td><td>默认 <code>padding-left</code> 缩进值不同（有的 40px，有的 20px），<code>list-style-type</code>（项目符号样式）也有细微区别。</td></tr><tr><td><code><a></code></td><td>链接默认颜色、下划线样式在各浏览器中一致（通常蓝色+下划线），但激活态（<code>:active</code>）表现不同。</td></tr><tr><td><code><button></code> / <code><input></code></td><td>边框（<code>border</code>）、背景（<code>background</code>）、内边距（<code>padding</code>）在各浏览器中差异极大。</td></tr></tbody></table> <br><h4 id="2.%20%E5%88%9D%E5%A7%8B%E5%8C%96%E7%9A%84%E6%A0%B8%E5%BF%83%E7%9B%AE%E7%9A%84" name="2.%20%E5%88%9D%E5%A7%8B%E5%8C%96%E7%9A%84%E6%A0%B8%E5%BF%83%E7%9B%AE%E7%9A%84">2. 初始化的核心目的</h4> <br><ol><li><strong>统一浏览器默认样式</strong>：确保页面在所有浏览器中以相同的外观起步，消除环境差异。</li><li><strong>减少冗余代码</strong>：不需要在每个组件中重复写 <code>margin: 0;</code> 来覆盖默认值。</li><li><strong>提高代码可维护性</strong>：基于一个干净、一致的基准样式进行开发，避免诡异的“浏览器玄学”Bug。</li></ol> <br><h3 id="%E4%BA%8C%E3%80%81%E4%B8%A4%E7%A7%8D%E5%88%9D%E5%A7%8B%E5%8C%96%E6%96%B9%E6%A1%88" name="%E4%BA%8C%E3%80%81%E4%B8%A4%E7%A7%8D%E5%88%9D%E5%A7%8B%E5%8C%96%E6%96%B9%E6%A1%88">二、两种初始化方案</h3> <br><p>根据项目规模和需求，我们有两种主流方案：<strong>简单重置（适合小白练手/小型项目）</strong> 和 <strong>引入 Normalize.css（适合中大型/生产项目）</strong>。</p> <br><h4 id="%E6%96%B9%E6%A1%88%E4%B8%80%EF%BC%9A%E7%AE%80%E5%8D%95%E9%87%8D%E7%BD%AE%EF%BC%88%E7%AE%80%E5%8D%95%E7%B2%97%E6%9A%B4%E5%9E%8B%EF%BC%89" name="%E6%96%B9%E6%A1%88%E4%B8%80%EF%BC%9A%E7%AE%80%E5%8D%95%E9%87%8D%E7%BD%AE%EF%BC%88%E7%AE%80%E5%8D%95%E7%B2%97%E6%9A%B4%E5%9E%8B%EF%BC%89">方案一：简单重置（简单粗暴型）</h4> <br><ul><li><strong>核心思想</strong>：使用通配符选择器 <code>*</code>，强制抹平所有元素的内外边距，并手动将常用的块级标签重置为视觉统一的样式。</li><li><strong>适用场景</strong>：个人练习、后台管理界面、对设计还原度要求不高的小型项目。</li></ul> <br><pre><code class="language-css">/* 1. 去除所有元素默认的内外边距（最核心） */<br>* {<br>    margin: 0;<br>    padding: 0;<br>}<br>/* 2. 取消列表（ul/ol）默认的项目符号和序号 */<br>ul,<br>ol {<br>    list-style: none;<br>}<br>/* 3. 取消链接默认的下划线 */<br>a {<br>    text-decoration: none;<br>}<br>/* 4. 取消标题默认的加粗（让标题回归普通文本粗细，方便统一控制） */<br>h1,<br>h2,<br>h3,<br>h4,<br>h5,<br>h6 {<br>    font-weight: 400;<br>}<br>/* 5. 取消 em / i 默认的斜体（如果需要斜体则用 font-style: italic 单独声明） */<br>em,<br>i {<br>    font-style: normal;<br>}<br>/* 6. 给 body 一个基础字体和颜色，统一全站文字基调 */<br>body {<br>    font-size: 16px;<br>    font-family: "Microsoft YaHei", Arial, sans-serif;<br>    color: #333;<br>}</code></pre> <br><blockquote> <br> <p><strong>⚠️ 注意</strong>：虽然通配符 <code>*</code> 方便，但<strong>性能较差</strong>（它会遍历匹配所有元素）。在大型项目中，我们极少这样写，而是使用更优的方案二。</p> <br></blockquote> <br><h4 id="%E6%96%B9%E6%A1%88%E4%BA%8C%EF%BC%9ANormalize.css%EF%BC%88%E6%8E%A8%E8%8D%90%EF%BC%8C%E7%94%9F%E4%BA%A7%E7%8E%AF%E5%A2%83%E6%A0%87%E5%87%86%EF%BC%89" name="%E6%96%B9%E6%A1%88%E4%BA%8C%EF%BC%9ANormalize.css%EF%BC%88%E6%8E%A8%E8%8D%90%EF%BC%8C%E7%94%9F%E4%BA%A7%E7%8E%AF%E5%A2%83%E6%A0%87%E5%87%86%EF%BC%89">方案二：Normalize.css（推荐，生产环境标准）</h4> <br><ul><li><strong>核心思想</strong>：<strong>保留有用的默认样式</strong>，而不是彻底抹平。 <br>  <ul><li>例如：<code><h1></code> 默认就是大标题，<code><b></code> 默认就是加粗。Normalize.css 并不会把它们强制改成普通文本，而是修复各浏览器中这些默认样式的具体数值偏差。</li><li>这意味着你不需要完全重写所有标签，<strong>页面在未加载 CSS 时依然拥有良好的语义化可读性</strong>。</li></ul> </li></ul> <br><ul><li><strong>使用方式</strong>：直接从官网下载，或通过 CDN 引入，像外部样式表一样在 HTML 中作为<strong>第一个</strong>样式文件引入。</li></ul> <br><p><strong>在 <code><head></code> 中的引入顺序</strong>：</p> <br><pre><code class="language-html"><!DOCTYPE html><br><html lang="zh-CN"><br><head><br>    <meta charset="UTF-8"><br>    <meta name="viewport" content="width=device-width, initial-scale=1.0"><br>    <!-- 1. 最先引入 Normalize.css（修复浏览器差异） --><br>    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/normalize/8.0.1/normalize.min.css"><br>    <!-- 2. 再引入你自己的项目公共样式（覆盖/追加你的业务逻辑） --><br>    <link rel="stylesheet" href="./css/style.css"><br>    <title>我的项目</title><br></head><br></code></pre> <br><ul><li><strong>官网下载</strong>：<a href="https://necolas.github.io/normalize.css/" title="Normalize.css: Make browsers render all elements more consistently." rel="nofollow">Normalize.css: Make browsers render all elements more consistently.</a></li><li>Vue.js 官方文档、GitHub、Twitter 等大量顶级网站都在使用 Normalize.css 作为初始化基底。</li></ul> <br><h3 id="%E5%B7%A5%E4%BD%9C%E6%B5%81%E7%A8%8B%E6%80%BB%E7%BB%93%EF%BC%88%E7%9C%9F%E5%AE%9E%E5%BC%80%E5%8F%91%E4%B9%A0%E6%83%AF%EF%BC%89" name="%E5%B7%A5%E4%BD%9C%E6%B5%81%E7%A8%8B%E6%80%BB%E7%BB%93%EF%BC%88%E7%9C%9F%E5%AE%9E%E5%BC%80%E5%8F%91%E4%B9%A0%E6%83%AF%EF%BC%89">工作流程总结（真实开发习惯）</h3> <br><ol><li><strong>新建项目</strong> → 第一时间去找 Normalize.css（复制其核心代码或 CDN 引入）。</li><li><strong>作为全局基底</strong> → 把它放在所有自定义 CSS 的<strong>最前面</strong>。</li><li><strong>再写公共样式</strong> → 在 <code>style.css</code> 中再去设置 <code>body</code> 的基础字体、背景色、通用工具类等。</li></ol> <br><p>这样一来，你的页面就不会被不同浏览器的“出厂设置”干扰，所有样式运行都在你自己的控制之下。</p>
