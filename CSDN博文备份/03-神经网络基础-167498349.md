<br><h2 id="%E4%B8%80%E3%80%81%E4%BB%80%E4%B9%88%E6%98%AF%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E2%80%94%E2%80%94%E4%BB%8E%E7%94%9F%E7%89%A9%E7%A5%9E%E7%BB%8F%E5%85%83%E5%88%B0%E6%95%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B" name="%E4%B8%80%E3%80%81%E4%BB%80%E4%B9%88%E6%98%AF%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E2%80%94%E2%80%94%E4%BB%8E%E7%94%9F%E7%89%A9%E7%A5%9E%E7%BB%8F%E5%85%83%E5%88%B0%E6%95%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B">一、什么是神经网络——从生物神经元到数学模型</h2> <br><h4 id="1.1%20%E7%94%9F%E7%89%A9%E7%A5%9E%E7%BB%8F%E5%85%83%E7%9A%84%E5%B7%A5%E4%BD%9C%E6%9C%BA%E5%88%B6" name="1.1%20%E7%94%9F%E7%89%A9%E7%A5%9E%E7%BB%8F%E5%85%83%E7%9A%84%E5%B7%A5%E4%BD%9C%E6%9C%BA%E5%88%B6">1.1 生物神经元的工作机制</h4> <br><p><strong>人工神经网络（Artificial Neural Network，ANN）</strong> 也简称为<strong>神经网络（Neural Network，NN）</strong>，是一种模仿生物神经网络结构和功能的计算模型。</p> <br><p>人脑可以看作一个生物神经网络，由约 860 亿个神经元连接而成。每个神经元的工作流程：</p> <br><p class="img-center"><img alt="" height="437" src="https://i-blog.csdnimg.cn/direct/744d1c9800454a2c91d8eead460571be.webp" width="600" /></p> <br><table><thead><tr><th>生物部件</th><th>做什么</th><th>对应人工神经元的部件</th></tr></thead><tbody><tr><td><strong>树突(Dendrites)</strong></td><td>接收来自其他神经元的输入信号</td><td>输入 x（特征）</td></tr><tr><td><strong>突触(</strong>Synapse / Synapses<strong>)</strong></td><td>连接强度有强有弱</td><td>权重 w</td></tr><tr><td><strong>细胞体（细胞核）(</strong>Cell body (nucleus) / Soma (nucleus)<strong>)</strong></td><td>汇总信号，逐渐聚集电荷，达到电位阈值就被激活</td><td>加权求和 z + 激活函数 f</td></tr><tr><td><strong>轴突(</strong>Axon<strong>)</strong></td><td>把结果输出给下一个神经元</td><td>输出 a</td></tr></tbody></table> <br><h4 id="1.2%20%E5%8D%95%E4%B8%AA%E7%A5%9E%E7%BB%8F%E5%85%83%E7%9A%84%E6%95%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B" name="1.2%20%E5%8D%95%E4%B8%AA%E7%A5%9E%E7%BB%8F%E5%85%83%E7%9A%84%E6%95%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B">1.2 单个神经元的数学模型</h4> <br><p><strong>构建神经网络就是在构建神经元</strong>。把上表的生物流程翻译成数学，一个神经元干两件事：</p> <br><p class="img-center"><img alt="" height="207" src="https://i-blog.csdnimg.cn/direct/8061a7b657824c9e94403f286f8fef9a.png" width="330" /></p> <br><pre><code class="language-python">输入 x₁, x₂, ..., xₙ<br>    ↓<br>① 加权求和（线性）：z = b + Σ(xᵢ · wᵢ)<br>    ↓<br>② 激活函数（非线性）：a = f(z)<br>    ↓<br>输出 a<br></code></pre> <br><p><strong>数值示例</strong>：设输入 x₁=2, x₂=3，权重 w₁=0.5, w₂=-1，偏置 b=1：</p> <br><ul><li>① 加权求和：z = 1 + (2×0.5) + (3×(-1)) = 1 + 1 - 3 = <strong>-1</strong></li><li>② 激活（假设用 Sigmoid）：a = f(-1) = 1/(1+e¹) ≈ <strong>0.269</strong></li></ul> <br><h4 id="1.3%20%E5%A4%9A%E4%B8%AA%E7%A5%9E%E7%BB%8F%E5%85%83%E6%9E%84%E6%88%90%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%EF%BC%9A%E4%B8%89%E5%B1%82%E7%BB%93%E6%9E%84" name="1.3%20%E5%A4%9A%E4%B8%AA%E7%A5%9E%E7%BB%8F%E5%85%83%E6%9E%84%E6%88%90%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%EF%BC%9A%E4%B8%89%E5%B1%82%E7%BB%93%E6%9E%84">1.3 多个神经元构成神经网络：三层结构</h4> <br><p class="img-center"><img alt="" height="296" src="https://i-blog.csdnimg.cn/direct/92e2a457f4a340ae958f035aeff60d84.png" width="600" /></p> <br><p>单个神经元能力有限，把多个神经元按层组织起来就是神经网络：</p> <br><table><thead><tr><th>层</th><th>说明</th></tr></thead><tbody><tr><td><strong>输入层（Input Layer）</strong></td><td>即输入 x 的那一层（图像、文本、声音等）。有几个输入特征，输入层就有几个神经元。输入层只负责<strong>传递数据，不做计算</strong></td></tr><tr><td><strong>隐藏层（Hidden Layers）</strong></td><td>输入层和输出层之间的所有层。神经网络的"深度"由隐藏层数量决定。每个隐藏神经元 = 一次"加权和 + 激活"</td></tr><tr><td><strong>输出层（Output Layer）</strong></td><td>即输出 y 的那一层，根据任务（回归、二分类、多分类）生成最终预测结果</td></tr></tbody></table> <br><p>结构示意（相邻层之间两两全连接，每个连接上有一个权重 w）：</p> <br><p class="img-center"><img alt="" height="276" src="https://i-blog.csdnimg.cn/direct/de1f03216c9c42b693a13c6e6e89e8a9.png" width="400" /></p> <br><pre><code>输入层(3个特征)      隐藏层(3个神经元)     输出层(2个神经元)<br>   x₁ ──────┬──────→  h₁  ──┬──────→  o₁<br>            ├────────→  h₁  ──┤<br>   x₂ ──────┼──────→  h₂  ──┼──────→  o₂<br>            ├────────→  h₂  ──┤<br>   x₃ ──────┴──────→  h₃  ──┴────<br></code></pre> <br><p>关键规则：</p> <br><ul><li>相邻层之间的神经元相互连接，每个<strong>连接分配一个强度（权重 w）</strong></li><li>前一层神经元的输出 = 后一层神经元的输入（信息逐层向前流动）</li><li>信息只沿一个方向移动：输入层 → 隐藏层 → 输出层</li><li>同一层的多个神经元并行处理相同的输入，各自学习输入数据的不同特征——每个神经元关注的部分不同，合起来才能捕捉数据的完整属性</li></ul> <br><blockquote> <br> <p><strong>注意</strong>:构建单层神经元不是越多越好。传统全连接网络常见"漏斗形"（前面宽、后面窄），像逐层压缩信息、提炼特征，这是<strong>经验设计</strong>而非定理；</p> <br> <p>现代网络（如 Transformer）每层宽度相同也很常见。层数/宽度要和任务、数据量匹配，盲目加宽会过拟合且费算力。</p> <br></blockquote> <br><h4 id="1.4%20%E5%85%A8%E8%BF%9E%E6%8E%A5%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E7%9A%84%E7%89%B9%E7%82%B9" name="1.4%20%E5%85%A8%E8%BF%9E%E6%8E%A5%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E7%9A%84%E7%89%B9%E7%82%B9">1.4 全连接神经网络的特点</h4> <br><ul><li><strong>同一层的神经元之间没有连接</strong>，相互隔离</li><li><strong>第 N 层的每个神经元与第 N-1 层的所有神经元相连</strong>——这就是 "fully connected（全连接）" 的含义</li><li>第 N-1 层神经元的输出就是第 N 层神经元的输入</li><li>每个连接都有一个权重 w，每个神经元还有一个偏置 b</li><li>全连接网络接收的样本数据是<strong>二维</strong>的（样本数 × 特征数），数据在层与层之间也以二维形式传递（呼应《02-PyTorch框架进阶》3.11 的 (2,5)·(5,3)+b）</li></ul> <br><p><br> </p> <br><blockquote> <br> <p><strong>疑问解答：为什么单独强调"全连接"？</strong></p> <br> <table><thead><tr><th>疑问</th><th>解答</th></tr></thead><tbody><tr><td>难道有<strong>不是全连接</strong>的神经网络吗？</td><td> <p>有，而且很多——全连接只是神经网络家族中的一种"连接方式"。</p> <p>卷积神经网络 CNN：局部连接 + 权重共享，每个神经元只看输入的一小块区域；</p> <p>循环神经网络 RNN：带"环"，隐藏状态跨时间步传递；</p> <p>Transformer：注意力动态连接。</p> <p>课程后面会学 CNN/RNN，它们会打破"N 层连 N-1 层全部"这条规则——所以现在要把全连接的规则单独列清楚</p> </td></tr><tr><td>全连接代价是什么？</td><td>参数量最大。例：100×100 图像有 1 万个像素，第一层只放 1000 个神经元，权重就是 1000 万个——CNN 就是为了砍这个参数量而发明的</td></tr><tr><td>和 1.1~1.3 讲的神经网络有区别吗？</td><td>没有区别。1.1~1.3 讲的"神经网络"默认就是全连接神经网络：1.2 的神经元数学模型 + 1.3 的三层结构 + 1.4 的连接规则 = 一个完整的全连接网络。1.4 只是把"全连接"这个名字背后的规则单独拎出来讲</td></tr><tr><td>和<strong>感知机</strong>是什么关系？</td><td>感知机（Perceptron，1958）是只有一层的最早网络：输入→输出一个神经元，z=w·x+b 后用<strong>阶跃激活</strong>（≥0 输出 1，否则 0）——它连"异或"这种线性不可分问题都拟合不了，且阶跃不可微、无法用 BP 训练。把感知机堆出隐藏层 + 换成可微激活函数（Sigmoid/ReLU），就升级成<strong>多层感知机（MLP）——它就是全连接神经网络的另一个名字</strong>。演进线：感知机（单层、阶跃）→ MLP/全连接网络（多层、可微）→ CNN/RNN（连接方式改进）</td></tr><tr><td>为什么要强调"全连接"？</td><td> <p>① 它是参数最多的"满配"结构，是理解其他网络的基准（CNN 是在它基础上做减法）；② 4.4 的参数量公式 fan_in×fan_out+fan_out 只对全连接层成立；</p> <p>③ 术语上 <code>nn.Linear</code> 层 = 全连接层 = FC 层，第九章案例里说的"3 个全连接层"就是它</p> </td></tr></tbody></table> <br></blockquote> <br><h4 id="1.5%20%E5%86%85%E9%83%A8%E7%8A%B6%E6%80%81%E5%80%BC%20z%20%E4%B8%8E%E6%BF%80%E6%B4%BB%E5%80%BC%20a" name="1.5%20%E5%86%85%E9%83%A8%E7%8A%B6%E6%80%81%E5%80%BC%20z%20%E4%B8%8E%E6%BF%80%E6%B4%BB%E5%80%BC%20a">1.5 内部状态值 z 与激活值 a</h4> <br><p>每一个神经元工作时，前向传播会产生两个值；反向传播时对应产生两个梯度：</p> <br><table><thead><tr><th>概念</th><th>公式</th><th>说明</th></tr></thead><tbody><tr><td><strong>内部状态值 z</strong></td><td><code>z = W·x + b</code></td><td>加权求和的结果，反映该神经元接收到的<strong>输入与权重计算</strong>的结果</td></tr><tr><td><strong>激活值 a</strong></td><td><code>a = f(z)</code></td><td>激活函数对 z 做<strong>非线性变换</strong>后的结果，决定该神经元的最终输出</td></tr></tbody></table> <br><p>公式中：<code>W</code> 权重矩阵、<code>x</code> 输入、<code>b</code> 偏置、<code>f</code> 激活函数。</p> <br><blockquote> <br> <p>z 是"攒够的电荷"，a 是"放出的信号"——激活函数就是把 z 变成 a 的那道闸门。下一章专门讲它。</p> <br></blockquote> <br><h3 id="%E4%BA%8C%E3%80%81%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%E2%80%94%E2%80%94%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%22%E6%8B%90%E4%B8%AA%E5%BC%AF%22" name="%E4%BA%8C%E3%80%81%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%E2%80%94%E2%80%94%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%22%E6%8B%90%E4%B8%AA%E5%BC%AF%22">二、激活函数——为什么要"拐个弯"</h3> <br><h4 id="2.1%20%E4%B8%BA%E4%BB%80%E4%B9%88%E5%BF%85%E9%A1%BB%E6%9C%89%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%EF%BC%88%E9%9D%9E%E7%BA%BF%E6%80%A7%EF%BC%89" name="2.1%20%E4%B8%BA%E4%BB%80%E4%B9%88%E5%BF%85%E9%A1%BB%E6%9C%89%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%EF%BC%88%E9%9D%9E%E7%BA%BF%E6%80%A7%EF%BC%89">2.1 为什么必须有激活函数（非线性）</h4> <br><p><strong>激活函数对每层的输出做变换，为网络注入非线性因素</strong>，使神经网络可以拟合各种曲线。</p> <br><p>如果不加激活函数会怎样？多层线性叠加仍然是线性。它可以被提取公因式、合并成一个权重：</p> <br><pre><code class="language-python">第1层: z₁ = w₁·x          （w₁ = 3）<br>第2层: z₂ = w₂·z₁         （w₂ = 2）<br>合并:  z₂ = w₂·(w₁·x) = (w₂·w₁)·x = 6·x<br></code></pre> <br><p>数值验证：两层网络 2×(3x) = 6x——无论叠多少层线性变换，等价于一个权重为 6 的<strong>单层</strong>线性模型。所以：</p> <br><ol><li><strong>没有非线性因素的网络，等价于一个线性模型</strong>（《00-深度学习简介》：线性模型连"异或"这种简单关系都拟合不了）</li><li>加了激活函数，网络就能<strong>逼近任意函数</strong>，拟合能力大幅提升</li></ol> <br><p>激活函数拐了弯（非线性），<code>f(2·(3x))</code> 就没法合并成 <code>6x</code> 了——网络的"深"才有了意义。</p> <br><p>另外还有一个隐藏要求：激活函数必须可微。因为网络参数更新使用的是反向传播算法（BP），梯度要沿着计算链一路求导传回去（《02》第三章手推过），不可微的函数（如 Binary step 阶跃函数）算不出梯度，BP 就走不通——这也是 2.2 起每个激活函数都配一个导数公式的原因。</p> id="2.2%20Sigmoid%E2%80%94%E2%80%94%E6%8A%8A%E4%BB%BB%E6%84%8F%E6%95%B0%E5%8E%8B%E8%BF%9B%20(0%2C1)" name="2.2%20Sigmoid%E2%80%94%E2%80%94%E6%8A%8A%E4%BB%BB%E6%84%8F%E6%95%B0%E5%8E%8B%E8%BF%9B%20(0%2C1)">2.2 Sigmoid——把任意数压进 (0,1)</h4> <br><p><strong id="mwEw">S形函数(</strong>Sigmoid<strong>)</strong>是指其<a href="https://en.wikipedia.org/wiki/Graph_of_a_function" id="mwFQ" title="图" rel="nofollow">图</a>具有特征性S形<strong id="mwFg">或S形曲线</strong>的任何<a href="https://en.wikipedia.org/wiki/Mathematical_function" id="mwFA" title="数学函数" rel="nofollow">数学函数</a>。</p> <br><p class="img-center"><img alt="" height="285" src="https://i-blog.csdnimg.cn/direct/542276f8bf464f0db2e81f2c570305d9.png" width="500" /></p> <br><p><strong>公式</strong>：</p> <br><p class="img-center"><img alt="" height="40" src="https://i-blog.csdnimg.cn/direct/3b480a19c2824a88869bb58a4641d407.png" width="100" /></p> <br><pre><code class="language-python">f(x) = 1 / (1 + e^(-x))<br></code></pre> <br><p>曲线行为：x 越大输出越接近 1，x 越小（越负）输出越接近 0，x=0 时输出 0.5。</p> <br><p><strong>导数</strong>（反向传播要用）：</p> <br><p class="img-center"><img alt="" height="53" src="https://i-blog.csdnimg.cn/direct/ae2ce2fa73c44f538b861bad67572748.png" width="600" /></p> <br><pre><code class="language-python">f'(x) = f(x) · (1 - f(x))<br></code></pre> <br><blockquote> <br> <p><strong>导数公式怎么来的</strong>：设 u = 1 + e^(-x)，f = u⁻¹。</p> <br> <p>链式法则：f' = -u⁻² · u' = -u⁻² · (-e^(-x)) = e^(-x)/(1+e^(-x))²。而 f(x) = 1/(1+e^(-x))、1-f(x) = e^(-x)/(1+e^(-x))，两式相乘正好等于上式——所以 f' = f(x)(1-f(x))。</p> <br></blockquote> <br><p><strong>导数最大值 0.25 的推导</strong>：f' = f(1-f) 是关于 f 的二次函数，在 f=0.5（即 x=0）时取最大：0.5 × 0.5 = <strong>0.25</strong>。所以 Sigmoid 的导数范围是 (0, 0.25]。</p> <br><p><strong>特点</strong>：</p> <br><ul><li>将任意输入映射到 <strong>(0, 1)</strong> 之间，天然适合表示概率</li><li>输入在 [-6, 6] 之间输出才有明显差异，[-3, 3] 之间效果较好；输入 < -6 或 > 6 时，无论输入啥激活值都差不多，会丢失信息——比如输入 100 和输入 10000，Sigmoid 的激活值几乎都等于 1，但两者相差 100 倍的信息就丢了 <br>  <blockquote> <br>   <p><strong>提示</strong>:这个区间不是谁规定的，是算出来的：x=±6 时 f≈0.9975/0.0025，已经贴着 0 和 1（曲线几乎水平 ）；x=±3 时 f≈0.95/0.05，再往外就基本不变了。看曲线/代入数值就能得到这个经验区间</p> <br>  </blockquote> </li><li>导数范围 (0, 0.25]，当输入 < -6 或 > 6 时导数接近 0，网络参数更新极其缓慢甚至无法更新</li><li><strong>Sigmoid 网络一般在 5 层之内就会梯度消失</strong>——机理：反向传播时梯度要逐层相乘，每层最多乘 0.25，5 层后最多剩 0.25⁵ ≈ 0.001，梯度缩到千分之一，靠前的层几乎学不到东西（这就是"梯度消失"）</li><li><strong>不以 0 为中心</strong>（输出全为正），导致权重更新方向总是"同涨同跌"、走 Z 字形，收敛变慢</li><li>一般只用于二分类的输出层（把输出当概率），隐藏层基本不用</li></ul> <br><h4 id="2.3%20Tanh%E2%80%94%E2%80%94%E4%BB%A5%200%20%E4%B8%BA%E4%B8%AD%E5%BF%83%E7%9A%84%20Sigmoid" name="2.3%20Tanh%E2%80%94%E2%80%94%E4%BB%A5%200%20%E4%B8%BA%E4%B8%AD%E5%BF%83%E7%9A%84%20Sigmoid" style="background-color:transparent">2.3 Tanh——以 0 为中心的 Sigmoid</h4> <br><p class="img-center"><img alt="" height="339" src="https://i-blog.csdnimg.cn/direct/a9ac9aae6eed46b4a78658209f37e718.png" width="450" /></p> <br><p><strong>公式</strong>：</p> <br><p class="img-center"><img alt="" height="54" src="https://i-blog.csdnimg.cn/direct/d8f4a7298c6b418c86f9b69b41005159.png" width="150" /></p> <br><pre><code class="language-python">f(x) = (1 - e^(-2x)) / (1 + e^(-2x))<br></code></pre> <br><blockquote> <br> <p>x→+∞ 时 e^(-2x)→0，分子→1、分母→1，f→<strong>1</strong>；</p> <br> <p>x→-∞ 时 e^(-2x)→+∞，分子≈-e^(-2x)、分母≈e^(-2x)，f→<strong>-1</strong>。</p> <br> <p>数值例：x=3 时 e⁻⁶≈0.0025，f=(1-0.0025)/(1+0.0025)≈0.995。</p> <br></blockquote> <br><p><strong>导数</strong>：</p> <br><p class="img-center"><img alt="" height="40" src="https://i-blog.csdnimg.cn/direct/196fc7ecf698413994e82895f4ec13a3.png" width="300" /></p> <br><pre><code class="language-python">f'(x) = 1 - f²(x)<br></code></pre> <br><p><strong>特点</strong>：</p> <br><ul><li>将输入映射到 <strong>(-1, 1)</strong> 之间</li><li><strong>以 0 为中心</strong>，关于原点对称——权重更新方向可以分开，收敛更稳</li><li>当输入 ≈ < -3 或 > 3 时，输出被"压平"为 -1 或 1</li><li>导数范围 <strong>(0, 1]</strong>（x=0 时最大 1）；输入 < -3 或 > 3 时导数近似 0</li><li>与 Sigmoid 相比：以 0 为中心 + 平均梯度更大，<strong>收敛更快、迭代次数更少</strong></li><li>但两侧导数同样趋于 0，<strong>深层仍会梯度消失</strong></li><li>经验用法：隐藏层用 tanh，输出层（二分类）用 sigmoid</li></ul> <br><h4 id="2.4%20ReLU%E2%80%94%E2%80%94%E6%9C%80%E5%B8%B8%E7%94%A8%E7%9A%84%22%E6%95%B4%E6%B5%81%E5%99%A8%22" name="2.4%20ReLU%E2%80%94%E2%80%94%E6%9C%80%E5%B8%B8%E7%94%A8%E7%9A%84%22%E6%95%B4%E6%B5%81%E5%99%A8%22">2.4 ReLU——最常用的"整流器"</h4> <br><p class="img-center"><img alt="" height="210" src="https://i-blog.csdnimg.cn/direct/326ed0d0e8f04d699f2182f3353d5872.png" width="600" /></p> <br><p><strong>公式</strong>：</p> <br><p class="img-center"><img alt="" height="32" src="https://i-blog.csdnimg.cn/direct/3c09f14e733b47b992fe316278106a96.png" width="150" /></p> <br><pre><code class="language-python">f(x) = max(0, x)<br></code></pre> <br><p>行为：小于 0 的值映射为 0，大于 0 的值原样保留。"更加重视正信号、忽略负信号"。</p> <br><p><strong>导数</strong>：</p> <br><p class="img-center"><img alt="" height="38" src="https://i-blog.csdnimg.cn/direct/4a0d27277a6540e99bdda4e376a7cbe8.png" width="150" /></p> <br><pre><code class="language-python">f'(x) = 0  (x < 0)；  1  (x > 0)<br></code></pre> <br><p><strong>特点</strong>：</p> <br><p class="img-center"><img alt="" height="208" src="https://i-blog.csdnimg.cn/direct/96733691c3994f2a970b3ccb9a821158.png" width="250" /></p> <br><ul><li><strong>运算极其简单</strong>（只有比较和截断），训练效率高</li><li>x > 0 区域导数恒为 1，梯度不衰减，缓解梯度消失；x < 0 区域导数为 0</li><li>缺点：训练中部分神经元输入落入负区，输出恒 0、梯度恒 0，权重永远无法更新——<strong>"神经元死亡"（Dead ReLU）</strong></li><li>目前隐藏层最常用的激活函数</li></ul> <br><p><strong>与 Sigmoid 相比的优势</strong>：</p> <br><ol><li>Sigmoid 含指数运算，计算量大；ReLU 只做比较，计算量节省很多</li><li>Sigmoid 反向传播容易梯度消失，无法训练深层网络；ReLU 正区间梯度恒 1</li><li>ReLU 使一部分神经元输出为 0，网络具有<strong>稀疏性</strong>，减少参数相互依存，缓解过拟合</li></ol> <br><blockquote> <br> <p><strong>讲这些函数到底有什么用？为什么又讲公式又讲导数？</strong></p> <br> <p>激活函数是每个神经元的"闸门"，决定网络能不能拟合复杂问题；</p> <br> <p>而反向传播传梯度靠的就是导数（梯度 = 损失对参数的导数，链条里要乘每个激活函数的导数）。</p> <br> <p>所以每学一个激活函数，固定看三件事：<strong>输出范围</strong>（会不会饱和）、<strong>导数范围</strong>（梯度会不会消失）、<strong>计算量</strong>（训练快不快）。公式和它的名字、图像是一一对应的——公式就是函数本身，图像就是把公式画出来，导数是它参与反向传播时的"通行证"。</p> <br> <p><strong>什么是“整流器”?</strong><br /> 它本来是电子工程里的词，和神经网络没关系 ——ReLU 借用了这个名字。</p> <br> <p class="img-center"><img alt="" height="387" src="https://i-blog.csdnimg.cn/direct/76652afe113242a897409d661daaf6be.png" width="700" /></p> <br> <p>电路里的整流器 ：家用电是“交流电”，电压正负交替变化（像上图左边的波浪）。但很多电器需要电流只往一个方向走。</p> <br> <p>“整流”就是<strong>把负的那半周掐掉，只留正半周</strong>——干这活的元件（典型是 二极管 ，只让电流单向通过）就叫 整流器 （Rectifier）。</p> <br> <p>ReLU 为什么叫“整流线性单元” ：ReLU 全称 R ectified L inear U nit，其中 Rectified 就是“被整流的”。看它的公式：</p> <br></blockquote> <br><pre><code class="language-python">f(x) = max(0, x)   # 负数 → 归零（掐掉"负半周"）; 正数 → 原样通过（"正半周"直通）</code></pre> <br><blockquote> <br> <p>对比一下，两者做的是同一件事,所以笔记 2.4 节 把它叫“最常用的整流器”——<strong>ReLU 对数据干的活，和整流器对电流干的活一模一样：负的全砍掉，正的放行</strong>。</p> <br> <p>小提醒：电路整流器还有“全波整流”（把负半周翻上来而不是掐掉，对应`f(x) = |x|` ），而 ReLU 是“半波整流”式的——只保留、不翻转。课程里记住max(0, x)这一版就够了。</p> <br></blockquote> <br><h4 id="2.5%20Softmax%E2%80%94%E2%80%94%E5%A4%9A%E5%88%86%E7%B1%BB%E7%9A%84%E6%A6%82%E7%8E%87%E5%88%86%E9%85%8D%E5%99%A8" name="2.5%20Softmax%E2%80%94%E2%80%94%E5%A4%9A%E5%88%86%E7%B1%BB%E7%9A%84%E6%A6%82%E7%8E%87%E5%88%86%E9%85%8D%E5%99%A8">2.5 Softmax——多分类的概率分配器</h4> <br><p class="img-center"><img alt="" height="226" src="https://i-blog.csdnimg.cn/direct/7a616f9a28444d26925c1740950d4072.png" width="300" /></p> <br><p><strong>公式</strong>（对输出向量 z 的第 i 个分量）：</p> <br><p class="img-center"><img alt="" height="68" src="https://i-blog.csdnimg.cn/direct/cf89afdd70664ae49715b93e1c92afcf.png" width="300" /></p> <br><pre><code class="language-python">softmax(zᵢ) = e^(zᵢ) / Σⱼ e^(zⱼ)<br></code></pre> <br><p><strong>特点</strong>：</p> <br><ul><li>用于<strong>多分类</strong>，是 sigmoid 在多分类上的推广</li><li>把网络输出的原始分数（这种未归一化的分数叫 logits）映射为 <strong>(0,1)</strong> 之间的概率</li><li><strong>所有输出概率之和为 1</strong>（满足概率性质）</li><li>取概率最大的节点作为预测类别</li></ul> <br><p><strong>手算示例</strong>（只算两个分量，感受一下）：scores = [0.2, 0.02, ..., 3.75]，e^3.75 ≈ 42.52，全部 e^z 之和 ≈ 57.52，则最后一项概率 = 42.52/57.52 ≈ 0.7392。</p> <br><pre><code class="language-python">import torch<br><br>scores = torch.tensor([0.2, 0.02, 0.15, 0.15, 1.3, 0.5, 0.06, 1.1, 0.05, 3.75])<br>probabilities = torch.softmax(scores, dim=0)<br>print(probabilities)<br># tensor([0.0212, 0.0177, 0.0202, 0.0202, 0.0638, 0.0287, 0.0185, 0.0522, 0.0183, 0.7392])<br># 验证: 42.52/57.52≈0.7392, 且全部相加 = 1.0<br></code></pre> <br><h4 <br><table><thead><tr><th>名称</th><th>公式</th><th>导数</th><th>输出范围</th></tr></thead><tbody><tr><td><strong>Identity（恒等）</strong></td><td>f(x) = x</td><td>f'(x) = 1</td><td>(-∞, ∞)</td></tr><tr><td><strong>Binary step（阶跃）</strong></td><td>f(x) = 0 (x<0), 1 (x≥0)</td><td>f'(x) = 0 (x≠0)</td><td>{0, 1}</td></tr><tr><td><strong>Leaky ReLU</strong></td><td>f(x) = 0.01x (x<0), x (x≥0)</td><td>f'(x) = 0.01 (x<0), 1 (x≥0)</td><td>(-∞, ∞)</td></tr><tr><td><strong>PReLU</strong></td><td>f(α,x) = αx (x<0), x (x≥0)</td><td>f'(α,x) = α (x<0), 1 (x≥0)</td><td>(-∞, ∞)</td></tr><tr><td><strong>ELU</strong></td><td>f(α,x) = α(eˣ-1) (x<0), x (x≥0)</td><td>f'(α,x) = f(α,x)+α (x<0), 1 (x≥0)</td><td>(-α, ∞)</td></tr></tbody></table> <br><blockquote> <br> <p><strong>这几个都是 ReLU 的"改良家族"，思路一致：</strong></p> <br> <p>负区间不直接给 0，留一条小通道，避免"神经元死亡"（Leaky ReLU 留 0.01 倍斜率；PReLU 的 α 可学习；ELU 负区间用平滑曲线）。</p> <br></blockquote> <br><h4 id="2.7%20%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%E6%80%8E%E4%B9%88%E9%80%89" name="2.7%20%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%E6%80%8E%E4%B9%88%E9%80%89">2.7 激活函数怎么选</h4> <br><p><strong>对于隐藏层</strong>：</p> <br><ol><li><strong>优先选 ReLU</strong></li><li>ReLU 效果不好再试 Leaky ReLU 等改良款</li><li>用 ReLU 要注意 <strong>Dead ReLU 问题</strong>，避免过多神经元死亡（如学习率别太大）</li><li>少用 sigmoid，可尝试 tanh</li></ol> <br><p><strong>对于输出层</strong>（输出层的激活函数由任务决定，不能随意换）：</p> <br><table><thead><tr><th>任务</th><th>输出层激活函数</th></tr></thead><tbody><tr><td>二分类</td><td><strong>sigmoid</strong>（输出一个 0~1 概率）</td></tr><tr><td>多分类</td><td><strong>softmax</strong>（输出多个概率，和为 1）</td></tr><tr><td>回归</td><td><strong>identity</strong>（恒等，输出就是数值本身，不加非线性约束）</td></tr></tbody></table> <br><blockquote> <br> <p><strong>为什么隐藏层可以随便挑、输出层却"必须"那样选</strong></p> <br> <p>隐藏层激活函数只是内部"弯头"，怎么拐都行，只要不阻断梯度；输出层直接面对任务——二分类要概率、多分类要"和为 1 的概率分布"、回归要任意实数，只有对应函数能满足这些数学性质。</p> <br> <p><strong>记忆法</strong>：隐藏层默认 ReLU，不行换 Leaky；输出层二 sigmoid、多 softmax、回归恒等。</p> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><table><thead><tr><th>问题</th><th>答案</th></tr></thead><tbody><tr><td>激活函数的作用？</td><td>为网络注入非线性因素</td></tr><tr><td>常见激活函数？</td><td>Sigmoid、Tanh、ReLU、Softmax 等</td></tr><tr><td>选择方法？</td><td>隐藏层 ReLU 优先；输出层：二分类 sigmoid、多分类 softmax、回归恒等</td></tr></tbody></table> <br><h4 style="background-color:transparent">三、参数初始化——训练前的"起跑线"</h3> <br><h4 id="3.1%20%E4%B8%BA%E4%BB%80%E4%B9%88%E5%BF%85%E9%A1%BB%E5%88%9D%E5%A7%8B%E5%8C%96" 0</strong>，重点在权重 w。初始化不当的三大后果：</p> <br><ol><li><strong>防止梯度消失或爆炸</strong>：初始权重过大或过小，梯度会在反向传播中逐层指数级放大/缩小（呼应 2.2 <p><strong>什么是对称性问题</strong>：如果所有权重初始化成<strong>相同的值</strong>（全 0、全 1、同一固定值都属于此类），那么同一层里每个神经元：</p> <br> <ul><li>前向：输入相同 → 输出相同</li><li>反向：梯度相同 → 更新后依然相同</li></ul> <br> <p><br>  </p> <br> <p><a class="link-link-icon" src="https://csdnimg.cn/release/blog_editor_html/release2.4.6/ckeditor/plugins/CsdnLink/icons/icon-default.png?t=Q239" src="https://i-blog.csdnimg.cn/direct/5fd8d1b5a0034871a26dd08e6f1cf9be.webp" width="600" /></p> <br><p><a href="https://www.pinecone.io/learn/weight-initialization/" title="Weight Initialization 1、固定值初始化无法打破对称性，权重必须"随机"着初始化。</p> <br><h4 id="3.2%20%E4%B8%83%E7%A7%8D%E5%B8%B8%E8%A7%81%E5%88%9D%E5%A7%8B%E5%8C%96%E6%96%B9%E5%BC%8F" 正态分布</strong>（同一个东西的两种叫法），形状是钟形曲线，"均值 0、标准差 1"的叫标准正态分布——均值决定钟的中心，标准差决定钟的胖瘦。</p> <br><p class="img-center"><img alt="" height="209" 随机</td></tr><tr><td><strong>正态分布初始化</strong></td><td>从均值 0、标准差 1 的高斯分布取样。用<strong>很小的值初始化 w</strong>：值太大前向激活值爆炸、反向梯度爆炸，太小则信号逐层衰减</td><td>✅ 随机</td></tr><tr><td><strong>全 0 初始化</strong></td><td>所有权重 = alt="" height="338" src="https://i-blog.csdnimg.cn/direct/ee0ab698caf442e9b5d38c859990b451.webp" width="600" /></p> <br><p>上面 3.2 的"均匀/正态随机"只保证了"随机"，没保证方差合适——方差该多大？Kaiming（何恺明）给出了答案。</p> <br><p><strong>fan_in 是什么</strong>：该层的输入神经元个数（上一层节点数）。<code>nn.Linear(5, 3)</code> 的 fan_in=5、fan_out=3（输出神经元个数）。权重矩阵形状是 (fan_out, fan_in)。</p> <br><table><thead><tr><th>类型</th><th>说明</th></tr></thead><tbody><tr><td><strong>正态分布的 HE 初始化</strong></td><td>从 N(0, std) 抽样，<code>std = sqrt(2 / fan_in)</code></td></tr><tr><td><strong>均匀分布的 HE 初始化</strong></td><td>从 [-limit, limit] 均匀抽样，<code>limit = sqrt(6 / fan_in)</code></td></tr></tbody></table> <br><blockquote> <br> <p>std 就是分布的"胖瘦"：std 值越大，w 离均值 0 分布越广（胖钟），算出来的内部状态值容易出现较大的正值或负值；std 值越小，w 越集中在 0 附近（瘦钟），内部状态值就偏小。3.2 正态初始化"用很小的值"、3.4 Xavier 的 std——都是在这根"胖瘦旋钮"上调。</p> <br></blockquote> <br><blockquote> <br> <p><strong>2 和 6 是怎么推导出来的</strong>（不展开完整证明）：</p> <br> <p>目标是"方差平衡"——让每层输出的方差和输入的方差<strong>相等</strong>，信号不放大也不缩小。对一层 <code>z = Σ(wᵢ·xᵢ)</code>（fan_in 项相加），由概率论结论，独立随机变量相乘相加后的方差满足：Var(z) = fan_in × Var(w) × Var(x)。要 Var(z) = Var(x)，就必须 Var(w) = 2/fan_in（分子 2 是因为 ReLU 把一半负数置 0、方差减半，补偿回来要 ×2）。</p> <br> <p>而均匀分布 U(-a, a) 的方差是 a²/3，令 a²/3 = 2/fan_in，解得 a = sqrt(6/fan_in)——这就是 6 的来源；换成正态分布，标准差 std = sqrt(2/fan_in)——这就是 2 的来源。6 = 2×3（3 是均匀分布方差的分母），两个公式同根同源。</p> <br></blockquote> <br><pre><code class="language-python">import torch.nn as nn<br><br>linear = nn.Linear(5, 3)<br># Kaiming 正态: std = sqrt(2/5) ≈ 0.63<br>nn.init.kaiming_normal_(linear.weight)<br># 输出示例: tensor([[ 1.5046, -0.5497,  0.3034, -0.0672,  1.0932],<br>#                   [ 1.0974,  0.2554, -1.4905, -0.5190, -0.8871],<br>#                   [-0.5310, -0.2631,  0.9815, -0.3557, -0.0063]])<br># Kaiming 均匀: limit = sqrt(6/5) ≈ 1.10<br>nn.init.kaiming_uniform_(linear.weight)<br></code></pre> <br><h4 <br><table><thead><tr><th>类型</th><th>说明</th></tr></thead><tbody><tr><td><strong>正态分布的 Xavier 初始化</strong></td><td>从 N(0, std) 抽样，<code>std = sqrt(2 / (fan_in + fan_out))</code></td></tr><tr><td><strong>均匀分布的 Xavier 初始化</strong></td><td>从 [-limit, limit] 均匀抽样，<code>limit = sqrt(6 / (fan_in + fan_out))</code></td></tr></tbody></table> <br><blockquote> <br> <p><code>fan_in</code>：输入层神经元个数；<code>fan_out</code>：输出层神经元个数。<code>nn.Linear(5, 3)</code> 这层是 5+3；若两层都是 5 个节点则是 5+5。</p> <br></blockquote> <br><p><strong>与 Kaiming 的关系</strong>：</p> <br><ul><li>Xavier（Glorot）2010 年在前，Kaiming（何恺明）2015 年在后</li><li>Xavier 的方差公式按"激活函数关于 0 对称（tanh/sigmoid）"推导；但 ReLU 会砍掉一半负值，按 Xavier 方差初始化的 ReLU 网络信号逐层衰减</li><li>所以 Kaiming 针对 <strong>ReLU</strong> 修正了方差（分子从"含 fan_out 的对称式"改成 2/fan_in）：<strong>Kaiming 是 Xavier 在 ReLU 场景下的改良版</strong></li><li><br>   <p><a class="has-card" href="https://novasolver.jp/en/tools/weight-initialization.html" 0.87<br>nn.init.xavier_uniform_(linear.weight)<br></code></pre> <br><h4 id="" name=""></h4> <br><h4 <br><blockquote> <br> <p><strong>什么是方差平衡、为什么深层才需要</strong></p> <br> <p>方差平衡就是 3.3 说的"每层输出方差 = 输入方差"。浅层网络（一两层）信号走一步就到输出，方差放大点缩小点无所谓；深层网络信号要过几十层，每层方差若放大 2 倍，30 层后是 2³⁰ ≈ 10 亿倍——彻底爆炸；每层缩小一半，30 层后剩十亿分之一——彻底消失。所以层数越深，越必须用 Kaiming/Xavier 把每层方差"焊死"在 1 倍附近。</p> <br> <p>实践中 PyTorch 各层都有默认初始化（<code>nn.Linear</code> 默认 Kaiming uniform），优先选 Kaiming / Xavier，特殊需要再手动改。</p> <br></blockquote> <br><h3 name="4.3%20%E5%BD%A2%E7%8A%B6%E9%93%BE%EF%BC%9A%E6%8A%A5%E9%94%99%E5%88%86%E6%9E%90%E4%B8%8E%22%E6%9C%80%E7%BB%88%E4%B8%BA%E4%BB%80%E4%B9%88%E6%98%AF%20(5%2C2)%22">4.3 形状链：报错分析与"最终为什么是 (5,2)"</h4> <br><p>把 hidden 层写错（<code>nn.Linear(2, 2)</code> 当第二层）时，报错：</p> <br><pre><code class="language-python">RuntimeError: mat1 and mat2 shapes cannot be multiplied (5x3 and 2x2)<br></code></pre> <br><p><strong>原因</strong>：每个 <code>nn.Linear</code> 本质是<strong>矩阵乘法 <code>x·Wᵀ + b</code></strong>。数据 (5,3) 流到第二层时，W 是 2×2，(5×3) 矩阵乘 (2×2) 矩阵：前一矩阵的列数 3 ≠ 后一矩阵的行数 2，乘不了。</p> <br><p><strong>修复原则</strong>：每一层的 in_features 必须等于上一层的 out_features。形状链一路推下去：</p> <br><table><thead><tr><th>步骤</th><th>运算</th><th>输出形状</th></tr></thead><tbody><tr><td>输入数据</td><td>5 个样本 × 3 特征</td><td>(5, 3)</td></tr><tr><td><code>linear1 = nn.Linear(3, 3)</code></td><td>(5,3)·(3,3)ᵀ</td><td>(5, 3)</td></tr><tr><td><code>linear2 = nn.Linear(3, 2)</code></td><td>(5,3)·(3,2)ᵀ</td><td>(5, 2)</td></tr><tr><td><code>output = nn.Linear(2, 2)</code></td><td>(5,2)·(2,2)ᵀ</td><td>(5, 2)</td></tr></tbody></table> <br><blockquote> <br> <p><strong>"最终结果为啥是 (5,2)"</strong>：第一个 5 是样本数（5 个样本各自独立预测，全程不变）；第二个 2 是输出层神经元个数（每个样本得到 2 个类别的概率）。记住：二维输出 = (样本数, 类别数)，中间层的形状怎么变都不影响样本数。</p> <br></blockquote> <br><h4 id="4.4%20%E5%8F%82%E6%95%B0%E9%87%8F%E8%AE%A1%E7%AE%97" name="4.4%20%E5%8F%82%E6%95%B0%E9%87%8F%E8%AE%A1%E7%AE%97">4.4 参数量计算</h4> <br><p><strong>每一层参数量公式</strong>：参数量 = fan_in × fan_out（w 的个数）+ fan_out（b 的个数）</p> <br><p>以示例网络逐层算（对照课件 summary 输出 Total params: 26）：</p> <br><table><thead><tr><th>层</th><th>w 个数</th><th>b 个数</th><th>小计</th></tr></thead><tbody><tr><td><code>Linear(3, 3)</code></td><td>3×3 = 9</td><td>3</td><td><strong>12</strong></td></tr><tr><td><code>Linear(3, 2)</code></td><td>3×2 = 6</td><td>2</td><td><strong>8</strong></td></tr><tr><td><code>Linear(2, 2)</code></td><td>2×2 = 4</td><td>2</td><td><strong>6</strong></td></tr><tr><td><strong>合计</strong></td><td>19</td><td>7</td><td><strong>26</strong></td></tr></tbody></table> <br><blockquote> <br> <p><strong>面试回答模板</strong>（"如何回答网络参数量计算"）：<br /> "每层参数 = 权重 + 偏置。权重个数 = 该层输入特征数 × 输出特征数（即全连接矩阵元素个数），偏置个数 = 输出特征数（每个输出神经元一个）。把每层相加即总参数量。例如 3→3→2→2 的网络：12 + 8 + 6 = 26 个参数。" —— 若追问某一层：只算那一层的 fan_in×fan_out + fan_out 即可。</p> <br></blockquote> <br><p><code>summary()</code> 的输出列对照：<code>Param #</code> 就是按上式算的每层参数数；<code>Output Shape</code> 是数据流经该层后的形状。</p> <br><h4 <br><p><strong>优点</strong>：</p> <br><ul><li>精度高，性能优于其他机器学习方法，某些领域甚至超过人类（自动特征提取，无需人工特征工程——呼应《00-深度学习简介》）</li><li>可以近似任意的非线性函数（激活函数的功劳，见 2.1）</li><li>学界业界热捧，框架和库生态丰富（PyTorch、TensorFlow、Keras、HuggingFace 等）</li></ul> <br><p><strong>缺点</strong>：</p> <br><ul><li><strong>黑箱</strong>：很难解释模型内部怎么工作。现在能解释了吗——有进展（可视化卷积特征、注意力权重分析、SHAP/LIME 等解释工具），但离"完全解释"还很远，可解释性仍是研究前沿</li><li>训练时间长，需要大量算力（常靠 GPU）</li><li>网络结构复杂，超参数（层数、宽度、学习率等）需要反复调</li><li>小数据集上表现不佳，容易过拟合</li></ul> <br><h3 <br><p>--交互式 8 种损失函数对比画布</p> <br><h4 id="5.2%20%E5%A4%9A%E5%88%86%E7%B1%BB%EF%BC%9A%E4%BA%A4%E5%8F%89%E7%86%B5%E6%8D%9F%E5%A4%B1%20CrossEntropyLoss" <br><p><strong>公式</strong>：</p> <br><p class="img-center"><img alt="" height="100" src="https://i-blog.csdnimg.cn/direct/d5015a20ce984772abe9a11d33d4a894.png" width="300" /></p> <br><p class="img-center"><img alt="" height="232" src="https://i-blog.csdnimg.cn/direct/eba5a45d85954b0580ccc83e79c09d3d.png" width="300" /></p> <br><pre><code class="language-python">L = -Σᵢ yᵢ · log( S(f(xᵢ)) )<br></code></pre> <br><p>符号拆解：</p> <br><table><thead><tr><th>符号</th><th>身份</th><th>大白话</th></tr></thead><tbody><tr><td><code>x</code></td><td>样本</td><td>一条输入数据</td></tr><tr><td><code>f(x)</code></td><td>加权求和的输出分数</td><td>模型给每个类别打的<strong>原始分</strong>（logits，没归一化）</td></tr><tr><td><code>S</code></td><td>softmax 激活函数</td><td>把分数转换成<strong>概率</strong>（和为 1）</td></tr><tr><td><code>y</code></td><td>样本的真实概率分布</td><td>正确答案，如独热编码 [0,1,0]</td></tr><tr><td><code>L</code></td><td>损失</td><td>真实值与预测值差异的度量</td></tr><tr><td><code>i</code></td><td>遍历所有类别（对类别求和，不是对样本；多样本时再取平均）</td><td>把每个类别的贡献加起来</td></tr></tbody></table> <br><p><a class="has-card" href="https://nipunbatra.github.io/interactive-articles/softmax-cross-entropy/" title="Softmax & Cross-Entropy" rel="nofollow"><span class="link-card-box" contenteditable="false"><span class="link-title">Softmax & Cross-Entropy</span><span class="link-link"><img class="link-link-icon" src="https://csdnimg.cn/release/blog_editor_html/release2.4.6/ckeditor/plugins/CsdnLink/icons/icon-default.png?t=Q239" />https://nipunbatra.github.io/interactive-articles/softmax-cross-entropy/</span></span></a><br> </p> <br><p>--Softmax + Cross-Entropy 三类交互</p> <br><p><strong>计算三步</strong>：</p> <br><ol><li>模型输出分数 f(x)（logits）</li><li>softmax 把分数变成概率 S(f(x))</li><li>取真实类别对应的概率，算 -log(概率)，就是损失</li></ol> <br><p><strong>图示例子</strong>（三分类，模型经 softmax 输出概率 [0.1, 0.7, 0.2]，真实类别是第 2 类）：</p> <br><pre><code class="language-python">类别:        猫     狗     鸟<br>模型概率:   0.10   0.70   0.20<br>真实标签:    0      1      0     ← 独热编码, 狗=1<br>             │      │      │<br>逐项相乘:   0×log0.10  1×log0.70  0×log0.20   ← 只有真实类别"活着"<br>             └──────┴──────┘<br>损失 L = -(0·log0.10 + 1·log0.70 + 0·log0.20) = -log(0.7) ≈ 0.357<br></code></pre> <br><p><strong>公式本质</strong>：交叉熵公式看起来吓人，其实只有一句话——<strong>损失 = -log(模型给真实类别的那个概率)</strong>。那一大串 Σ yᵢ·log(...) 只是"用数学语言挑出真实类别"：独热编码只有真实类别的 yᵢ=1，其他全是 0，乘完求和自动只剩真实类别那一项（上面图示已演示）。多分类、二分类的交叉熵都是这一个逻辑。</p> <br><blockquote> <br> <p><strong>从概率角度理解</strong>：损失 = 最小化"正确类别的预测概率"的负对数。预测正确类别概率越接近 1，-log(概率) 越接近 0（loss=-log(1)=0 最小）；越接近 0，损失越趋近无穷大。模型只有"把正确的说对"才能降损失。</p> <br></blockquote> <br><p><strong>PyTorch 实现</strong>：</p> <br><pre><code class="language-python">import torch<br>import torch.nn as nn<br><br># 演示多分类交叉熵损失<br>def dm01():<br>    # 1.真实值: 两种写法都行 ——<br>    #    写法A(独热编码): y_true = torch.tensor([[0, 1, 0], [1, 0, 0]], dtype=torch.float)<br>    #      独热形式是概率分布, 必须是浮点型<br>    #    写法B(类别索引): 直接写类别编号, 必须是 int64 —— 主流写法<br>    y_true = torch.tensor([0, 1])<br>    # 2.预测值: 模型输出的 logits (未 softmax 的原始分数)<br>    y_pred = torch.tensor([[0.1, 0.8, 0.1], [0.7, 0.2, 0.1]], requires_grad=True, dtype=torch.float)<br>    # 3.实例化交叉熵损失 (reduction 默认 'mean': 多样本损失取平均;<br>    #   reduction='sum' 时返回总损失, 不除以样本数)<br>    criterion = nn.CrossEntropyLoss()<br>    # 4.计算损失 —— criterion 是"损失对象", 调用它就像调函数:<br>    #   nn.Module 重写了 __call__ 魔法方法, criterion(预测, 真实) 自动执行计算<br>    loss = criterion(y_pred, y_true)<br>    print(f'损失值:{loss}')<br><br>if __name__ == '__main__':<br>    dm01()<br># 损失值:1.3288381099700928<br></code></pre> <br><p><strong>手算核对</strong>（示例输出，按公式推得）：</p> <br><ul><li>样本1 logits [0.1, 0.8, 0.1]，真实类别 0：softmax 概率 p₀ = e^0.1/(e^0.1+e^0.8+e^0.1) ≈ 1.1052/4.4359 ≈ 0.2492，loss₁ = -ln(0.2492) ≈ 1.389</li><li>样本2 logits [0.7, 0.2, 0.1]，真实类别 1：p₁ = e^0.2/(e^0.7+e^0.2+e^0.1) ≈ 1.2214/4.3404 ≈ 0.2814，loss₂ = -ln(0.2814) ≈ 1.268</li><li>平均：(1.389 + 1.268) / 2 ≈ <strong>1.3288</strong> ✓ 与运行结果一致</li></ul> <br><blockquote> <br> <p><strong>重点：<code>nn.CrossEntropyLoss() = softmax + 损失计算</code>（二合一封装）</strong>。所以：</p> <br> <ol><li>传给它的预测值是 logits（原始分数），不是概率, 它内部先做 softmax</li><li>用了这个损失函数，输出层就不用再写 softmax 激活（写了等于 softmax 两次，效果变差）</li><li>真实值用类别索引（如 [0, 1]），不用手动独热</li><li><br>   为什么运用 logits 不直接运用概率：先 softmax 再取 log，概率极小时（如 0.0001）log 值会数值不稳定；PyTorch 内部用 log_softmax 一步算完，数值更稳</li></ol> <br></blockquote> <br><h4 id="5.3%20%E4%BA%8C%E5%88%86%E7%B1%BB%EF%BC%9ABCELoss" name="5.3%20%E4%BA%8C%E5%88%86%E7%B1%BB%EF%BC%9ABCELoss">5.3 二分类：BCELoss</h4> <br><p>二分类用 <strong>sigmoid</strong>，损失函数换成<strong>二分类交叉熵</strong>：</p> <br><p class="img-center"><img alt="" height="32" src="https://i-blog.csdnimg.cn/direct/3ff7eb25fac44d109b09427d0a0a7abd.png" width="400" /></p> <br><p class="img-center"><img alt="" height="236" src="https://i-blog.csdnimg.cn/direct/8cab99caf1a84079bd5ca89260aecfc6.png" width="300" /></p> <br><pre><code>L = -y·log(ŷ) - (1-y)·log(1-ŷ)<br></code></pre> <br><p>其中：<code>y</code> 真实标签（0 或 1）、<code>ŷ</code> 预测概率（sigmoid 之后的输出）、<code>L</code> 损失。</p> <br><blockquote> <br> <p><strong>公式里为什么没有 sigmoid(</strong><br>  上一个公式有 softmax 这个没有<strong>)</strong>：<strong>公式里的 ŷ 已定义为 sigmoid 之后的概率</strong>。softmax 被 CrossEntropyLoss 打包了，而 sigmoid 没被打包进 BCELoss——用 BCELoss 前必须手动过一遍 sigmoid。</p> <br> <p><strong>CrossEntropyLoss = softmax + 损失；BCELoss = 只算损失，sigmoid 自己加</strong>。</p> <br></blockquote> <br><p><strong>为什么"y=0 或 y=1 时，公式要么算前半、要么算后半"</strong>：把 y 代进去看:</p> <br><ul><li>y=1：L = -log(ŷ)，只剩前半: 惩罚"正确类(1)的概率给低了"</li><li>y=0：L = -log(1-ŷ)，只剩后半: 惩罚"错误类(1)的概率给高了"</li></ul> <br><p>作用：不管真实标签是 0 还是 1，公式都自动聚焦到<strong>真实类别对应的预测概率</strong>，只惩罚"说错的那部分"。</p> <br><p><br> </p> <br><p><strong>场景：预测"这次考试是否通过"，模型输出的概率是 ŷ</strong></p> <br><table><thead><tr><th>场景</th><th>真实 y</th><th>模型说 ŷ</th><th>代公式计算</th><th>损失 L</th><th>感觉</th></tr></thead><tbody><tr><td>猜对了还很自信</td><td>1</td><td>0.95</td><td>-log(0.95)</td><td>≈ 0.05</td><td>损失几乎为零，表现好</td></tr><tr><td>猜对了但没把握</td><td>1</td><td>0.60</td><td>-log(0.60)</td><td>≈ 0.51</td><td>还行，但不够自信</td></tr><tr><td>完全猜反了</td><td>0</td><td>0.95</td><td>-log(1-0.95) = -log(0.05)</td><td>≈ 3.00</td><td>巨高，模型严重错误</td></tr></tbody></table> <br><p>规律：模型给真实类别的概率越高，损失越小；越低，损失越大, log 单调递减的特性天然就是"惩罚说错、奖励说对"。对照 5.2 的一句话本质：二分类和多分类的交叉熵是同一个逻辑，公式里 y· 和 (1-y)· 两项只是"挑出真实类别"的工具。</p> <br><p><strong>PyTorch 实现</strong>：</p> <br><pre><code class="language-python">import torch<br>import torch.nn as nn<br><br># 演示二分类交叉熵损失<br>def dm01():<br>    # 1.真实值: 0 或 1<br>    y_true = torch.tensor([0, 1, 0], dtype=torch.float)<br>    # 2.预测值: 必须是 sigmoid 之后的概率 (0~1)<br>    y_pred = torch.tensor([0.6901, 0.9845, 0.2311], dtype=torch.float)<br>    # 3.实例化损失对象 —— 不能写 nn.BCELoss(y_pred, y_true)!<br>    #   BCELoss 是"类", 直接传参是"创建对象"的语法错误;<br>    #   正确姿势: 先实例化 criterion = nn.BCELoss(), 再 criterion(预测, 真实)<br>    criterion = nn.BCELoss()<br>    # 4.计算损失 —— .detach() 摘掉追踪(预测值带 requires_grad, 直接转 numpy 报错),<br>    #   .numpy() 转成数组只看数值 (呼应《02》3.8 detach)<br>    loss = criterion(y_pred, y_true).detach().numpy()<br>    print(f'损失值:{loss}')<br><br>if __name__ == '__main__':<br>    dm01()<br># 损失值:0.4832<br></code></pre> <br><p><strong>手算核对</strong>（示例输出，按公式推得）：</p> <br><ul><li>样本1 y=0, ŷ=0.6901：L₁ = -log(1-0.6901) = -log(0.3099) ≈ 1.1712</li><li>样本2 y=1, ŷ=0.9845：L₂ = -log(0.9845) ≈ 0.0156</li><li>样本3 y=0, ŷ=0.2311：L₃ = -log(1-0.2311) = -log(0.7689) ≈ 0.2629</li><li>平均：(1.1712 + 0.0156 + 0.2629) / 3 ≈ <strong>0.4832</strong> ✓</li></ul> <br><h4 id="5.4%20%E5%9B%9E%E5%BD%92%E6%8D%9F%E5%A4%B1%E4%B8%80%EF%BC%9AMAE%EF%BC%88L1%20Loss%EF%BC%89" name="5.4%20%E5%9B%9E%E5%BD%92%E6%8D%9F%E5%A4%B1%E4%B8%80%EF%BC%9AMAE%EF%BC%88L1%20Loss%EF%BC%89">5.4 回归损失一：MAE（L1 Loss）</h4> <br><p><strong>Mean Absolute Error（MAE）</strong> 也称 <strong>L1 Loss</strong>，以绝对误差为距离：</p> <br><p class="img-center"><img alt="" height="60" src="https://i-blog.csdnimg.cn/direct/a2ac3663055140c0927b58dfa8c1a5f6.png" width="200" /></p> <br><p class="img-center"><img alt="" height="248" src="https://i-blog.csdnimg.cn/direct/cbc87f94f1c04b8490b30613caac0729.png" width="300" /></p> <br><pre><code>L = (1/n) · Σᵢ |yᵢ - f(xᵢ)|<br></code></pre> <br><p>即"误差绝对值之和 ÷ 样本总数"。</p> <br><p><strong>特点</strong>：</p> <br><ol><li>作为正则项使用时具有<strong>稀疏性</strong>——L1 正则会把许多权重压成正好 0</li><li>最大问题：梯度在零点不平滑（|x| 在 x=0 处不可导），优化时可能跳过极小值</li><li>适用场景：回归问题中存在<strong>异常值或噪声数据</strong>时——误差线性计账，不像平方那样放大，对离群点不敏感</li></ol> <br><p><strong>PyTorch 实现</strong>：</p> <br><pre><code class="language-python">import torch<br>import torch.nn as nn<br><br># 演示 MAE 损失<br>def dm01():<br>    y_true = torch.tensor([2.0, 2.0, 2.0], dtype=torch.float)   # 真实值<br>    y_pred = torch.tensor([1.0, 1.0, 1.9], requires_grad=True)  # 预测值<br>    criterion = nn.L1Loss()<br>    loss = criterion(y_pred, y_true).detach().numpy()<br>    print(f'损失值:{loss}')<br><br>if __name__ == '__main__':<br>    dm01()<br># 损失值:0.699999988079071<br></code></pre> <br><p><strong>手算核对</strong>：|2-1| + |2-1| + |2-1.9| = 1 + 1 + 0.1 = 2.1，除以样本数 3 → <strong>0.7</strong> ✓</p> <br><h4 id="5.5%20%E5%9B%9E%E5%BD%92%E6%8D%9F%E5%A4%B1%E4%BA%8C%EF%BC%9AMSE%EF%BC%88L2%20Loss%EF%BC%89" name="5.5%20%E5%9B%9E%E5%BD%92%E6%8D%9F%E5%A4%B1%E4%BA%8C%EF%BC%9AMSE%EF%BC%88L2%20Loss%EF%BC%89">5.5 回归损失二：MSE（L2 Loss）</h4> <br><p><strong>Mean Squared Error（MSE）</strong> 也称 <strong>L2 loss</strong>，以误差平方为距离（即欧氏距离的平方）：</p> <br><p class="img-center"><img alt="" height="78" src="https://i-blog.csdnimg.cn/direct/beb19967dd36462894d8cd292ec149eb.png" width="300" /></p> <br><p class="img-center"><img alt="" height="248" src="https://i-blog.csdnimg.cn/direct/8d86e6a00393455084c02d9429d2290b.png" width="300" /></p> <br><pre><code>L = (1/n) · Σᵢ (yᵢ - f(xᵢ))²<br></code></pre> <br><p>即"误差平方之和 ÷ 样本总数"。</p> <br><blockquote> <br> <p>什么是欧氏距离？：</p> <br> <ul><li>L2 = 欧氏距离（Euclidean）：两点间<strong>直线距离</strong>，√(Δx²+Δy²)</li><li>L1 = 曼哈顿距离（Manhattan，也叫出租车距离）：网格街道上拐弯走的距离，|Δx|+|Δy|</li><li>另外，"L1/L2 loss"与"L1/L2 <strong>正则</strong>"名字相同但用途不同：MSELoss 只是损失，不做正则；L2 正则（权重衰减）是训练时另外加的惩罚项。L1 正则把权重压成正好 0（稀疏），L2 正则把权重压到接近 0 但不等于 0</li></ul> <br> <p><strong>MSE "更关注异常点"</strong>：平方放大了大误差——差 10 的样本贡献 100，差 2 的只贡献 4；大误差（异常点）在损失里权重被放大，训练会优先纠正它。</p> <br></blockquote> <br><p><strong>特点</strong>：</p> <br><ol><li>也常作为正则项</li><li>当预测值与目标值相差很大时，平方放大 → 梯度容易爆炸 <br>  <ul><li>梯度爆炸：网络层之间的梯度（值大于 1.0）重复相乘，指数级增长——和 2.2 的梯度消失（值小于 1.0 重复相乘，指数级缩小）是一枚硬币的两面</li></ul> </li><li>适用场景：大多数<strong>标准回归问题</strong>，如房价预测、温度预测等</li></ol> <br><p><strong>PyTorch 实现</strong>：</p> <br><pre><code class="language-python">import torch<br>import torch.nn as nn<br><br># 演示 MSE 损失 (同一组数据, 只换损失函数)<br>def dm02():<br>    y_true = torch.tensor([2.0, 2.0, 2.0], dtype=torch.float)<br>    y_pred = torch.tensor([1.0, 1.0, 1.9], requires_grad=True)<br>    criterion = nn.MSELoss()<br>    loss = criterion(y_pred, y_true).detach().numpy()<br>    print(f'损失值:{loss}')<br><br>if __name__ == '__main__':<br>    dm02()<br># 损失值:0.6700000166893005<br></code></pre> <br><p><strong>手算核对</strong>：1² + 1² + 0.1² = 1 + 1 + 0.01 = 2.01，除以 3 → <strong>0.67</strong> ✓</p> <br><h4 id="5.6%20%E5%9B%9E%E5%BD%92%E6%8D%9F%E5%A4%B1%E4%B8%89%EF%BC%9ASmooth%20L1" name="5.6%20%E5%9B%9E%E5%BD%92%E6%8D%9F%E5%A4%B1%E4%B8%89%EF%BC%9ASmooth%20L1">5.6 回归损失三：Smooth L1</h4> <br><p><strong>Smooth L1 = 光滑化的 L1</strong>，分段函数（x = 预测值 - 真实值）：</p> <br><p class="img-center"><img alt="" height="55" src="https://i-blog.csdnimg.cn/direct/6a9d18c2710b418d938016ab28d912b4.png" width="300" /></p> <br><p class="img-center"><img alt="" height="218" src="https://i-blog.csdnimg.cn/direct/2b567a7098fe4d4b8c68e4c43837cf97.png" width="300" /></p> <br><pre><code class="language-python">smooth_L1(x) = 0.5·x²        当 |x| < 1<br>               |x| - 0.5      其他<br></code></pre> <br><p><strong>特点</strong>：</p> <br><ol><li>误差小（|x|<1）的段落用 <strong>L2</strong>（0.5x²）——解决了 L1 在 0 点不平滑、可能错过最小值的问题</li><li>误差大（|x|≥1）的段落用 <strong>L1</strong>（线性增长）——解决了 L2 平方放大、离群点梯度爆炸的问题</li></ol> <br><p><strong>PyTorch 实现</strong>（同一组数据三连对比）：</p> <br><pre><code class="language-python">import torch<br>import torch.nn as nn<br><br># 演示 Smooth L1 损失<br>def dm03():<br>    y_true = torch.tensor([2.0, 2.0, 2.0], dtype=torch.float)<br>    y_pred = torch.tensor([1.0, 1.0, 1.9], requires_grad=True)<br>    criterion = nn.SmoothL1Loss()<br>    loss = criterion(y_pred, y_true).detach().numpy()<br>    print(f'损失值:{loss}')<br><br>if __name__ == '__main__':<br>    dm03()<br># 损失值:0.33500000834465027<br></code></pre> <br><p><strong>手算核对</strong>：差值 x = [-1, -1, -0.1]。前两个 |x|=1 不小于 1，走 L1 段：|-1|-0.5 = 0.5（×2 = 1.0）；第三个 |x|=0.1<1 走 L2 段：0.5×0.01 = 0.005。合计 1.005，除以 3 → <strong>0.335</strong> ✓</p> <br><blockquote> <br> <p><strong>三个损失为什么差别这么大、谁"最差"</strong>：</p> <br> <p>同一组误差 [1, 1, 0.1]，</p> <br> <p>MAE 线性计账 = 0.7；</p> <br> <p>MSE 平方计账 = 0.67；</p> <br> <p>Smooth L1 大误差走 L1、小误差打折 = 0.335。</p> <br> <p>损失数值大小只在"同一种损失函数内部"可比，跨函数比较没有意义——不能说 0.335 的模型就比 0.7 的好，因为"尺子"都不一样。没有谁最差，只有和任务匹不匹配（离群点多 → Smooth L1 稳；要强调大误差 → MSE）。</p> <br> <p>课程后续以分类任务为主，多分类交叉熵是最常用的默认选择；回归任务则按需在 L1/MSE/SmoothL1 里挑。</p> <br></blockquote> <br><h4 id="5.7%20%E5%B0%8F%E7%BB%93" name="5.7%20%E5%B0%8F%E7%BB%93">5.7 小结</h4>
