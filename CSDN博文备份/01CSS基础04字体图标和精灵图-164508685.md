个人中心<br></a><br><br></code></pre> <br><h5 id="%E7%AC%AC%E5%9B%9B%E6%AD%A5%EF%BC%9A%E9%80%9A%E8%BF%87%20CSS%20%E8%B0%83%E6%95%B4%E5%9B%BE%E6%A0%87%E6%A0%B7%E5%BC%8F" <br><h4 id="6.%20%E5%AD%97%E4%BD%93%E5%9B%BE%E6%A0%87%E4%B8%8E%E6%99%AE%E9%80%9A%E5%9B%BE%E7%89%87%E7%9A%84%E5%AF%B9%E6%AF%94" <br><table><thead><tr><th>对比维度</th><th>字体图标</th><th>普通图片（PNG/JPG）</th></tr></thead><tbody><tr><td><strong>缩放质量</strong></td><td>矢量无损，任意缩放不模糊</td><td>位图，放大后模糊/锯齿</td></tr><tr><td><strong>颜色修改</strong></td><td>CSS 直接改 <code>color</code>，一行代码</td><td>需要重新切图或 CSS filter</td></tr><tr><td><strong>大小修改</strong></td><td>CSS 改 <code>font-size</code></td><td>需要重新切图或 CSS 宽高（可能变形）</td></tr><tr><td><strong>HTTP id="%E4%BA%8C%E3%80%81CSS%20%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%88CSS%20Sprites%EF%BC%89" name="%E4%BA%8C%E3%80%81CSS%20%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%88CSS%20Sprites%EF%BC%89">二、CSS 精灵图（CSS Sprites）</h3> <br><h4 id="1.%20%E4%BB%80%E4%B9%88%E6%98%AF%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%9F" name="1.%20%E4%BB%80%E4%B9%88%E6%98%AF%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%9F">1. 什么是精灵图？</h4> <br><p><strong>CSS 精灵图</strong>（也叫 CSS Sprites、雪碧图）是一种将<strong>多个小图标或小图片合并到一张大图</strong>中，然后通过 CSS 的 <code>background-position</code> 属性来控制显示其中<strong>特定部分</strong>的技术。</p> <br><blockquote> <br> <p>你可以把精灵图想象成一张<strong>电影胶片</strong>，每一帧是一个小图标。我们通过移动胶片的位置（<code>background-position</code>），让盒子的“取景框”对准我们想看的那个画面。</p> <br></blockquote> <br><h4 id="2.%20%E4%BD%BF%E7%94%A8%E5%9C%BA%E6%99%AF" name="2.%20%E4%BD%BF%E7%94%A8%E5%9C%BA%E6%99%AF">2. 使用场景</h4> <br><table><thead><tr><th>场景</th><th>说明</th></tr></thead><tbody><tr><td><strong>导航菜单图标</strong></td><td>网站导航栏中多个彩色小图标</td></tr><tr><td><strong>按钮状态图标</strong></td><td>按钮的 正常/悬停/点击 不同状态用同一张图的三个不同位置</td></tr><tr><td><strong>复杂彩色小图标</strong></td><td>图标带有渐变色、阴影等复杂视觉效果，不适合字体图标</td></tr><tr><td><strong>游戏/应用内元素</strong></td><td>游戏中的角色、道具、技能图标等</td></tr><tr><td><strong>背景装饰图案</strong></td><td>页面中重复使用的装饰性小元素</td></tr></tbody></table> <br><h4 id="3.%20%E6%A0%B8%E5%BF%83%E4%BC%98%E5%8A%BF" name="3.%20%E6%A0%B8%E5%BF%83%E4%BC%98%E5%8A%BF">3. 核心优势</h4> <br><table><thead><tr><th>优势</th><th>详细说明</th></tr></thead><tbody><tr><td><strong>大幅减少 HTTP 请求</strong></td><td>N 个小图标 → 1 张大图，只需<strong>1 次 HTTP 请求</strong>，显著提升页面加载速度</td></tr><tr><td><strong>减少网络开销</strong></td><td>尤其在移动端或低带宽环境下，减少请求数比减少总大小更重要</td></tr><tr><td><strong>统一管理</strong></td><td>所有图标集中在一张图上，方便维护和版本更新</td></tr><tr><td><strong>提前加载</strong></td><td>一次加载即可使用全部图标，不存在“图标逐个闪现”的问题</td></tr></tbody></table> <br><h4 id="4.%20%E6%A0%B8%E5%BF%83%E5%8E%9F%E7%90%86%EF%BC%88%E4%B8%89%E6%AD%A5%E8%B5%B0%EF%BC%89" name="4.%20%E6%A0%B8%E5%BF%83%E5%8E%9F%E7%90%86%EF%BC%88%E4%B8%89%E6%AD%A5%E8%B5%B0%EF%BC%89">4. 核心原理（三步走）</h4> <br><ol><li><strong>给盒子设置固定宽高</strong>：盒子相当于一个“取景框”，只显示大图中对应区域。</li><li><strong>给盒子添加背景图片</strong>：背景图片就是那张合并好的大图。</li><li><strong>通过 <code>background-position</code> 移动背景图</strong>：把大图中目标图标的位置，移动到盒子取景框内。</li></ol> <br><h4 id="5.%20%E5%85%B3%E9%94%AE%EF%BC%9A%E7%BD%91%E9%A1%B5%E5%9D%90%E6%A0%87%E7%B3%BB%EF%BC%88%E9%9D%9E%E5%B8%B8%E5%AE%B9%E6%98%93%E5%87%BA%E9%94%99%EF%BC%89" name="5.%20%E5%85%B3%E9%94%AE%EF%BC%9A%E7%BD%91%E9%A1%B5%E5%9D%90%E6%A0%87%E7%B3%BB%EF%BC%88%E9%9D%9E%E5%B8%B8%E5%AE%B9%E6%98%93%E5%87%BA%E9%94%99%EF%BC%89">5. 关键：网页坐标系（非常容易出错）</h4> <br><p>在网页中，坐标系的<strong>原点 (0, 0)</strong> 在<strong>左上角</strong>：</p> <br><ul><li><strong>X 轴</strong>：向右为正（→ 正）</li><li><strong>Y 轴</strong>：向下为正（↓ 正）</li></ul> <br><p><strong><code>background-position</code> 的取值逻辑</strong>：</p> <br><ul><li><code>background-position: x y;</code> 中的 x 和 y，表示<strong>背景图左上角相对于盒子左上角的偏移量</strong>。</li><li>假设目标图标在精灵图中的坐标为 <strong>(x, y)</strong>（即图标左上角距离大图左上角的距离），那么我们要把背景图向左、向上移动，公式为：</li></ul> <br><blockquote> <br> <p><strong><code>background-position: -xpx -ypx;</code></strong></p> <br></blockquote> <br><p><strong>示例</strong>：</p> <br><p>假设精灵图 <code>sprites.png</code> 宽 600px、高 400px，里面包含如下图标：</p> <br><table><thead><tr><th>图标</th><th>在大图中的位置（左上角坐标）</th><th>图标尺寸</th></tr></thead><tbody><tr><td>首页图标</td><td>(0, 0)</td><td>20px × 20px</td></tr><tr><td>搜索图标</td><td>(100, 0)</td><td>20px × 20px</td></tr><tr><td>购物车图标</td><td>(200, 0)</td><td>20px × 20px</td></tr><tr><td>用户图标</td><td>(0, 50)</td><td>20px × 20px</td></tr></tbody></table> <br><p>如果要显示<strong>搜索图标</strong>：</p> <br><pre><code class="language-css">.search-icon {<br>    width: 20px;<br>    height: 20px;<br>    background-image: url(./sprites.png);<br>    background-position: -100px 0px;   /* 往左移动100px */<br>}<br></code></pre> <br><p>如果要显示<strong>用户图标</strong>：</p> <br><pre><code class="language-css">.user-icon {<br>    width: 20px;<br>    height: 20px;<br>    background-image: url(./sprites.png);<br>    background-position: 0px -50px;    /* 往上移动50px */<br>}<br></code></pre> <br><blockquote> <br> <p><strong>记忆口诀</strong>：想要背景图往<strong>左</strong>移，<code>x</code> 写<strong>负值</strong>；想要背景图往<strong>上</strong>移，<code>y</code> 写<strong>负值</strong>。</p> <br></blockquote> <br><h4 id="6.%20%E7%B2%BE%E7%81%B5%E5%9B%BE%E7%9A%84%20CSS%20%E6%A0%B8%E5%BF%83%E5%B1%9E%E6%80%A7" name="6.%20%E7%B2%BE%E7%81%B5%E5%9B%BE%E7%9A%84%20CSS%20%E6%A0%B8%E5%BF%83%E5%B1%9E%E6%80%A7">6. 精灵图的 CSS 核心属性</h4> <br><pre><code class="language-css">.icon {<br>    /* 1. 固定宽高（取景框尺寸 = 图标尺寸） */<br>    width: 20px;<br>    height: 20px;<br>    /* 2. 设置背景图 */<br>    background-image: url(./sprites.png);<br>    /* 3. 禁止平铺（重要） */<br>    background-repeat: no-repeat;<br>    /* 4. 定位到目标图标（关键） */<br>    background-position: -100px -50px;<br>}<br></code></pre> <br><p><strong>现实开发：</strong>下面是一个真实项目中的写法。假设 UI 设计师给了一张精灵图 <code>wz.webp</code>，其中每个小图标尺寸约为 27px × 26px，我们通过「基础类 + 定位类」组合的方式，让多个图标共用同一张背景图：</p> <br><pre><code class="language-css"><style><br>    /* 基础类：只负责取景框尺寸 + 背景图，不写定位 */<br>    .box {<br>        width: 27px;<br>        height: 26px;<br>        background: url(./img/wz.webp) no-repeat;<br>    }<br>    /* 定位类：每个图标一个类名，只改 background-position */<br>    .sprite {<br>        background-position: 0 -169px;<br>    }<br>    .sprite2 {<br>        background-position: -90px -170px;<br>    }<br></style><br><br><!-- 使用时：基础类 + 定位类 组合 --><br><div class="box sprite"></div><br><div class="box sprite2"></div><br></code></pre> <br><p>这种「基础类 + 定位类」的写法是实际项目中最常用的模式：<strong>基础类</strong>统一管理宽高和背景图，避免每个图标重复写一遍；<strong>定位类</strong>只负责各自的 <code>background-position</code>，新增图标时只需追加一个类名，维护成本低、代码更干净。</p> <br><p>如果图标需要支持鼠标悬停换图（比如按钮的正常态和悬停态），可以配合 <code>:hover</code> 切换定位类：</p> <br><pre><code class="language-css">.btn-icon {<br>    width: 27px;<br>    height: 26px;<br>    background: url(./img/wz.webp) no-repeat;<br>    background-position: 0 -169px;   /* 正常态 */<br>}<br>.btn-icon:hover {<br>    background-position: 0 -195px;   /* 悬停态：同一张图往下偏移 */<br>}<br></code></pre> <br><blockquote> <br> <p><strong>注意</strong>：<code>background-position</code> 除了可以用 <code>px</code> 精确值，也可以用 <code>center</code>、<code>top</code>、<code>left</code> 等方位词，但精灵图场景下为了精准，<strong>必须用具体的 px 值</strong>。</p> <br></blockquote> <br><h4 id="7.%20%E7%B2%BE%E7%81%B5%E5%9B%BE%E4%BD%BF%E7%94%A8%E6%B5%81%E7%A8%8B%EF%BC%88%E5%AE%9E%E9%99%85%E5%BC%80%E5%8F%91%EF%BC%89" name="7.%20%E7%B2%BE%E7%81%B5%E5%9B%BE%E4%BD%BF%E7%94%A8%E6%B5%81%E7%A8%8B%EF%BC%88%E5%AE%9E%E9%99%85%E5%BC%80%E5%8F%91%EF%BC%89">7. 精灵图使用流程（实际开发）</h4> <br><table><thead><tr><th>步骤</th><th>操作</th></tr></thead><tbody><tr><td><strong>1. 设计合并</strong></td><td>UI 设计师将多个小图标合并为一张大图（或使用工具自动合成），并提供<strong>每个图标在大图中的坐标和尺寸</strong></td></tr><tr><td><strong>2. 测量坐标</strong></td><td>使用 Photoshop / Figma / 像素测量工具，获取目标图标左上角距离大图左上角的 <code>x</code> 和 <code>y</code> 值</td></tr><tr><td><strong>3. 编写 CSS</strong></td><td>设置盒子宽高 = 图标尺寸，<code>background-position</code> = <code>-xpx -ypx</code></td></tr><tr><td><strong>4. 复用类名</strong></td><td>给不同图标设置不同类名，每个类名对应不同的 <code>background-position</code></td></tr></tbody></table> <br><h3 id="%E4%B8%89%E3%80%81%E5%AD%97%E4%BD%93%E5%9B%BE%E6%A0%87%20vs%20%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%88%E6%80%8E%E4%B9%88%E9%80%89%EF%BC%89" name="%E4%B8%89%E3%80%81%E5%AD%97%E4%BD%93%E5%9B%BE%E6%A0%87%20vs%20%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%88%E6%80%8E%E4%B9%88%E9%80%89%EF%BC%89">三、字体图标 vs 精灵图（怎么选）</h3> <br><p>下面从几个关键维度把两者放在一起对比，方便快速做选型判断。</p> <br><table><thead><tr><th>对比维度</th><th>字体图标（Icon Fonts）</th><th>精灵图（CSS Sprites）</th></tr></thead><tbody><tr><td><strong>缩放质量</strong></td><td>矢量无损，任意缩放不模糊</td><td>位图，放大后模糊/锯齿</td></tr><tr><td><strong>颜色修改</strong></td><td>CSS 直接改 <code>color</code>，一行代码</td><td>不能直接改颜色，除非用 CSS filter（有兼容性问题且效果有限）</td></tr><tr><td><strong>HTTP 请求</strong></td><td>一个字体文件包含全部图标（1 次请求）</td><td>一张大图包含全部图标（1 次请求）</td></tr><tr><td><strong>语义化</strong></td><td>较差（<code><i></code> / <code><span></code> 本身无语义，需加 <code>aria-hidden</code>）</td><td>背景图无语义，需额外加 <code>alt</code> 或 <code>aria-label</code></td></tr><tr><td><strong>适用场景</strong></td><td>单色、扁平风格图标，导航菜单、按钮、纯展示型图标</td><td>彩色、渐变色、复杂细节图标，固定尺寸的装饰元素、游戏/应用图标</td></tr><tr><td><strong>维护成本</strong></td><td>低，增删改图标只需更新字体文件</td><td>高，增删图标需要重新合成大图，坐标全部重新计算</td></tr></tbody></table> <br><p><strong>选型结论：</strong>没有绝对的好坏，关键看图标形态。单色、扁平、需要频繁换色或缩放的图标，优先用字体图标，省事且灵活；彩色、渐变色、带复杂细节的图标，用精灵图更合适。两者也可以混用，各取所长。</p> <br><h3 id="%E5%9B%9B%E3%80%81%E5%AE%9E%E9%99%85%E5%BC%80%E5%8F%91%E5%BB%BA%E8%AE%AE" name="%E5%9B%9B%E3%80%81%E5%AE%9E%E9%99%85%E5%BC%80%E5%8F%91%E5%BB%BA%E8%AE%AE">四、实际开发建议</h3> <br><h4 id="%E4%BB%80%E4%B9%88%E6%97%B6%E5%80%99%E7%94%A8%20%E5%AD%97%E4%BD%93%E5%9B%BE%E6%A0%87%EF%BC%9F" name="%E4%BB%80%E4%B9%88%E6%97%B6%E5%80%99%E7%94%A8%20%E5%AD%97%E4%BD%93%E5%9B%BE%E6%A0%87%EF%BC%9F">什么时候用 字体图标？</h4> <br><ul><li>图标风格统一、单色、扁平化设计（如绝大多数后台管理界面、移动端 APP 底部导航）。</li><li>需要频繁调整颜色或大小（如换肤功能、响应式适配）。</li><li>团队没有专业 UI 设计师，直接用 iconfont 社区图标即可。</li></ul> <br><h4 id="%E4%BB%80%E4%B9%88%E6%97%B6%E5%80%99%E7%94%A8%20%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%9F" name="%E4%BB%80%E4%B9%88%E6%97%B6%E5%80%99%E7%94%A8%20%E7%B2%BE%E7%81%B5%E5%9B%BE%EF%BC%9F">什么时候用 精灵图？</h4> <br><ul><li>图标色彩丰富、包含渐变色或阴影（如电商平台的首字母大图标、品牌 Logo 合集）。</li><li>需要展示高精度、固定尺寸的图标（不需要缩放）。</li><li>历史遗留项目或 UI 设计稿已经提供了合成好的精灵图。</li><li>对字体图标兼容性有顾虑（IE8 以下对字体图标支持较差，但如今已极少见）。</li></ul> <br><h4 id="%E4%B8%A4%E8%80%85%E5%8F%AF%E4%BB%A5%E6%B7%B7%E7%94%A8%E5%90%97%EF%BC%9F" name="%E4%B8%A4%E8%80%85%E5%8F%AF%E4%BB%A5%E6%B7%B7%E7%94%A8%E5%90%97%EF%BC%9F" style="background-color:transparent">两者可以混用吗？</h4> <br><p><strong>当然可以！</strong> 实际大型项目中，两者经常搭配使用：</p> <br><ul><li><strong>导航/工具栏的单色图标</strong> → 用字体图标，方便换色和缩放。</li><li><strong>品牌 Logo、彩色促销标签、会员等级徽章</strong> → 用精灵图或独立图片，保留色彩和细节。</li></ul> <br><p>各自发挥各自的优势，互不冲突。</p>
