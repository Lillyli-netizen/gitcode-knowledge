<p></p><br><br><h4>1.1 什么是CSS</h4><br><br><p><strong>CSS</strong>（Cascading Style Sheets，层叠样式表）是一种用来控制网页在浏览器中显示外观的语言。</p><br><br><table><thead><tr><th>概念</th><th>说明</th></tr></thead><tbody><tr><td><strong>HTML</strong></td><td>结构，用于展示内容</td></tr><tr><td><strong>CSS</strong></td><td>样式，用于设置网页的样式及布局</td></tr><tr><td><strong>核心思想</strong></td><td>结构与样式分离</td></tr></tbody></table><br><br><h4>1.2 CSS的核心作用</h4><br><br><p>CSS的核心是<strong>控制视觉表现</strong>，主要包括三个方面：</p><br><br><ol><li><strong>样式美化</strong>：文本样式、背景、边框等</li><li><strong>布局与定位</strong>：元素排列、响应式设计</li><li><strong>动画交互</strong>：伪类、过渡、动画</li></ol><br><br><h4>1.3 CSS3现状</h4><br><br><ul><li>CSS3已被大部分现代浏览器支持</li><li>CSS4仍在开发中</li></ul><br><br><p></p><br><br><h4>修改后的 HTML 代码（含外部样式表）</h4><br><br><p>下面这份 HTML 代码同时演示了三种 CSS 引入方式：内联样式、内部样式表和外部样式表。</p><br><br><p>通俗来说呢，内联是直接写在 HTML 元素的 <strong><code>style</code> 属性</strong>内，<strong>作用于当前这一个具体的 HTML 元素</strong>，无法复用。</p><br><br><p>而内部样式表写在当前 HTML 文档 <code><head></code> 标签内的 <strong><code><style></code> 标签</strong>中。<strong>仅作用于当前的这一个 HTML 文档。</strong>（以下的笔记均通过这种方式整理）</p><br><br><p><strong>外部样式表（External Styles）</strong>存放在独立的 <strong><code>.css</code></strong> 文件中，通过 <code><head></code> 内的 <code><link rel="stylesheet" href="..."></code> 标签引入。只要任意 HTML 文件通过 <code><link></code> 引入该 CSS 文件，即可复用全部样式，是前端开发的基石。</p><br><br><pre><br><code class="language-html"><!DOCTYPE html><br><html lang="zh-CN"><br><head><br>    <meta charset="UTF-8"><br>    <meta name="viewport" content="width=device-width, initial-scale=1.0"><br>    <title>CSS三种引入方式</title><br>    <!-- 3. 外部样式表（推荐） --><br>    <link rel="stylesheet" href="style.css"><br>    <!-- 2. 内部样式表（写到head中的style标签里） --><br>    <style><br>        div {<br>            color: blue;<br>            font-size: 20px;<br>        }<br>    </style><br></head><br><body><br>    <!-- 1. 内联样式表（行内样式），直接在标签的style属性中写CSS --><br>    <p style="color: pink; font-size: 18px;">喵喵喵（内联样式）</p><br>    <!-- 内部样式表生效 --><br>    <div>喵喵喵（内部样式）</div><br>    <!-- 外部样式表生效（需要在style.css中定义） --><br>    <span>喵喵喵（外部样式）</span><br></body><br></html><br></code></pre><br><br><hr /><br><h4>创建外部样式表文件 <code>style.css</code></h4><br><br><p>在同一个文件夹下新建 <code>style.css</code> 文件，写入以下内容：</p><br><br><pre><br><code class="language-css">/* style.css - 外部样式表 */<br>span {<br>    color: green;<br>    font-weight: bold;<br>    font-size: 24px;<br>}<br>/* 也可以同时设置其他标签，但会被内联/内部覆盖（优先级规则） */<br>div {<br>    color: orange;  /* 会被内部样式表的 blue 覆盖，因为内部样式在后面 */<br>}</code></pre><br><br><p>下面逐行拆解这份 <code>style.css</code> 文件，看看每一部分到底在做什么：</p><br><br><h5>1. 注释行</h5><br><br><pre><br><code class="language-css">/* style.css - 外部样式表 */</code></pre><br><br><p>以 <code>/*</code> 开头、<code>*/</code> 结尾的内容是 CSS 注释，浏览器会直接忽略，不会产生任何样式效果。这里只是给文件起个名字，方便自己和同事一眼看出这是哪个文件。</p><br><br><h5>2. 选择器 <code>span</code></h5><br><br><pre><br><code class="language-css">span {<br>    color: green;<br>    font-weight: bold;<br>    font-size: 24px;<br>}</code></pre><br><br><p>这里的 <code>span</code> 是<strong>类型选择器（标签选择器）</strong>，意思是：选中页面中<strong>所有</strong> <code><span></code> 标签，并给它们统一应用大括号里的三条样式：</p><br><br><ul><li><code>color: green;</code> —— 文字颜色变成绿色</li><li><code>font-weight: bold;</code> —— 文字加粗</li><li><code>font-size: 24px;</code> —— 字号放大到 24 像素</li></ul><br><br><p>回到前面那份 HTML 代码，正文里有一个 <code><span>喵喵喵（外部样式）</span></code>，它没有写任何内联样式，也没有被内部样式表覆盖，所以最终会命中这里，显示为<strong>绿色、加粗、24px</strong> 的文字。</p><br><br><h5>3. 选择器 <code>div</code></h5><br><br><pre><br><code class="language-css">div {<br>    color: orange;  /* 会被内部样式表的 blue 覆盖，因为内部样式在后面 */<br>}</code></pre><br><br><p>同理，<code>div</code> 会选中页面中<strong>所有</strong> <code><div></code> 标签，把它们的文字颜色设为橙色。</p><br><br><p>但注意：HTML 里的 <code><div>喵喵喵（内部样式）</div></code> 同时被<strong>内部样式表</strong>设置了 <code>color: blue</code>。根据前面总结的优先级规则，在权重相同的情况下，<strong>后加载/后定义的样式会覆盖前面的</strong>。内部样式表写在 <code><head></code> 中，而外部样式表通过 <code><link></code> 引入，浏览器按顺序加载，内部样式表在外部样式表之后生效，所以最终这个 <code>div</code> 显示为<strong>蓝色</strong>，而不是橙色。</p><br><br><h5 style="background-color:transparent">4. 小结：这份文件到底在做什么</h5><br><br><table><thead><tr><th>选择器</th><th>作用对象</th><th>设置的样式</th><th>最终是否生效</th></tr></thead><tbody><tr><td><code>span</code></td><td>所有 <code><span></code> 标签</td><td>绿色、加粗、24px</td><td>生效（无其他样式覆盖）</td></tr><tr><td><code>div</code></td><td>所有 <code><div></code> 标签</td><td>橙色</td><td>被内部样式表的蓝色覆盖</td></tr></tbody></table><br><br><p>所以这份 <code>style.css</code> 的核心作用就是：<strong>把「样式」从 HTML 里抽离出来，单独放到一个 .css 文件中统一管理</strong>。HTML 只负责结构，CSS 负责外观，这就是「结构与样式分离」的体现，也是外部样式表成为主流做法的原因。</p><br><br><hr /><br><h4>三种样式表的优先级总结（权重相同的情况下）</h4><br><br><table><thead><tr><th>引入方式</th><th>优先级（就近原则）</th></tr></thead><tbody><tr><td><strong>内联样式</strong>（行内）</td><td>最高（权重 (1,0,0,0)）</td></tr><tr><td><strong>内部样式表</strong>（<code><style></code>）</td><td>中等（后定义覆盖先定义）</td></tr><tr><td><strong>外部样式表</strong>（<code>.css</code> 文件）</td><td>最低（但依然遵循层叠规则）</td></tr></tbody></table><br><br><blockquote><br><p><strong>注意</strong>：当权重相同时，<strong>后加载/后定义的样式会覆盖前面的</strong>。内联样式权重最高，会覆盖内部和外部。</p><br></blockquote><br><br><hr /><br><p>下面用一张流程图直观展示三种引入方式的加载顺序与优先级关系：</p><br><br><pre><br><code class="language-mermaid">flowchart TD<br>    A[浏览器加载页面] --> B[解析 HTML 文档]<br>    B --> C[加载外部样式表 link style.css]<br>    C --> D[解析内部样式表 style 标签]<br>    D --> E[解析内联样式 style 属性]<br>    E --> F[按就近原则确定最终样式]<br>    F --> G[内联样式 优先级最高]<br>    F --> H[内部样式表 优先级中等]<br>    F --> I[外部样式表 优先级最低]<br>    G --> J[最终生效样式]<br>    H --> J<br>    I --> J</code></pre><br><br><p><strong>就近原则的实际体现</strong>：所谓「就近」，指的是样式声明距离目标元素越近，优先级越高。内联样式直接写在标签的 <code>style</code> 属性上，离元素最近，所以优先级最高；内部样式表写在 <code><head></code> 的 <code><style></code> 标签里，距离稍远；外部样式表通过 <code><link></code> 引入，距离最远，优先级最低。在权重相同的情况下，后加载的样式会覆盖先加载的样式，这也是「就近原则」的另一种体现——后定义的样式在时间上更「近」。实际开发中，我们通常只用外部样式表统一管理样式，避免内联样式和内部样式表造成优先级混乱，这正是对就近原则的合理规避。</p><br><br><h4>实际开发建议</h4><br><br><ul><li><strong>外部样式表</strong>是主流做法，便于复用和维护。</li><li>一个项目通常只使用一种引入方式（外部），这里展示三种是为了学习区别。</li></ul><br><br><h3>二、CSS选择器</h3><br><br><p>选择器是CSS规则的第一部分，用于选择HTML元素。选择器选择标签，CSS属性修改样式。<br /><br>Pasted image 20260903180812.png</p><br><br><h4>2.1 基础选择器</h4><br><br><p>基础选择器由单个选择器组成，是CSS中最基本的选择方式。</p><br><br><h5>2.1.1 类型选择器（标签选择器）</h5><br><br><p>选择某个类型的元素。</p><br><br><pre><br><code class="language-css"><br>/* 选择所有span标签修改样式 */<br>span {<br>    color: green;<br>}<br></code></pre><br><br><blockquote><br><p><strong>CSS层叠性</strong>：CSS规则可以同时作用于一个元素，浏览器通过特定规则决定最终生效的样式。原则是<strong>后定义的样式覆盖先前的样式</strong>（就近原则）。</p><br></blockquote><br><br><h5>2.1.2 类选择器</h5><br><br><p>选择1个或多个元素，以 <code>.</code> 开头，实现差异性选择。</p><br><br><pre><br><code class="language-css">/* CSS */<br>.nav {<br>    color: pink;<br>}<br></code></pre><br><br><pre><br><code class="language-html"><div class="nav">修改样式</div><br></code></pre><br><br><p><strong>使用规范：</strong></p><br><br><ul><li>类名自定义，不能是中文或纯数字</li><li>多个英文单词组成尽量使用 <code>-</code> 链接</li><li>命名有重要意义，尽量见名知义</li><li>class属性可以有多类名，中间用空格隔开</li></ul><br><br><h5>2.1.3 ID选择器</h5><br><br><p>选择HTML中具有特定id属性的<strong>唯一</strong>元素，以 <code>#</code> 开头。</p><br><br><pre><br><code class="language-css">/* CSS */<br>#header {<br>    color: blue;<br>}<br></code></pre><br><br><pre><br><code><!-- HTML --><br><div id="header">修改样式</div><br></code></pre><br><br><blockquote><br><p><strong>注意</strong>：同一页面中，id值必须唯一（不能重复），主要用于配合JavaScript添加交互效果。</p><br></blockquote><br><br><h5>类选择器 vs ID选择器</h5><br><br><table><thead><tr><th>对比项</th><th>类选择器</th><th>ID选择器</th></tr></thead><tbody><tr><td>语法</td><td><code>.类名</code></td><td><code>#id名</code></td></tr><tr><td>作用</td><td>选择class属性的一个或多个元素</td><td>选择特定id属性的唯一元素</td></tr><tr><td>特点</td><td>可以使用多次</td><td>同一页面必须唯一</td></tr><tr><td>类似</td><td>身份证的名字</td><td>身份证的编号</td></tr><tr><td>场景</td><td>后期修改样式基本都是类选择器</td><td>配合JavaScript添加交互效果</td></tr></tbody></table><br><br><h5>2.1.4 通配符选择器</h5><br><br><p>选择HTML中所有的标签，用 <code>*</code> 表示。</p><br><br><pre><br><code class="language-css"><br>* {<br>    margin: 0;<br>    padding: 0;<br>}<br></code></pre><br><br><blockquote><br><p>特殊情况下通过通配符清除所有元素的默认边距和填充，统一不同浏览器的默认样式。但<strong>性能较差，慎用</strong>。</p><br></blockquote><br><br><h5>2.1.5 基础选择器总结</h5><br><br><table><thead><tr><th>选择器类型</th><th>语法示例</th><th>匹配范围</th><th>复用性</th><th>典型使用场景</th><th>注意事项</th></tr></thead><tbody><tr><td>类型选择器</td><td><code>div {...}</code></td><td>某一类型标签</td><td>全局</td><td>标签样式重置</td><td>避免滥用，可能导致样式冲突</td></tr><tr><td>类选择器</td><td><code>.nav {...}</code></td><td>含指定class的元素</td><td>多次使用</td><td>多元素共享样式</td><td>优先使用</td></tr><tr><td>ID选择器</td><td><code>#header {...}</code></td><td>唯一元素</td><td>唯一性</td><td>唯一元素标识</td><td>必须唯一</td></tr><tr><td>通配符选择器</td><td><code>* {...}</code></td><td>所有元素</td><td>全局覆盖</td><td>全局样式重置</td><td>性能较差，慎用</td></tr></tbody></table><br><br><blockquote><br><p><strong>大部分情况下，我们使用类选择器，是最重要的。</strong></p><br></blockquote><br><br><h4>2.2 关系选择器</h4><br><br><p>通过位置关系来选择目标元素，可以更精准选择某些元素。</p><br><br><h5>2.2.1 后代选择器</h5><br><br><p>选择某个元素的后代元素（不限层级，包括子元素、孙元素等），用<strong>空格</strong>隔开。</p><br><br><pre><br><code class="language-css"><br>div p {<br>    color: pink;<br>}<br>/* 选择div标签里面的所有p元素 */<br></code></pre><br><br><h5>2.2.2 子代选择器</h5><br><br><p>选择某个元素的直接子元素（仅限一层），用 <code>></code> 隔开。</p><br><br><pre><br><code class="language-css"><br>div > span {<br>    color: pink;<br>}<br>/* 选择div标签里面的第一层span元素 */<br></code></pre><br><br><h5>2.2.3 兄弟选择器</h5><br><br><p><strong>邻接兄弟选择器（+）</strong>：选中紧跟在某元素后面的第一个同级元素。</p><br><br><pre><br><code class="language-css"><br>h2 + p {<br>    color: pink;<br>}<br>/* 选中紧跟在h2后面的第一个p元素 */<br></code></pre><br><br><p><strong>通用兄弟选择器（~）</strong>：选中某元素之后的所有同级元素。</p><br><br><pre><br><code class="language-css"><br>h2 ~ p {<br>    color: pink;<br>}<br>/* 选中紧跟在h2后面的所有p元素 */<br></code></pre><br><br><h5>2.2.4 关系选择器总结</h5><br><br><table><thead><tr><th>选择器</th><th>语法</th><th>选择范围</th><th>示例</th></tr></thead><tbody><tr><td>后代选择器</td><td><code>A B</code></td><td>所有后代（跨层级）</td><td><code>ul li {color: pink;}</code></td></tr><tr><td>子代选择器</td><td><code>A > B</code></td><td>直接子元素（仅一层）</td><td><code>div > span {color: pink;}</code></td></tr><tr><td>邻接兄弟选择器</td><td><code>A + B</code></td><td>紧邻的下一个同级元素</td><td><code>h2 + p {}</code></td></tr><tr><td>通用兄弟选择器</td><td><code>A ~ B</code></td><td>A之后的所有同级元素</td><td><code>h2 ~ p {}</code></td></tr></tbody></table><br><br><blockquote><br><p><strong>后代选择器是最常用的。</strong></p><br></blockquote><br><br><h4>2.3 分组选择器（并集选择器）</h4><br><br><p>将不同的选择器组合在一起，用<strong>逗号</strong>分割。</p><br><br><pre><br><code class="language-css"><br>div, span {<br>    color: pink;<br>}<br></code></pre><br><br><p><strong>使用场景</strong>：多个元素具备相同样式时，组合在一起避免重复代码。</p><br><br><h4>2.4 伪类选择器</h4><br><br><p>选择元素的特定状态或结构位置，符号是<strong>冒号（:）</strong>。</p><br><br><h5>2.4.1 状态伪类选择器</h5><br><br><p><strong>链接伪类</strong>（LVHA顺序）：</p><br><br><table><thead><tr><th>链接伪类</th><th>作用</th></tr></thead><tbody><tr><td><code>a:link</code></td><td>未访问链接的默认样式</td></tr><tr><td><code>a:visited</code></td><td>已访问链接的样式</td></tr><tr><td><code>a:hover</code></td><td>鼠标悬停在链接上时的反馈</td></tr><tr><td><code>a:active</code></td><td>链接被点击时的瞬时状态</td></tr></tbody></table><br><br><p><code>:active</code> 的触发条件是：<strong>鼠标左键按下 → 还没松开</strong> 的这段时间。</p><br><br><blockquote><br><p><strong>伪类顺序规则</strong>：<code>a:link</code> → <code>a:visited</code> → <code>a:hover</code> → <code>a:active</code></p><br></blockquote><br><br><p><strong>规则 1：四个伪类权重一样</strong></p><br><br><p><code>a:link</code>、<code>a:visited</code>、<code>a:hover</code>、<code>a:active</code> 都是 (0,1,1)，分不出高下，只能靠<strong>书写顺序</strong>（后来者覆盖）。</p><br><br><p><strong>规则 2：状态会叠加，不是一个时刻只命中一个</strong></p><br><br><table><thead><tr><th>场景</th><th>同时命中的伪类</th></tr></thead><tbody><tr><td>没访问过、鼠标悬停</td><td><code>:link</code> + <code>:hover</code></td></tr><tr><td>访问过、鼠标悬停</td><td><code>:visited</code> + <code>:hover</code></td></tr><tr><td>按住鼠标（必然悬停着）</td><td><code>:hover</code> + <code>:active</code></td></tr></tbody></table><br><br><p><strong>用户行为伪类（动态伪类）</strong>：</p><br><br><table><thead><tr><th>动态伪类</th><th>作用</th></tr></thead><tbody><tr><td><code>:hover</code></td><td>鼠标经过元素</td></tr><tr><td><code>:focus</code></td><td>获得焦点的元素（表单）</td></tr></tbody></table><br><br><h5>2.4.2 结构伪类选择器</h5><br><br><p>根据元素的位置选择目标元素。</p><br><br><table><thead><tr><th>结构伪类</th><th>作用</th></tr></thead><tbody><tr><td><code>:first-child</code></td><td>一组兄弟元素中的第一个元素</td></tr><tr><td><code>:last-child</code></td><td>一组兄弟元素中的最后一个元素</td></tr><tr><td><code>:nth-child(n)</code></td><td>一组兄弟元素列表中第n个元素</td></tr></tbody></table><br><br><p><strong>n的取值可以是：</strong></p><br><br><ul><li><strong>数字</strong>：从1开始</li><li><strong>关键字</strong>：<code>odd</code>（奇数）、<code>even</code>（偶数）</li><li><strong>公式</strong>：<br>	<ul><li><code>:nth-child(3n)</code> → 第3、6、9...个元素</li><li><code>:nth-child(n+2)</code> → 第2个以及以后的元素</li><li><code>:nth-child(-n+3)</code> → 前面3个元素</li></ul><br>	</li></ul><br><br><blockquote><br><p>公式中n的取值从0开始计算。结构选择器每个语法权重相同，看顺序<br
