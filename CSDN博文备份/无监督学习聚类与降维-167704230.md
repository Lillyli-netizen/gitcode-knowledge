<p><br> </p> <br><blockquote> <br> <p>有监督学习有"标准答案"（标签），无监督学习没有——它要从数据自身结构中"发现"规律。<br /> 本文覆盖两大无监督任务：<strong>聚类</strong>（把相似的样本分到一堆）和<strong>降维</strong>（把高维数据压到低维便于可视化与分析），全程配 sklearn / umap-learn 代码。</p> <br></blockquote> <br><hr /> <br><h3>一、无监督学习概述</h3> <br><h4>1.1 三种学习范式对比</h4> <br><table><thead><tr><th>范式</th><th>数据</th><th>目标</th><th>典型任务</th><th>典型算法</th></tr></thead><tbody><tr><td>有监督学习（Supervised）</td><td>有标签 (X, y)</td><td>学习 X→y 映射</td><td>分类、回归</td><td>SVM、决策树、神经网络</td></tr><tr><td>无监督学习（Unsupervised）</td><td>无标签 (X)</td><td>发现数据内在结构</td><td>聚类、降维、密度估计</td><td>KMeans、PCA、t-SNE</td></tr><tr><td>半监督学习（Semi-supervised）</td><td>少量有标签 + 大量无标签</td><td>用无标签数据辅助有标签训练</td><td>标签传播</td><td>Label Spreading</td></tr></tbody></table> <br><h4>1.2 无监督学习的两大核心任务</h4> <br><p><strong>聚类（Clustering）</strong>：把样本按相似度分成若干组，同组内相似、跨组差异大。用途：客户分群、异常检测、图像分割。</p> <br><p><strong>降维（Dimensionality Reduction）</strong>：把高维数据映射到低维空间，尽量保留原始信息。用途：数据可视化、特征压缩、去噪、加速下游模型训练。</p> <br><h4>1.3 为什么要学无监督</h4> <br><ul><li>现实中<strong>无标签数据远多于有标签数据</strong>，标注成本高</li><li>探索性数据分析（EDA）的第一步：先看数据"长什么样"</li><li>很多场景根本没有标签可言（异常检测、用户画像分群）</li><li>降维是高维数据可视化的<strong>唯一手段</strong>——人眼最多看 3 维</li></ul> <br><hr /> <br><h3>二、聚类——把相似的样本分到一堆</h3> <br><h4>2.1 KMeans：最经典的"分 K 堆"</h4> <br><h5>原理</h5> <br><p>给定 K 个簇，KMeans 通过迭代两步收敛：</p> <br><pre><code>1. 初始化：随机选 K 个样本点作为簇中心（质心）<br>2. 分配：每个样本分到离它最近的质心所在的簇<br>3. 更新：每个簇的质心更新为该簇所有样本的均值<br>4. 重复 2-3，直到质心不再移动（或变化 < 阈值）<br></code></pre> <br><p>目标函数（最小化簇内平方误差和 SSE）：</p> <br><pre><code>SSE = Σ_{k=1}^{K} Σ_{x∈C_k} ||x - μ_k||²<br></code></pre> <br><p>其中 μ_k 是第 k 个簇的质心，C_k 是属于该簇的样本集合。</p> <br><h5>K 值怎么选</h5> <br><p>KMeans 需要预先指定 K，这是它最大的"人为干预"环节。两种常用方法：</p> <br><p><strong>肘部法则（Elbow Method）</strong>：对不同的 K 计算 SSE，画 K-SSE 曲线，选"拐弯"处（SSE 下降速率骤减的点）。</p> <br><p><strong>轮廓系数（Silhouette Score）</strong>：对每个样本算一个 [-1, 1] 的分数，越接近 1 说明分得越好。取不同 K 看平均轮廓系数，选最大的。</p> <br><h5>sklearn 代码</h5> <br><pre><code>from sklearn.cluster import KMeans<br>from sklearn.datasets import make_blobs<br>import matplotlib.pyplot as plt<br><br># 1. 生成测试数据：3 个簇，共 300 个样本<br>X, y_true = make_blobs(n_samples=300, centers=3, cluster_std=0.6, random_state=42)<br><br># 2. KMeans 聚类<br>kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)<br>labels = kmeans.fit_predict(X)<br>centers = kmeans.cluster_centers_<br><br># 3. 可视化<br>plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', s=20)<br>plt.scatter(centers[:, 0], centers[:, 1], c='red', marker='x', s=200, linewidths=3)<br>plt.title('KMeans 聚类结果')<br>plt.show()<br><br># 4. 查看簇内平方误差<br>print(f'SSE (inertia): {kmeans.inertia_:.2f}')<br></code></pre> <br><h5>肘部法则选 K</h5> <br><pre><code>sse_list = []<br>K_range = range(1, 11)<br>for k in K_range:<br>    km = KMeans(n_clusters=k, random_state=42, n_init=10)<br>    km.fit(X)<br>    sse_list.append(km.inertia_)<br><br>plt.plot(K_range, sse_list, 'bo-')<br>plt.xlabel('K (簇数)')<br>plt.ylabel('SSE (簇内平方误差)')<br>plt.title('肘部法则选 K')<br>plt.axvline(x=3, color='red', linestyle='--', label='肘部 K=3')<br>plt.legend()<br>plt.show()<br></code></pre> <br><h5>优缺点</h5> <br><table><thead><tr><th>优点</th><th>缺点</th></tr></thead><tbody><tr><td>简单高效，O(nKt) 复杂度</td><td>需预先指定 K</td></tr><tr><td>适合球形/凸形簇</td><td>对非球形簇效果差（如环形）</td></tr><tr><td>结果可解释性强</td><td>对异常值敏感（质心被拉偏）</td></tr><tr><td></td><td>K 个初始质心随机选，可能陷入局部最优（<code>n_init</code> 多跑几次取最优）</td></tr></tbody></table> <br><hr /> <br><h4>2.2 层次聚类：自底向上"合并树"</h4> <br><h5>原理</h5> <br><p>层次聚类不需要预先指定 K，它生成一棵"聚类树"（树状图 Dendrogram），你可以在任意高度"剪一刀"得到 K 个簇。</p> <br><p>两种策略：</p> <br><table><thead><tr><th>策略</th><th>做法</th><th>sklearn 参数</th></tr></thead><tbody><tr><td>凝聚法（Agglomerative，自底向上）</td><td>每个样本初始为一个簇，反复合并最相似的两簇</td><td><code>AgglomerativeClustering</code>（常用）</td></tr><tr><td>分裂法（Divisive，自顶向下）</td><td>所有样本初始为一个簇，反复分裂最不均匀的簇</td><td>sklearn 未直接实现</td></tr></tbody></table> <br><h5>簇间距离怎么算</h5> <br><p>合并两个簇时，"两个簇之间的距离"有多种定义：</p> <br><table><thead><tr><th>链接方式</th><th>定义</th><th>特点</th></tr></thead><tbody><tr><td>单链接（Single / Ward min）</td><td>两簇中<strong>最近</strong>的两点距离</td><td>容易"链式效应"，把长条形数据拉成一串</td></tr><tr><td>全链接（Complete / Ward max）</td><td>两簇中<strong>最远</strong>的两点距离</td><td>偏好紧凑球形簇</td></tr><tr><td>平均链接（Average）</td><td>两簇所有点对的<strong>平均</strong>距离</td><td>折中</td></tr><tr><td>Ward 链接</td><td>合并后使<strong>SSE 增量最小</strong></td><td>最常用，效果接近 KMeans</td></tr></tbody></table> <br><h5>sklearn 代码</h5> <br><pre><code>from sklearn.cluster import AgglomerativeClustering<br>from scipy.cluster.hierarchy import dendrogram, linkage<br>import matplotlib.pyplot as plt<br><br># 1. 凝聚层次聚类（指定最终 3 个簇，Ward 链接）<br>agg = AgglomerativeClustering(n_clusters=3, linkage='ward')<br>labels = agg.fit_predict(X)<br><br># 2. 画树状图（看不同高度"剪"出几个簇）<br>Z = linkage(X, method='ward')   # linkage 矩阵<br>plt.figure(figsize=(12, 5))<br>dendrogram(Z, truncate_mode='level', p=5)  # p=显示最后 5 层<br>plt.title('层次聚类树状图（Dendrogram）')<br>plt.xlabel('样本索引 / 簇')<br>plt.ylabel('距离')<br>plt.show()<br></code></pre> <br><p><strong>怎么用树状图选 K</strong>：看纵轴——最长的那条"竖线"（未被横线截断的最大间距）对应的位置横切一刀，切到的横线数就是推荐 K。</p> <br><h5>优缺点</h5> <br><table><thead><tr><th>优点</th><th>缺点</th></tr></thead><tbody><tr><td>不需预先指定 K</td><td>计算复杂度高 O(n³)，大数据集慢</td></tr><tr><td>树状图直观，可交互式选 K</td><td>一旦合并/分裂不可撤销</td></tr><tr><td>可发现数据的层次结构</td><td>对噪声敏感</td></tr><tr><td>任意形状簇都能处理</td><td></td></tr></tbody></table> <br><hr /> <br><h4>2.3 DBSCAN：基于密度的"自动找簇"</h4> <br><h5>原理</h5> <br><p>DBSCAN（Density-Based Spatial Clustering of Applications with Noise）的核心思想：<strong>簇是高密度区域，由低密度区域分隔</strong>。</p> <br><p>两个参数：</p> <br><table><thead><tr><th>参数</th><th>含义</th></tr></thead><tbody><tr><td><code>eps</code>（ε）</td><td>邻域半径：以某点为圆心、eps 为半径的圆内的点都算"邻居"</td></tr><tr><td><code>min_samples</code></td><td>核心点阈值：一个点的 eps 邻域内至少有 min_samples 个点，它才是"核心点"</td></tr></tbody></table> <br><p>三种点：</p> <br><table><thead><tr><th>类型</th><th>定义</th><th>簇归属</th></tr></thead><tbody><tr><td>核心点（Core）</td><td>eps 邻域内点数 ≥ min_samples</td><td>簇的"骨架"</td></tr><tr><td>边界点（Border）</td><td>不是核心点，但在某核心点的 eps 邻域内</td><td>归属该核心点所在簇</td></tr><tr><td>噪声点（Noise）</td><td>既不是核心点，也不在任何核心点邻域内</td><td>标记为 -1，不归属任何簇</td></tr></tbody></table> <br><p>算法流程：</p> <br><pre><code>1. 对每个未访问的点 p：<br>   a. 找 p 的 eps 邻域<br>   b. 若邻域点数 < min_samples → 暂标记为噪声（后续可能被重新归为边界点）<br>   c. 若邻域点数 ≥ min_samples → p 是核心点，创建新簇<br>      → 把 p 的所有邻居加入簇<br>      → 对每个邻居递归重复（若邻居也是核心点，扩展其邻居）<br>2. 直到所有点都被访问<br></code></pre> <br><h5>sklearn 代码</h5> <br><pre><code>from sklearn.cluster import DBSCAN<br>from sklearn.datasets import make_moons<br><br># 1. 生成月牙形数据（KMeans 处理不了的非凸簇）<br>X_moons, _ = make_moons(n_samples=300, noise=0.1, random_state=42)<br><br># 2. DBSCAN 聚类<br>db = DBSCAN(eps=0.2, min_samples=5)<br>labels = db.fit_predict(X_moons)<br><br># 3. 可视化（-1 是噪声点，画成黑色）<br>plt.scatter(X_moons[:, 0], X_moons[:, 1], c=labels, cmap='viridis', s=20)<br>plt.title(f'DBSCAN: {len(set(labels)) - (1 if -1 in labels else 0)} 个簇, '<br>          f'{list(labels).count(-1)} 个噪声点')<br>plt.show()<br></code></pre> <br><h5>eps 怎么选</h5> <br><p>经验方法：对每个点算到最近邻居的距离，排序后画 k-距离图（k=min_samples），曲线"拐弯"处对应 eps。</p> <br><pre><code>from sklearn.neighbors import NearestNeighbors<br><br>nn = NearestNeighbors(n_neighbors=5)<br>nn.fit(X_moons)<br>distances, _ = nn.kneighbors(X_moons)<br>distances = np.sort(distances[:, -1])   # 第 5 近邻的距离，排序<br><br>plt.plot(distances)<br>plt.xlabel('样本（按距离排序）')<br>plt.ylabel('第 5 近邻距离')<br>plt.title('k-距离图选 eps')<br>plt.show()<br></code></pre> <br><h5>优缺点</h5> <br><table><thead><tr><th>优点</th><th>缺点</th></tr></thead><tbody><tr><td>不需指定簇数 K</td><td>eps 和 min_samples 对结果影响大</td></tr><tr><td>能发现任意形状的簇</td><td>密度差异大的数据集（有的簇密、有的疏）效果差</td></tr><tr><td>自动识别噪声点（异常检测）</td><td>高维数据"维度灾难"——距离失效</td></tr><tr><td>对异常值鲁棒</td><td></td></tr></tbody></table> <br><hr /> <br><h4>2.4 三种聚类方法对比</h4> <br><table><thead><tr><th>方法</th><th>簇形状</th><th>需指定 K</th><th>噪声处理</th><th>复杂度</th><th>适用场景</th></tr></thead><tbody><tr><td>KMeans</td><td>球形</td><td>✅</td><td>❌</td><td>O(nKt)</td><td>簇形状规则、数据量大</td></tr><tr><td>层次聚类</td><td>任意</td><td>❌（树状图选）</td><td>❌</td><td>O(n³)</td><td>小数据集、需层次结构</td></tr><tr><td>DBSCAN</td><td>任意</td><td>❌</td><td>✅</td><td>O(n log n)</td><td>非凸簇、异常检测</td></tr></tbody></table> <br><hr /> <br><h4>2.5 聚类评估指标</h4> <br><p>无标签时怎么评估聚类好坏？三个内部指标：</p> <br><table><thead><tr><th>指标</th><th>公式思想</th><th>取值范围</th><th>sklearn API</th><th>越大/越小越好</th></tr></thead><tbody><tr><td>轮廓系数（Silhouette）</td><td>(b-a)/max(a,b)，a=簇内平均距离，b=最近簇间平均距离</td><td>[-1, 1]</td><td><code>silhouette_score</code></td><td>越大越好（>0.5 好，<0 差）</td></tr><tr><td>CH 指数（Calinski-Harabasz）</td><td>簇间离散度 / 簇内离散度 × 样本数修正</td><td>[0, ∞)</td><td><code>calinski_harabasz_score</code></td><td>越大越好</td></tr><tr><td>Davies-Bouldin</td><td>各簇间最大相似度平均</td><td>[0, ∞)</td><td><code>davies_bouldin_score</code></td><td>越小越好</td></tr></tbody></table> <br><pre><code>from sklearn.metrics import silhouette_score, calinski_harabasz_score, davies_bouldin_score<br><br># 假设 X 是数据，labels 是聚类结果<br>print(f'轮廓系数: {silhouette_score(X, labels):.4f}')   # 越大越好<br>print(f'CH 指数:  {calinski_harabasz_score(X, labels):.4f}')  # 越大越好<br>print(f'DB 指数:  {davies_bouldin_score(X, labels):.4f}')     # 越小越好<br></code></pre> <br><p><strong>有标签时</strong>（用聚类结果跟真实标签对比，注意聚类标签编号可能跟真实标签不一致）：</p> <br><table><thead><tr><th>指标</th><th>sklearn API</th><th>说明</th></tr></thead><tbody><tr><td>ARI（调整兰德指数）</td><td><code>adjusted_rand_score</code></td><td>[-1, 1]，0=随机，1=完全一致</td></tr><tr><td>NMI（归一化互信息）</td><td><code>normalized_mutual_info_score</code></td><td>[0, 1]，1=完全一致</td></tr><tr><td>同质性 / 完整性 / V-measure</td><td><code>homogeneity_completeness_v_measure</code></td><td>[0, 1]</td></tr></tbody></table> <br><hr /> <br><h3>三、降维——把高维压到低维</h3> <br><h4>3.1 为什么降维</h4> <br><ul><li><strong>可视化</strong>：人最多看 3 维，高维数据必须降到 2-3 维才能画图</li><li><strong>去噪</strong>：低维子空间往往保留了信号、滤掉了噪声</li><li><strong>加速</strong>：特征少了，下游模型训练更快、内存更省</li><li><strong>缓解维度灾难</strong>：高维空间中样本稀疏，距离/密度都失效</li></ul> <br><h4>3.2 PCA：线性降维的"老大哥"</h4> <br><h5>原理</h5> <br><p>PCA（Principal Component Analysis，主成分分析）通过<strong>正交变换</strong>把原始特征投影到新的坐标系，新坐标轴按数据方差大小排序——前几个轴（主成分）保留了最多信息。</p> <br><p>数学步骤：</p> <br><pre><code>1. 数据中心化：X = X - mean(X)   （每个特征减去均值，平移到原点）<br>2. 计算协方差矩阵：C = XᵀX / (n-1)<br>3. 对 C 做特征值分解：C = V Λ Vᵀ<br>4. 取前 k 个最大特征值对应的特征向量，组成投影矩阵 W (d×k)<br>5. 降维：X_reduced = X · W   （n×d · d×k = n×k）<br></code></pre> <br><p>直觉理解：找数据"方差最大"的方向作为第一主成分，再在与它正交的方向里找方差最大的作为第二主成分，依此类推。<strong>方差 = 信息量</strong>。</p> <br><h5>sklearn 代码</h5> <br><pre><code>from sklearn.decomposition import PCA<br>from sklearn.datasets import load_digits<br><br># 1. 加载手写数字数据集：1797 个样本，每个 8×8=64 维<br>digits = load_digits()<br>X, y = digits.data, digits.target   # X.shape = (1797, 64)<br><br># 2. PCA 降到 2 维（可视化用）<br>pca = PCA(n_components=2)<br>X_pca = pca.fit_transform(X)   # X_pca.shape = (1797, 2)<br><br># 3. 可视化：不同数字用不同颜色<br>plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='tab10', s=10, alpha=0.7)<br>plt.colorbar(label='数字类别')<br>plt.title(f'PCA 降维 (64→2), 解释方差比: {pca.explained_variance_ratio_.sum():.2%}')<br>plt.xlabel(f'PC1 ({pca.explained_variance_ratio_[0]:.2%})')<br>plt.ylabel(f'PC2 ({pca.explained_variance_ratio_[1]:.2%})')<br>plt.show()<br><br># 4. 查看各主成分解释了多少方差<br>print(f'前 2 个主成分解释方差比: {pca.explained_variance_ratio_}')<br>print(f'累计解释方差: {pca.explained_variance_ratio_.sum():.2%}')<br></code></pre> <br><h5>保留多少维</h5> <br><pre><code># 画累计解释方差曲线，找"够用"的维度数<br>pca_full = PCA().fit(X)<br>cumvar = np.cumsum(pca_full.explained_variance_ratio_)<br><br>plt.plot(range(1, len(cumvar) + 1), cumvar, 'b-')<br>plt.axhline(y=0.95, color='r', linestyle='--', label='95% 方差')<br>plt.xlabel('主成分数')<br>plt.ylabel('累计解释方差比')<br>plt.title('PCA 选维度数')<br>plt.legend()<br>plt.show()<br><br># 或者直接指定保留 95% 方差<br>pca_95 = PCA(n_components=0.95)   # 传 0~1 的浮点数 = 保留的方差比例<br>X_95 = pca_95.fit_transform(X)<br>print(f'保留 95% 方差需要 {pca_95.n_components_} 维（原始 64 维）')<br></code></pre> <br><h5>优缺点</h5> <br><table><thead><tr><th>优点</th><th>缺点</th></tr></thead><tbody><tr><td>线性变换，计算高效</td><td>只能捕捉线性结构，非线性流形无能为力</td></tr><tr><td>降维后各主成分不相关（正交）</td><td>主成分可解释性差（是原始特征的线性组合）</td></tr><tr><td>可逆（可重建原始数据近似）</td><td>对异常值敏感（协方差矩阵被拉偏）</td></tr><tr><td>解释方差比量化信息保留量</td><td></td></tr></tbody></table> <br><hr /> <br><h4>3.3 t-SNE：非线性降维的可视化利器</h4> <br><h5>原理</h5> <br><p>t-SNE（t-Distributed Stochastic Neighbor Embedding）专门为<strong>可视化</strong>设计（降到 2-3 维），核心思想：<strong>高维空间中"近邻"的点，在低维空间中仍然近邻</strong>。</p> <br><p>两步走：</p> <br><pre><code>1. 高维空间：用高斯分布算点对之间的"相似度"（条件概率）<br>   p_{j|i} = exp(-||x_i - x_j||² / 2σ_i²) / Σ_k exp(-||x_i - x_k||² / 2σ_i²)<br><br>2. 低维空间：用 t 分布（自由度=1，即柯西分布）算相似度<br>   q_{ij} = (1 + ||y_i - y_j||²)⁻¹ / Σ_k (1 + ||y_k - y_l||²)⁻¹<br><br>3. 最小化 KL 散度：KL(P || Q) = Σ_i Σ_j p_{ij} log(p_{ij} / q_{ij})<br>   → 用梯度下降优化低维坐标 y_i<br></code></pre> <br><p><strong>为什么用 t 分布而不是高斯分布</strong>：高维空间中"中等距离"的点很多（维度灾难），如果低维也用高斯分布，这些点会被挤成一团。t 分布"尾巴更重"，能把中等距离的点推到更远的地方，缓解"拥挤问题"。</p> <br><h5>sklearn 代码</h5> <br><pre><code>from sklearn.manifold import TSNE<br><br># 1. t-SNE 降到 2 维<br>tsne = TSNE(n_components=2, perplexity=30, learning_rate='auto',<br>            init='pca', random_state=42, n_iter=1000)<br>X_tsne = tsne.fit_transform(X)<br><br># 2. 可视化<br>plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='tab10', s=10, alpha=0.7)<br>plt.colorbar(label='数字类别')<br>plt.title('t-SNE 降维 (64→2)')<br>plt.show()<br></code></pre> <br><h5>关键参数</h5> <br><table><thead><tr><th>参数</th><th>含义</th><th>调参建议</th></tr></thead><tbody><tr><td><code>perplexity</code></td><td>每个点关注的"有效近邻数"，平衡局部/全局结构</td><td>5~50，默认 30；样本多就调大，<code>perplexity < n_samples</code></td></tr><tr><td><code>learning_rate</code></td><td>梯度下降学习率</td><td>10~1000；太大簇压缩成点，太远簇缩成密集球</td></tr><tr><td><code>n_iter</code></td><td>最大迭代次数</td><td>≥1000，默认 1000</td></tr><tr><td><code>init</code></td><td>低维坐标初始化</td><td><code>'pca'</code>（用 PCA 结果初始化，比随机更稳）</td></tr></tbody></table> <br><p><strong>perplexity 对比实验</strong>：</p> <br><pre><code>fig, axes = plt.subplots(1, 3, figsize=(18, 5))<br>for i, perp in enumerate([5, 30, 100]):<br>    tsne = TSNE(n_components=2, perplexity=perp, random_state=42, init='pca')<br>    X_tsne = tsne.fit_transform(X)<br>    axes[i].scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='tab10', s=10)<br>    axes[i].set_title(f'perplexity={perp}')<br>plt.suptitle('t-SNE: perplexity 对比')<br>plt.show()<br></code></pre> <br><h5>优缺点</h5> <br><table><thead><tr><th>优点</th><th>缺点</th></tr></thead><tbody><tr><td>非线性，能展开复杂流形</td><td><strong>只用于可视化</strong>，不适合作为下游模型输入</td></tr><tr><td>簇分离效果好，视觉漂亮</td><td>计算慢 O(n²)，大数据集需先 PCA 降到 50 维再 t-SNE</td></tr><tr><td></td><td><strong>簇间距离无意义</strong>——t-SNE 会"放大"簇间距离让图好看，但不反映真实距离</td></tr><tr><td></td><td><strong>簇大小无意义</strong>——t-SNE 会"均匀化"簇大小</td></tr><tr><td></td><td>非确定性（每次运行结果不同，需固定 random_state）</td></tr><tr><td></td><td>不能新增点降维（没有 transform 方法，只能 fit_transform）</td></tr></tbody></table> <br><hr /> <br><h4>3.4 UMAP：又快又好的"新秀"</h4> <br><h5>原理</h5> <br><p>UMAP（Uniform Manifold Approximation and Projection）基于代数拓扑，核心思想与 t-SNE 类似（保持局部近邻关系），但数学基础更扎实、速度更快。</p> <br><p>两步走：</p> <br><pre><code>1. 构建高维拓扑表示：用 k-近邻图（每个点连 k 个最近邻，边权=距离）<br>2. 优化低维表示：在低维构建类似的图，最小化两个图之间的交叉熵<br></code></pre> <br><p>与 t-SNE 的关键区别：UMAP 用<strong>指数衰减</strong>的边权（不是 t 分布），且优化目标是<strong>交叉熵</strong>（不是 KL 散度），这让它：</p> <br><ul><li>速度更快（O(n·k)，k 是近邻数，通常 15）</li><li><strong>保留了更多全局结构</strong>（t-SNE 只保局部）</li><li><strong>可以 transform 新数据</strong>（有 <code>transform</code> 方法，能增量降维）</li><li>可以降到任意维度（不限于 2-3 维，也能做特征压缩）</li></ul> <br><h5>代码（需安装：<code>pip install umap-learn</code>）</h5> <br><pre><code>import umap<br><br># 1. UMAP 降到 2 维<br>reducer = umap.UMAP(n_components=2, n_neighbors=15, min_dist=0.1, random_state=42)<br>X_umap = reducer.fit_transform(X)<br><br># 2. 可视化<br>plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='tab10', s=10, alpha=0.7)<br>plt.colorbar(label='数字类别')<br>plt.title('UMAP 降维 (64→2)')<br>plt.show()<br><br># 3. UMAP 可以 transform 新数据（t-SNE 做不到）<br>X_new = X[:10]   # 假设这是新数据<br>X_new_umap = reducer.transform(X_new)<br></code></pre> <br><h5>关键参数</h5> <br><table><thead><tr><th>参数</th><th>含义</th><th>调参建议</th></tr></thead><tbody><tr><td><code>n_neighbors</code></td><td>近邻数，平衡局部/全局</td><td>2~200，默认 15；小值重局部细节，大值重全局结构</td></tr><tr><td><code>min_dist</code></td><td>低维中点之间的最小距离</td><td>0.0~0.99，默认 0.1；小值簇更紧密，大值簇更松散</td></tr><tr><td><code>n_components</code></td><td>降维目标维度</td><td>2~100，可视化用 2-3，特征压缩可更高</td></tr><tr><td><code>metric</code></td><td>距离度量</td><td><code>'euclidean'</code>（默认）、<code>'cosine'</code>、<code>'manhattan'</code> 等</td></tr></tbody></table> <br><h5>优缺点</h5> <br><table><thead><tr><th>优点</th><th>缺点</th></tr></thead><tbody><tr><td>速度快（比 t-SNE 快 5-10 倍）</td><td>数学理论较深，参数直觉不如 t-SNE 直观</td></tr><tr><td>保留局部+全局结构</td><td>不同 random_state 结果差异比 t-SNE 小但仍存在</td></tr><tr><td>可以 transform 新数据</td><td></td></tr><tr><td>可降到任意维度（不限于可视化）</td><td></td></tr><tr><td>支持非欧距离（cosine 等，适合文本/图像）</td><td></td></tr></tbody></table> <br><hr /> <br><h4>3.5 三种降维方法对比</h4> <br><table><thead><tr><th>方法</th><th>线性/非线性</th><th>速度</th><th>保留结构</th><th>可 transform</th><th>适用维度</th><th>典型用途</th></tr></thead><tbody><tr><td>PCA</td><td>线性</td><td>⚡⚡⚡ 快</td><td>全局（方差）</td><td>✅</td><td>任意</td><td>特征压缩、去噪、预处理</td></tr><tr><td>t-SNE</td><td>非线性</td><td>🐢 慢 (O(n²))</td><td>局部</td><td>❌</td><td>2-3</td><td>纯可视化</td></tr><tr><td>UMAP</td><td>非线性</td><td>⚡⚡ 较快</td><td>局部+全局</td><td>✅</td><td>任意</td><td>可视化 + 特征压缩</td></tr></tbody></table> <br><p><strong>经验流程</strong>：</p> <br><pre><code>高维数据<br>  │<br>  ├─ 只为可视化 → UMAP（首选）或 t-SNE<br>  │<br>  ├─ 为下游模型做特征压缩 → PCA（先试）或 UMAP（PCA 不够好再试）<br>  │<br>  └─ 数据量很大（>10万）→ 先 PCA 降到 50 维 → 再 UMAP/t-SNE 降到 2 维<br></code></pre> <br><hr /> <br><h3>四、实战案例：手写数字聚类与可视化</h3> <br><p>把聚类和降维串起来，用 sklearn 的 digits 数据集（1797 个 8×8 手写数字图片，64 维，0-9 共 10 类）做完整流程。</p> <br><pre><code>import numpy as
